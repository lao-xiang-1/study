# 论文逐段翻译 Skill

将 OCR 提取的英文学术论文逐段翻译为中文，译文直接写入原文件，每段原文下方紧跟【译文】标签和中文翻译。

## 适用场景

- OCR 后的英文论文文件（.md 格式）
- 用户要求"逐段翻译"、"翻译一段改一段"
- 用户要求在原文文件中直接插入翻译

## 执行流程

### 第一步：确认目标文件

1. 读取用户指定的目标文件，确认文件存在且包含待翻译的英文正文
2. 只处理文件中的**正文段落**，跳过以下内容：
   - 纯 HTML 标签行（如 `<div>`、`<img>` 标签块）
   - 图片 URL 行
   - 作者单位地址行
   - 图表编号标记（如 `a`、`b`、`C` 等独立标签）
   - 已翻译过的段落（已包含【译文】标记的）

### 第二步：清理无断空格（NBSP），确保 Edit 工具可用

OCR 或网页复制的内容常混入无断空格字符（NBSP，Unicode ` `），在文件中显示为普通空格但字节不同。**这会直接导致 Edit 工具的 `old_string` 匹配失败。** 翻译开始前必须先全局替换。

1. 用 Python 检查目标文件中是否包含 `\xa0` 字符：

   ```python
   with open(file, encoding='utf-8') as f:
       content = f.read()
   if '\xa0' in content:
       # 全局替换为普通空格
       content = content.replace('\xa0', ' ')
       with open(file, 'w', encoding='utf-8') as f:
           f.write(content)
   ```

2. 替换后重新读取文件，确认内容干净再开始翻译

> **注意**：每次 Edit 调用失败时，也应优先怀疑 NBSP 问题。可使用 `python3 -c "print(repr(line))"` 查看行内的隐藏字符。

### 第三步：逐段翻译

**核心规则：每次只翻译一个段落，使用 Edit 工具替换原文，完成一段后继续下一段，不要停。**

之后出现问题时才向用户确认

对每个待翻译的正文段落：

1. 使用 Edit 工具，匹配原文段落的精确文本
2. 将 `old_string` 设为**完整原文段落**（包含引用标记如 `$^{1}$`）
3. 将 `new_string` 设为：

```
原文段落（一字不动）

【译文】
中文翻译内容
```

> **注意**：【译文】后需要空一行再写翻译内容，确保 Markdown 渲染正常。

### 第四步：完成标记

所有正文段落翻译完成后，告知用户翻译进度。

## 翻译规范

### 术语处理
- 首次出现的核心术语保留英文原文：`信用分配（Credit Assignment）`
- 后续统一使用中文译名
- 人名、机构名保留原文

### 引用标记
- 保留原文中的 `$^{1}$`、`$^{1,2,3}$` 等引用标记，不加修改

### 数学符号
- LaTeX 数学表达式原样保留（如 `$\mathbf{d}_{\text{target}}$`）

### 翻译风格
- 学术论文风格，准确优先于流畅
- 长句可适当拆分，但保持原意
- 遇到不确定的术语，保留英文原文并用括号标注

## 示例

```
原文段落内容 here with $^{1,2}$ citations.

【译文】
原文的中文翻译，包含引用$^{1,2}$。
```

## 注意事项

1. **不可批量处理**：严格遵守每次只翻译一段的规则
2. **原文不动**：英文原文一字不删，翻译只是追加在其下方
3. **精准匹配**：使用 Edit 工具时确保 `old_string` 与文件中的文本完全一致（包括空白、引用）。**若 Edit 返回 "String to replace not found"，首先怀疑 NBSP 问题**——检查隐藏字符本质而非仅凭肉眼，使用 `python3 -c "print(repr(line))"` 查看 `\xa0` 等不可见字符
4. **跳过图片/表格**：遇到 `<img>` 标签、图表说明等非正文内容直接跳过
5. **尊重用户节奏**：每翻译一段后等待用户反馈再继续
6. **预处理 NBSP**：翻译前务必执行第二步的 NBSP 清理，这是保证后续 Edit 操作顺利的前提
