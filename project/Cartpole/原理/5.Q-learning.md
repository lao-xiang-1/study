## Q-learning（off-policy）
?
>这里是离线的算法。真实场景下，一般需要持续探索不同策略，而不是一开始就固定轨迹。

### 思路
>准备随机生成的轨迹（平均策略），更新每一步的动作价值

#### 初始化
1. 预先准备的轨迹需要很长，也就是大量数据。这样才能覆盖到每一种状态和动作。
2. 对每一种动作价值设定初始值 $q_0$ ，并设置学习率 $\alpha$

#### 更新值
对轨迹中的每一步：
$$q(s_t, a_t) = q(s_t, a_t) + \alpha_t\,\underbrace{\Big[\underbrace{r_{t} + \gamma \max_a q_t(s_{t+1}, a)}_{\text{TD 目标（target）}} - q(s_t, a_t)\Big]}_{\text{TD 误差 }\delta_t}$$

**参数说明**：
- $s_t$：第 $t$ 步的状态；$a_t$：在该状态采取的动作
- $s_{t+1}$：执行 $a_t$ 后转移到的下一个状态
- $r_t$：从 $s_t$ 经 $a_t$ 转移到 $s_{t+1}$ 所获得的**即时奖励（reward）**
- $q(s,a)$：对状态-动作对 $(s,a)$ 的**动作价值估计**
- $q(s_{t+1},a)$：下一状态 $s_{t+1}$ 各动作的当前估值，$\max_a$ 表示对其取最大
- $\alpha_t$：**学习率（步长）**，$0<\alpha_t\le 1$，控制单次更新的幅度；实践中常取固定值 $\alpha$，理论上随时间衰减可保证收敛
- $\gamma$：**折扣因子（discount factor）**，$0\le\gamma<1$，衡量未来奖励相对于即时奖励的重要程度
- **TD 目标（target）**：$r_t + \gamma\max_a q_t(s_{t+1},a)$，用一步回报加下一状态最优估值的**自举**（bootstrap）结果作为更新的目标
- **TD 误差 $\delta_t$**：目标与当前估值之差，$\delta_t = r_t + \gamma\max_a q_t(s_{t+1},a) - q(s_t,a_t)$，是驱动这次更新的信号

#### 更新目标策略
>值收敛后，取动作价值最大的作为目标策略（在迭代完成后进行）

$\pi_{T,t+1}(a|s_t) = 1$，其中 $a = \arg\max_a q_{t+1}(s_t, a)$
其余动作的概率为 0

### 完整算法（伪代码）

**输入**：一条很长的**轨迹（trajectory）** $\{(s_t,a_t,r_t,s_{t+1})\}$（由任意行为策略采样得到）、学习率 $\alpha_t$、折扣因子 $\gamma$、初值 $q_0$。

> 下文 `q[s][a]` 即 $q(s,a)$；`terminal(s_next)` 判断后继是否为终止状态。

```python
# Q-learning（off-policy）：在固定轨迹上反复做一步自举更新
q = {s: {a: q0 for a in actions(s)} for s in states}   # 初始化所有动作价值为 q_0

for (s, a, r, s_next) in trajectory:                   # 遍历轨迹中的每一步
    if terminal(s_next):
        target = r                                     # 终止状态无后继，目标就是即时奖励
    else:
        target = r + gamma * max(q[s_next].values())   # TD 目标：一步回报 + 自举的最优后继值
    q[s][a] += alpha * (target - q[s][a])              # 用 TD 误差驱动更新

# 收敛后（或每隔一段）提取目标策略
pi_T = {}
for s in states:
    pi_T[s] = argmax_a q[s][a]                         # 取动作价值最大的动作
```

**几点说明**：

- **off-policy**：更新用的是贪心目标 $\max_a q(s_{t+1},a)$，与产生轨迹的**行为策略（behavior policy）**无关，所以轨迹可以一次性随机生成并固定下来。
- **学习率含义**：第 $t$ 步的 $\alpha_t$ 即上式中的学习率；经典 Q-learning 要求 $\alpha_t$ 满足 $\sum_t\alpha_t=\infty$、$\sum_t\alpha_t^2<\infty$ 才保证收敛，实践中常用固定 $\alpha$。
- **终止条件**：当 $q$ 的最大变化量 $\max_{s,a}|target-q(s,a)|$ 小于阈值（或轨迹走到尽头）时停止迭代。
