**3.8 离散系统的系统函数，频率响应**

## 例题
**例** 已知系统初始状态为零，离散LSI系统的差分方程为
$$y(n) - \frac{3}{4}y(n-1) + \frac{1}{8}y(n-2) = x(n) + \frac{1}{3}x(n-1)$$

求：(1) 求系统函数，指出系统的零极点；
(2) 若该系统是因果稳定的，指出系统的ROC；
(3) 若系统是因果稳定的，求单位脉冲响应 $h(n)$


### (1) 求系统函数，指出系统的零极点

对差分方程两边取Z变换（初始状态为零）：
$$Y(z) - \frac{3}{4}z^{-1}Y(z) + \frac{1}{8}z^{-2}Y(z) = X(z) + \frac{1}{3}z^{-1}X(z)$$

提取公因式：
$$Y(z) \left[ 1 - \frac{3}{4}z^{-1} + \frac{1}{8}z^{-2} \right] = X(z) \left[ 1 + \frac{1}{3}z^{-1} \right]$$

**系统函数 $H(z)$** 为：
$$H(z) = \frac{Y(z)}{X(z)} = \frac{1 + \frac{1}{3}z^{-1}}{1 - \frac{3}{4}z^{-1} + \frac{1}{8}z^{-2}}$$

分子分母同乘 $z^2$ 以表示为正幂次：
$$H(z) = \frac{z^2 + \frac{1}{3}z}{z^2 - \frac{3}{4}z + \frac{1}{8}}$$

*   **求零点**：令分子为0，即 $z(z + \frac{1}{3}) = 0$
    系统的零点为：**$z_1 = 0$，$z_2 = -\frac{1}{3}$**
*   **求极点**：令分母为0，即 $z^2 - \frac{3}{4}z + \frac{1}{8} = 0$
    因式分解得：$(z - \frac{1}{2})(z - \frac{1}{4}) = 0$
    系统的极点为：**$p_1 = \frac{1}{2}$，$p_2 = \frac{1}{4}$**

---

### (2) 若该系统是因果稳定的，指出系统的ROC

*   **因果系统**要求收敛域（ROC）在模最大的极点之外，即 $|z| > \max(|p_1|, |p_2|) = \frac{1}{2}$。
*   **稳定系统**要求收敛域包含单位圆，即 $|z| = 1$ 必须在ROC内。由于 $1 > \frac{1}{2}$，所以该条件满足。

因此，若该系统是因果稳定的，**系统的收敛域（ROC）为 $|z| > \frac{1}{2}$**。

---

### (3) 若系统是因果稳定的，求单位脉冲响应 $h(n)$

对系统函数进行部分分式展开：
$$H(z) = \frac{1 + \frac{1}{3}z^{-1}}{(1 - \frac{1}{2}z^{-1})(1 - \frac{1}{4}z^{-1})} = \frac{A}{1 - \frac{1}{2}z^{-1}} + \frac{B}{1 - \frac{1}{4}z^{-1}}$$

通分并对比系数：
$A(1 - \frac{1}{4}z^{-1}) + B(1 - \frac{1}{2}z^{-1}) = 1 + \frac{1}{3}z^{-1}$

列出方程组：
1. $A + B = 1$
2. $-\frac{1}{4}A - \frac{1}{2}B = \frac{1}{3}$

将 $B = 1 - A$ 代入方程2：
$-\frac{1}{4}A - \frac{1}{2}(1 - A) = \frac{1}{3}$
$\frac{1}{4}A - \frac{1}{2} = \frac{1}{3}$
$\frac{1}{4}A = \frac{5}{6} \implies A = \frac{10}{3}$

因此，$B = 1 - \frac{10}{3} = -\frac{7}{3}$

所以：
$$H(z) = \frac{\frac{10}{3}}{1 - \frac{1}{2}z^{-1}} - \frac{\frac{7}{3}}{1 - \frac{1}{4}z^{-1}}$$

因为系统是因果的（ROC为 $|z| > \frac{1}{2}$），对应的逆Z变换为右边序列。
根据变换对 $a^n u(n) \leftrightarrow \frac{1}{1 - az^{-1}}$，可得出：

**单位脉冲响应 $h(n)$ 为：**
$$h(n) = \left[ \frac{10}{3}\left(\frac{1}{2}\right)^n - \frac{7}{3}\left(\frac{1}{4}\right)^n \right] u(n)$$
