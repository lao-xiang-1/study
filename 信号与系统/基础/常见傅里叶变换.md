### 常见连续时间傅里叶变换对

下表总结了信号与系统中最常用的一些傅里叶变换对：

| 时域信号 $f(t)$                                       | 频域信号 $F(j\omega)$                                             | 备注说明                                                            |                             |        |
| ------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------- | ------ |
| $\delta(t)$                                       | $1$                                                           | 单位冲激信号具有均匀的连续全频带频谱                                              |                             |        |
| $1$                                               | $2\pi\delta(\omega)$                                          | 直流信号的频谱集中在零频                                                    |                             |        |
| $\delta(t - t_0)$                                 | $e^{-j\omega t_0}$                                            | 冲激信号的时移（相频特性产生线性变化）                                             |                             |        |
| $e^{j\omega_0 t}$                                 | $2\pi\delta(\omega - \omega_0)$                               | 频移性质的直接体现                                                       |                             |        |
| $\cos(\omega_0 t)$                                | $\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$  | 包含正负两个频率成分                                                      |                             |        |
| $\sin(\omega_0 t)$                                | $j\pi[\delta(\omega + \omega_0) - \delta(\omega - \omega_0)]$ | 注意虚数单位 $j$ 和符号                                                  |                             |        |
| $\text{sgn}(t)$                                   | $\frac{2}{j\omega}$                                           | 符号函数，纯虚数奇函数频谱                                                   |                             |        |
| $u(t)$                                            | $\pi\delta(\omega) + \frac{1}{j\omega}$                       | 单位阶跃信号（包含直流分量和交流分量）                                             |                             |        |
| $e^{-at}u(t) \quad (a > 0)$                       | $\frac{1}{a + j\omega}$                                       | 单边指数衰减信号                                                        |                             |        |
| $t e^{-at}u(t) \quad (a > 0)$                     | $\frac{1}{(a + j\omega)^2}$                                   | 频域微分性质的应用                                                       |                             |        |
| $e^{-a                                            | t                                                             | } \quad (a > 0)$                                                | $\frac{2a}{a^2 + \omega^2}$ | 双边指数信号 |
| 矩形脉冲 （门信号）$G_\tau(t)$                             | $\tau \text{Sa}(\frac{\omega \tau}{2})$                       | 脉宽为 $\tau$ 且关于 $t=0$ 对称的矩形窗。注：$\text{Sa}(x) = \frac{\sin x}{x}$ |                             |        |
| 抽样函数 $\frac{\omega_c}{\pi} \text{Sa}(\omega_c t)$ | $G_{2\omega_c}(\omega)$                                       | 频带宽度为 $2\omega_c$ 的理想低通滤波器冲激响应（对称性质）                            |                             |        |
| 高斯脉冲 $e^{-at^2} \quad (a > 0)$                    | $\sqrt{\frac{\pi}{a}} e^{-\frac{\omega^2}{4a}}$               | 高斯函数的傅里叶变换仍然是高斯函数                                               |                             |        |

### 记忆建议：
- **对称规律**：矩形脉冲与 $\text{Sa}$ 函数是一对“黄金搭档”。时域是矩形，频域就是 $\text{Sa}$ 函数；时域是 $\text{Sa}$ 函数，频域就是矩形（体现了傅里叶变换的对称性质）。
- **微积分规律**：含有 $u(t)$ 的通常会在分母出现 $j\omega$，这是因为 $u(t)$ 相当于积分操作；而带有直流偏置的信号通常会产生冲激 $\delta(\omega)$。
- **欧拉公式**：正余弦信号的傅里叶变换可以直接通过欧拉公式 $e^{\pm j\omega_0 t}$ 结合 $1 \leftrightarrow 2\pi\delta(\omega)$ 推导出来，无需死记硬背。



**门信号**（Gate Signal），通常也称为**矩形脉冲信号**（Rectangular Pulse）或**窗函数**。其实在上一条回复的表格中已经提到过（即“矩形脉冲 $G_\tau(t)$”），这里为您详细展开一下。

设门信号为 $g_\tau(t)$，其脉冲宽度为 $\tau$，幅度为 $E$（为方便起见通常取 $E=1$），数学定义为：
$$
g_\tau(t) = \begin{cases} 
1, & |t| < \frac{\tau}{2} \\
0, & |t| > \frac{\tau}{2} 
\end{cases}
$$

### 傅里叶变换对
门信号的傅里叶变换为采样函数（$\text{Sa}$ 函数或 $\text{Sinc}$ 函数）：
$$
g_\tau(t) \quad \longleftrightarrow \quad \tau \text{Sa}\left(\frac{\omega \tau}{2}\right)
$$
*(注：其中 $\text{Sa}(x) = \frac{\sin x}{x}$)*

### 简单推导过程
根据傅里叶变换的定义，直接对门信号进行积分：
$$
\begin{aligned}
F(\omega) &= \int_{-\infty}^{\infty} g_\tau(t) e^{-j\omega t} dt \\
&= \int_{-\tau/2}^{\tau/2} 1 \cdot e^{-j\omega t} dt \\
&= \frac{1}{-j\omega} \left[ e^{-j\omega t} \right]_{-\tau/2}^{\tau/2} \\
&= \frac{e^{-j\omega \tau/2} - e^{j\omega \tau/2}}{-j\omega} \\
&= \frac{2 \sin(\frac{\omega \tau}{2})}{\omega} \\
&= \tau \frac{\sin(\frac{\omega \tau}{2})}{\frac{\omega \tau}{2}} \\
&= \tau \text{Sa}\left(\frac{\omega \tau}{2}\right)
\end{aligned}
$$

### 门信号的几个重要物理结论：
1. **零点位置**：频域图像 $F(\omega)$ 第一次过零点的位置出现在 $\frac{\omega \tau}{2} = \pi$ 处，即 **$\omega = \frac{2\pi}{\tau}$**。
2. **时频展缩特性（测不准原理）**：时域脉宽 $\tau$ 越窄（信号持续时间越短），频域第一次过零点的频率 $\frac{2\pi}{\tau}$ 就越大，频带越宽；反之，时域脉冲越宽，频带越窄。
3. **对称性**：它与表格中提到的“抽样函数 $\text{Sa}(\omega_c t)$ 对应 频域的矩形门”是一对**对偶关系**。
