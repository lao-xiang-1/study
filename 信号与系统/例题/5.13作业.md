
## 题1
![406](信号与系统/例题/assets/Pasted%20image%2020260518210647.jpg)

根据图片中的公式，我们需要求以下函数的傅里叶逆变换：

$F(j\Omega) = \frac{\sin[3(\Omega-2\pi)]}{\Omega-2\pi}$

我们可以通过**基本傅里叶变换对**和**频移性质**来求解。具体步骤如下：

### 1. 识别基本变换对
首先，考虑不带频移的基础形式：
$X(j\Omega) = \frac{\sin(3\Omega)}{\Omega}$

我们知道，幅度为 $E$、宽度为 $\tau$ 的矩形脉冲信号 $x(t) = E \cdot \text{rect}(\frac{t}{\tau})$（即在 $|t| < \frac{\tau}{2}$ 时为 $E$，其余为 0），其傅里叶变换为：
$\mathcal{F}[x(t)] = E\tau \frac{\sin(\Omega \tau / 2)}{\Omega \tau / 2} = \frac{2E \sin(\Omega \tau / 2)}{\Omega}$

对比 $X(j\Omega) = \frac{\sin(3\Omega)}{\Omega}$：
- $\tau / 2 = 3 \implies \tau = 6$
- $2E = 1 \implies E = \frac{1}{2}$

所以 $X(j\Omega)$ 对应的时域信号为：
$$x(t) = \begin{cases} 
\frac{1}{2}, & |t| < 3 \\ 
0, & |t| > 3 
\end{cases}$$
（也可以写为 $\frac{1}{2} [u(t+3) - u(t-3)]$）

### 2. 应用频移性质
根据傅里叶变换的频移性质：
$x(t)e^{j\Omega_0 t} \stackrel{\mathcal{F}}{\longleftrightarrow} X(j(\Omega - \Omega_0))$

原函数 $F(j\Omega)$ 中含有 $\Omega - 2\pi$，说明在频域发生了右移，即 $\Omega_0 = 2\pi$。

### 3. 得出最终结果
将频移应用到时域信号上，只需给 $x(t)$ 乘上 $e^{j2\pi t}$：

$$f(t) = x(t)e^{j2\pi t} = \begin{cases} 
\frac{1}{2} e^{j2\pi t}, & |t| < 3 \\ 
0, & |t| > 3 
\end{cases}$$

**也可以用阶跃函数写成更紧凑的形式：**
$f(t) = \frac{1}{2} [u(t+3) - u(t-3)] e^{j2\pi t}$

### 第一步：求 $f_0(t)$ 的傅里叶变换 $F(j\Omega)$
**？有无简略方法**
从图(a)可以看出，单脉冲信号 $f_0(t)$ 的数学表达式为：
$f_0(t) = \begin{cases} t, & 0 \le t \le 1 \\ 0, & \text{其他} \end{cases}$

根据傅里叶变换的定义式：
$F(j\Omega) = \int_{-\infty}^{\infty} f_0(t) e^{-j\Omega t} dt = \int_{0}^{1} t e^{-j\Omega t} dt$

使用分部积分法求解：
$\int_{0}^{1} t e^{-j\Omega t} dt = \left[ t \cdot \frac{e^{-j\Omega t}}{-j\Omega} \right]_0^1 - \int_{0}^{1} \frac{e^{-j\Omega t}}{-j\Omega} dt$
$= -\frac{1}{j\Omega} e^{-j\Omega} + \frac{1}{j\Omega} \left[ \frac{e^{-j\Omega t}}{-j\Omega} \right]_0^1$
$= -\frac{1}{j\Omega} e^{-j\Omega} - \frac{1}{(j\Omega)^2} (e^{-j\Omega} - 1)$

因为 $(j\Omega)^2 = -\Omega^2$，代入化简得：
$F(j\Omega) = \frac{e^{-j\Omega} - 1 + j\Omega e^{-j\Omega}}{\Omega^2}$

### 第二步：求周期信号 $f(t)$ 的傅里叶级数 $F_n$

从图(b)可以看出，周期信号 $f(t)$ 是由 $f_0(t)$ 周期延拓得到的。
信号的周期为 $T = 2$，因此基频为 $\Omega_0 = \frac{2\pi}{T} = \pi$。

根据理论，周期信号的傅里叶级数系数 $F_n$ 与其单周期截断信号的傅里叶变换 $F(j\Omega)$ 之间的关系为：
$F_n = \frac{1}{T} F(j n \Omega_0)$

将 $T = 2$ 和 $\Omega_0 = \pi$ 代入，得到：
$F_n = \frac{1}{2} F(j n \pi)$

把 $F(j\Omega) = \frac{e^{-j\Omega} - 1 + j\Omega e^{-j\Omega}}{\Omega^2}$ 中 $\Omega = n\pi$ 代入（当 $n \neq 0$ 时）：
$F_n = \frac{1}{2} \cdot \frac{e^{-jn\pi} - 1 + jn\pi e^{-jn\pi}}{(n\pi)^2}$

利用欧拉公式性质，我们知道 $e^{-jn\pi} = \cos(n\pi) - j\sin(n\pi) = (-1)^n$，代入上式化简：
$F_n = \frac{(-1)^n - 1 + jn\pi (-1)^n}{2 n^2 \pi^2} \quad (n \neq 0)$

**当 $n = 0$ 时（即直流分量）**，可以直接通过计算平均值得到（这部分计算不受前面化简符号影响）：
$F_0 = \frac{1}{T} \int_{0}^{T} f(t) dt = \frac{1}{2} \int_{0}^{1} t dt = \frac{1}{2} \left[ \frac{1}{2}t^2 \right]_0^1 = \frac{1}{4}$

### 最终结论
周期信号 $f(t)$ 的傅里叶级数系数为：
$F_n = \begin{cases} \frac{1}{4}, & n = 0 \\ \frac{(-1)^n - 1 + jn\pi (-1)^n}{2 n^2 \pi^2}, & n \neq 0 \end{cases}$

**求出来的只是系数，怎么转换为傅里叶级数，自己想！**


## 题3
![](信号与系统/例题/assets/5.13作业.jpg)

### 已知条件：
系统的微分方程为：$y''(t) + 4y'(t) + 3y(t) = f(t)$

---

### (1) 求系统的频率响应 $H(j\Omega)$ 和冲激响应 $h(t)$

**1. 求频率响应 $H(j\Omega)$**
对微分方程两边同时取傅里叶变换。根据傅里叶变换的微分性质 $\mathcal{F}[y^{(n)}(t)] = (j\Omega)^n Y(j\Omega)$，我们得到：
$$(j\Omega)^2 Y(j\Omega) + 4(j\Omega)Y(j\Omega) + 3Y(j\Omega) = F(j\Omega)$$

提取公因式 $Y(j\Omega)$：
$$[(j\Omega)^2 + 4j\Omega + 3] Y(j\Omega) = F(j\Omega)$$

系统的频率响应 $H(j\Omega)$ 定义为输出频谱与输入频谱之比：
$$H(j\Omega) = \frac{Y(j\Omega)}{F(j\Omega)} = \frac{1}{(j\Omega)^2 + 4j\Omega + 3}$$

对分母进行因式分解：
$$H(j\Omega) = \frac{1}{(j\Omega + 1)(j\Omega + 3)}$$

**2. 求冲激响应 $h(t)$**
为了求傅里叶逆变换，我们需要将 $H(j\Omega)$ 展开为部分分式：
$$\frac{1}{(j\Omega + 1)(j\Omega + 3)} = \frac{A}{j\Omega + 1} + \frac{B}{j\Omega + 3}$$
通过通分求解 $A$ 和 $B$：
$$A(j\Omega + 3) + B(j\Omega + 1) = 1$$
- 令 $j\Omega = -1$，得 $2A = 1 \implies A = \frac{1}{2}$
- 令 $j\Omega = -3$，得 $-2B = 1 \implies B = -\frac{1}{2}$

所以：
$$H(j\Omega) = \frac{1/2}{j\Omega + 1} - \frac{1/2}{j\Omega + 3}$$

根据常用傅里叶变换对 $\mathcal{F}^{-1}\left[\frac{1}{j\Omega + a}\right] = e^{-at}U(t)$，对其求傅里叶逆变换，得到冲激响应：
$$h(t) = \frac{1}{2}e^{-t}U(t) - \frac{1}{2}e^{-3t}U(t)$$

---

### (2) 若激励 $f(t) = e^{-2t}U(t)$，求系统的零状态响应 $y_f(t)$

**1. 求解输入信号的频域表达式**
已知激励 $f(t) = e^{-2t}U(t)$，对其求傅里叶变换：
$$F(j\Omega) = \frac{1}{j\Omega + 2}$$

**2. 求解输出的频域表达式 $Y_f(j\Omega)$**
根据频域乘积定理，零状态响应的频谱为：
$$Y_f(j\Omega) = H(j\Omega) F(j\Omega)$$
代入已知表达式：
$$Y_f(j\Omega) = \frac{1}{(j\Omega + 1)(j\Omega + 3)} \cdot \frac{1}{j\Omega + 2} = \frac{1}{(j\Omega + 1)(j\Omega + 2)(j\Omega + 3)}$$

**3. 部分分式展开求逆变换**
将 $Y_f(j\Omega)$ 展开为三个部分分式：
$$Y_f(j\Omega) = \frac{A}{j\Omega + 1} + \frac{B}{j\Omega + 2} + \frac{C}{j\Omega + 3}$$

使用留数法（遮挡法）快速求解常数：
- $A = \left. \frac{1}{(j\Omega + 2)(j\Omega + 3)} \right|_{j\Omega = -1} = \frac{1}{(1)(2)} = \frac{1}{2}$
- $B = \left. \frac{1}{(j\Omega + 1)(j\Omega + 3)} \right|_{j\Omega = -2} = \frac{1}{(-1)(1)} = -1$
- $C = \left. \frac{1}{(j\Omega + 1)(j\Omega + 2)} \right|_{j\Omega = -3} = \frac{1}{(-2)(-1)} = \frac{1}{2}$

因此：
$$Y_f(j\Omega) = \frac{1/2}{j\Omega + 1} - \frac{1}{j\Omega + 2} + \frac{1/2}{j\Omega + 3}$$

最后，对每一项求傅里叶逆变换，得到系统的零状态响应：
$$y_f(t) = \left( \frac{1}{2}e^{-t} - e^{-2t} + \frac{1}{2}e^{-3t} \right) U(t)$$

## 题4
![](信号与系统/例题/assets/5.13作业-1.jpg)

### 已知条件
- 系统微分方程：$y''(t) + 3y'(t) + 2y(t) = f(t)$
- 激励信号：$f(t) = -2e^{-t}U(t)$
- 初始状态：$y(0^-) = 1, y'(0^-) = 2$

==这里使用**拉普拉斯变换**（单边拉普拉斯变换）来求解，因为它非常方便。当然老师可能用的是傅里叶变换，甚至是时域内求解，需自行抉择==

---

### 第一步：对微分方程两端取单边拉普拉斯变换

根据拉普拉斯变换的微分性质：
- $\mathcal{L}[y(t)] = Y(s)$
- $\mathcal{L}[y'(t)] = sY(s) - y(0^-)$
- $\mathcal{L}[y''(t)] = s^2Y(s) - sy(0^-) - y'(0^-)$

将上述式子和初始状态 $y(0^-) = 1, y'(0^-) = 2$ 代入微分方程：
$$[s^2Y(s) - s(1) - 2] + 3[sY(s) - 1] + 2Y(s) = F(s)$$

整理并合并同类项：
$$s^2Y(s) - s - 2 + 3sY(s) - 3 + 2Y(s) = F(s)$$
$$(s^2 + 3s + 2)Y(s) - (s + 5) = F(s)$$

将其化简为 $Y(s)$ 的表达式：
$$(s^2 + 3s + 2)Y(s) = (s + 5) + F(s)$$
$$Y(s) = \underbrace{\frac{s + 5}{s^2 + 3s + 2}}_{Y_{zi}(s) \text{ 零输入响应频域}} + \underbrace{\frac{F(s)}{s^2 + 3s + 2}}_{Y_{zs}(s) \text{ 零状态响应频域}}$$

---

### 第二步：求零输入响应 $y_{zi}(t)$

零输入响应对应的部分为 $Y_{zi}(s)$：
$$Y_{zi}(s) = \frac{s + 5}{s^2 + 3s + 2} = \frac{s + 5}{(s + 1)(s + 2)}$$

对其进行部分分式展开：
$$Y_{zi}(s) = \frac{A}{s + 1} + \frac{B}{s + 2}$$
利用留数法求解待定系数：
- $A = \left. \frac{s + 5}{s + 2} \right|_{s = -1} = \frac{-1 + 5}{-1 + 2} = 4$
- $B = \left. \frac{s + 5}{s + 1} \right|_{s = -2} = \frac{-2 + 5}{-2 + 1} = \frac{3}{-1} = -3$

因此：
$$Y_{zi}(s) = \frac{4}{s + 1} - \frac{3}{s + 2}$$

对上式求拉普拉斯逆变换，得到**零输入响应**：
$$y_{zi}(t) = (4e^{-t} - 3e^{-2t})U(t)$$

---

### 第三步：求零状态响应 $y_{zs}(t)$

首先求出激励信号 $f(t) = -2e^{-t}U(t)$ 的拉普拉斯变换：
$$F(s) = \frac{-2}{s + 1}$$

将 $F(s)$ 代入零状态响应的表达式 $Y_{zs}(s)$ 中：
$$Y_{zs}(s) = \frac{F(s)}{(s + 1)(s + 2)} = \frac{-2}{(s + 1)^2(s + 2)}$$

因为分母中含有重根 $(s+1)^2$，我们将其展开为以下部分分式：
$$Y_{zs}(s) = \frac{K_1}{(s + 1)^2} + \frac{K_2}{s + 1} + \frac{K_3}{s + 2}$$

求解待定系数：
- $K_1$ (重根最高次项)：$K_1 = \left. \frac{-2}{s + 2} \right|_{s = -1} = \frac{-2}{-1 + 2} = -2$
- $K_3$ (单根项)：$K_3 = \left. \frac{-2}{(s + 1)^2} \right|_{s = -2} = \frac{-2}{(-2 + 1)^2} = -2$
- 求解 $K_2$：可以在等式两边同乘 $s$ 并令 $s \to \infty$，得到 $0 = K_2 + K_3$，所以 $K_2 = -K_3 = 2$。

这里可查看笔记：[留数法](信号与系统/attach_md/留数法.md)

因此：
$$Y_{zs}(s) = \frac{-2}{(s + 1)^2} + \frac{2}{s + 1} - \frac{2}{s + 2}$$

利用常用的逆变换对 $\mathcal{L}^{-1}\left[\frac{1}{(s+a)^2}\right] = t e^{-at}U(t)$ 和 $\mathcal{L}^{-1}\left[\frac{1}{s+a}\right] = e^{-at}U(t)$，求得**零状态响应**：
$$y_{zs}(t) = (-2te^{-t} + 2e^{-t} - 2e^{-2t})U(t)$$

---

### 第四步：求全响应 $y(t)$

全响应等于零输入响应与零状态响应之和：
$$y(t) = y_{zi}(t) + y_{zs}(t)$$
$$y(t) = (4e^{-t} - 3e^{-2t})U(t) + (-2te^{-t} + 2e^{-t} - 2e^{-2t})U(t)$$

合并同类项，得到最终的**全响应**：
$$y(t) = (6e^{-t} - 5e^{-2t} - 2te^{-t})U(t)$$

这是一道求解线性时不变（LTI）系统稳态响应的经典题目。我们可以通过系统的频率响应函数 $H(j\omega)$ 来分别计算不同频率分量下的响应，然后利用叠加定理求和。

以下是画圈题目（第2小题）的详细解答步骤：

**题目：**
已知系统微分方程为 $y'(t) + 2y(t) = -f'(t) + 2f(t)$，激励信号 $f(t) = \cos(2t) + 3$。求系统的稳态响应。

==这里用拉普拉斯变换计算复杂，使用傅里叶变换==

### 1. 求系统的频率响应函数 $H(j\omega)$
对方程两边进行傅里叶变换（或令 $s = j\omega$ 代入系统函数）：
$$j\omega Y(j\omega) + 2Y(j\omega) = -j\omega F(j\omega) + 2F(j\omega)$$
提取公因式：
$$Y(j\omega)(j\omega + 2) = F(j\omega)(2 - j\omega)$$
由此可得系统的频率响应函数为：
$$H(j\omega) = \frac{Y(j\omega)}{F(j\omega)} = \frac{2 - j\omega}{2 + j\omega}$$

### 2. 分解激励信号并计算各分量的响应
激励信号 $f(t) = 3 + \cos(2t)$ 可以看作是由直流分量（$\omega = 0$）和交流分量（$\omega = 2$）组成的。我们分别计算这两部分的响应。

**① 直流分量：$f_1(t) = 3$ （此时频率 $\omega = 0$）**
将 $\omega = 0$ 代入 $H(j\omega)$：
$$H(j0) = \frac{2 - j0}{2 + j0} = \frac{2}{2} = 1$$
所以，直流分量引起的稳态响应为：
$$y_{ss1}(t) = 3 \times H(j0) = 3 \times 1 = 3$$

**② 交流分量：$f_2(t) = \cos(2t)$ （此时频率 $\omega = 2$）**
将 $\omega = 2$ 代入 $H(j\omega)$：
$$H(j2) = \frac{2 - j2}{2 + j2}$$
为了求出其幅度和相位，我们进行复数化简（分子分母同乘共轭复数）：
$$H(j2) = \frac{(2 - j2)^2}{(2 + j2)(2 - j2)} = \frac{4 - j8 - 4}{2^2 + 2^2} = \frac{-j8}{8} = -j$$
复数 $-j$ 可以表示为极坐标形式：
*   幅度 $|H(j2)| = 1$
*   相位 $\angle H(j2) = -\frac{\pi}{2}$

所以，交流分量引起的稳态响应为：
$$y_{ss2}(t) = 1 \times \cos\left(2t - \frac{\pi}{2}\right) = \sin(2t)$$

### 3. 叠加求全响应
根据线性系统的叠加定理，系统的总稳态响应 $y_{ss}(t)$ 等于各分量响应之和：
$$y_{ss}(t) = y_{ss1}(t) + y_{ss2}(t)$$
$$y_{ss}(t) = 3 + \sin(2t)$$

**最终答案：**
系统的稳态响应为 **$y_{ss}(t) = \sin(2t) + 3$** （或写为 $3 + \cos(2t - \frac{\pi}{2})$）。
