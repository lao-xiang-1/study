# 数据存储器 (RAM)

## 一、 基本概念
随机存取存储器（Random Access Memory, RAM）主要用于存放微机运行时的程序、数据及中间结果。
- **特点**：可以随机进行读/写操作，读写速度快，但**断电后数据会丢失**（易失性存储器）。
- **作用**：作为计算机的主存（内存）或高速缓存（Cache）。

## 二、 RAM 的分类
根据存储单元工作原理的不同，RAM 主要分为两大类：SRAM 和 DRAM。

| 特性 | SRAM (静态 RAM) | DRAM (动态 RAM) |
| --- | --- | --- |
| **存储原理** | 触发器 (双稳态电路) | 电容充放电 |
| **刷新** | 不需要 | **需要定期刷新** |
| **集成度** | 低（每个单元需4-6个晶体管） | 高（每个单元仅需1个晶体管+1个电容） |
| **存取速度** | 快 | 较慢 |
| **功耗** | 较大 | 较小 |
| **成本** | 高 | 低 |
| **典型应用** | 高速缓存 (Cache) | 微机主存 (内存条) |

## 三、 RAM 芯片的基本结构
一个典型的 RAM 芯片内部主要包括以下几个部分：
- **存储矩阵**：由许多存储单元排列成行和列组成，用于存放数据。
- **地址译码器**：将 CPU 传来的地址信号转换成选中某特定存储单元的控制信号。通常分为行译码和列译码。
- **控制逻辑电路**：接收 CPU 的控制信号，产生芯片内部的读/写和工作时序。常见的控制引脚有：
  - 片选信号 ($\overline{CS}$ 或 $\overline{CE}$)：低电平有效，用于选中当前芯片。
  - 读信号 ($\overline{OE}$ 或 $\overline{RD}$)：低电平有效，允许数据输出。
  - 写信号 ($\overline{WE}$ 或 $\overline{WR}$)：低电平有效，允许数据写入。
- **数据缓冲器**：作为芯片内部数据总线与外部数据总线的接口。

## 四、 存储器的扩展技术 (考试重点)
在微机系统中，单片 RAM 的容量和字长往往不能满足实际需求，需要将多片 RAM 组合起来与系统总线连接，称为存储器扩展。

### 1. 位扩展 (扩展字长)
- **适用场景**：芯片字数（容量）够了，但数据位数（字长）不够。例如：用 8K $\times$ 4位的芯片组成 8K $\times$ 8位的存储器。
- **连接方法**：
  - 地址线：全部并联接入系统的低位地址线。
  - 控制线：片选信号 $\overline{CS}$ 和读写信号并联。
  - 数据线：各芯片的数据线分别接到系统数据总线的不同位上（如芯片A接 $D_0 \sim D_3$，芯片B接 $D_4 \sim D_7$）。

### 2. 字扩展 (扩展容量)
- **适用场景**：芯片数据位数（字长）够了，但字数（容量）不够。例如：用 8K $\times$ 8位的芯片组成 32K $\times$ 8位的存储器。
- **连接方法**：
  - 地址线：片内地址线并联接到系统的低位地址线。
  - 数据线：并联接到系统数据总线。
  - 控制线：读写信号并联；**系统的高位地址线通过译码器（如 74LS138）产生片选信号 $\overline{CS}$，分别接到各芯片上**（保证同一时刻只有一片工作）。

### 3. 字位同时扩展
- **适用场景**：字数和位数都不够。例如：用 16K $\times$ 4位的芯片组成 64K $\times$ 8位的存储器。
- **连接方法**：先进行位扩展（将两片 16K $\times$ 4位组合成一组 16K $\times$ 8位），再将分组进行字扩展。

# 8051单片机存储器地址分配

8051 单片机采用**哈佛架构**，程序存储器 (ROM) 和数据存储器 (RAM) 在物理上和逻辑上都是分开的。总共分为三个独立的存储空间：**片内外统一编址的ROM**、**片内RAM**、**片外扩展RAM**。

## 一、 程序存储器 (ROM / Flash)
用于存放程序代码和常数，容量最大可寻址 **64KB**，地址范围：`0000H ~ FFFFH`。

- **0000H**：单片机复位后的程序入口地址。
- **0003H ~ 0023H**：中断向量区（存放各个中断服务程序的入口地址）。
  - `0003H`：外部中断 0
  - `000BH`：定时器 0 溢出中断
  - `0013H`：外部中断 1
  - `001BH`：定时器 1 溢出中断
  - `0023H`：串口中断
- **内外ROM的选择**：由引脚 $\overline{EA}$ 决定。
  - $\overline{EA} = 1$：先执行片内 ROM 程序，超出片内容量后再自动跳到片外 ROM。
  - $\overline{EA} = 0$：强制只执行片外扩展 ROM 中的程序。

## 二、 数据存储器 (RAM)
用于存放程序运行时的临时数据、标志位和堆栈。分为**片内 RAM**和**片外扩展 RAM**。

### 1. 片外数据存储器 (External RAM)
- **容量**：最大可扩展 **64KB**。
- **地址范围**：`0000H ~ FFFFH`。
- **说明**：虽然地址空间与 ROM 重叠，但在硬件上，访问片外 RAM 时 CPU 会自动产生 $\overline{RD}$ (读) 或 $\overline{WR}$ (写) 信号，而不是 $\overline{PSEN}$ 信号（读ROM专用），从而区分开来。

### 2. 片内数据存储器 (Internal RAM) - 核心重点
标准 8051 片内 RAM 共有 **256 字节**，分为两大部分：**低 128 字节** 和 **高 128 字节 (SFR)**。

| 区域 | 地址范围 | 功能描述 | 寻址方式 |
| --- | --- | --- | --- |
| **工作寄存器区** | `00H ~ 1FH` | 共 32 字节，分为 4 个寄存器组（Bank 0 ~ Bank 3）。每组包含 8 个工作寄存器 R0~R7。通过修改 PSW 寄存器可切换当前使用的 Bank。 | 直接寻址、寄存器寻址 |
| **位寻址区** | `20H ~ 2FH` | 共 16 字节（16 $\times$ 8 = 128 位）。这 128 个比特位都有独立的位地址（`00H ~ 7FH`），可以直接对单独的一位（bit）进行清零或置位。 | 直接寻址、位寻址 |
| **通用RAM区/堆栈区** | `30H ~ 7FH` | 共 80 字节。通常用作用户数据缓冲区。系统复位后，堆栈指针 SP 的初始值为 `07H`，但通常会在程序初始化时将 SP 移到 `30H` 以上，以避免与寄存器区和位寻址区冲突。 | 直接寻址、间接寻址 |
| **特殊功能寄存器 (SFR)** | `80H ~ FFH` | **高 128 字节**。存放着控制单片机各大部件（如定时器、串口、I/O口、中断系统等）的核心寄存器（如 ACC, B, PSW, P0~P3 等）。**注意：这部分物理上是不连续的，只有被定义的地址才有效。** | **只能直接寻址** |

*(注：对于 8052 单片机，内部增加了额外的 128 字节 RAM，地址也是 `80H ~ FFH`，但它与 SFR 区的区别在于：访问额外的 RAM 只能用**间接寻址**，访问 SFR 只能用**直接寻址**。)*

## 三、 存储器访问指令总结 (区分三大空间的钥匙)

汇编语言中，通过不同的指令前缀或后缀来明确要访问哪个存储器：

1. **访问片内 RAM**：使用 `MOV` 指令。
   - `MOV A, 30H` (将片内RAM 30H处的数据送到累加器A)
2. **访问片外 RAM**：使用 `MOVX` 指令 (X 代表 eXternal)。必须借助 DPTR 或 R0/R1 间接寻址。
   - `MOVX A, @DPTR` (读取片外扩展 RAM 的数据)
3. **访问程序存储器 ROM**：使用 `MOVC` 指令 (C 代表 Code)。通常用于查表操作。
   - `MOVC A, @A+DPTR` (读取 ROM 里的表格常数)
