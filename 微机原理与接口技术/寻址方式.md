#review 

51单片机（基于MCS-51架构）共有 **7种** 主要的寻址方式。寻址方式是指寻找操作数（数据）或指令执行地址的方法。理解这些寻址方式对于编写和优化51单片机汇编语言程序至关重要。

以下是这7种寻址方式的详细介绍及示例：

---

### 1. 立即寻址 (Immediate Addressing)
操作数直接写在指令中，它紧跟在操作码后面，存放在程序存储器（ROM）中。
* **特点**：操作数前必须加井号 `#`，以示与内存地址的区别。
* **寻址范围**：常数、立即数。
* **示例**：
  ```assembly
  MOV A, #20H    ; 将十六进制数 20H 送入累加器 A
  MOV DPTR, #1234H ; 将 16 位立即数 1234H 送入数据指针 DPTR
  ```

### 2. 直接寻址 (Direct Addressing)
指令中直接给出操作数所在的内存地址。
* **特点**：指令中直接写出地址数值或其定义的符号，没有 `#` 号。
* **寻址范围**：
  * 内部 RAM 的低 128 字节（00H ~ 7FH）。
  * 特殊功能寄存器（SFR，80H ~ FFH）。
* **示例**：
  ```assembly
  MOV A, 30H    ; 将内部 RAM 地址为 30H 的单元中的内容送入累加器 A
  MOV P1, A     ; 将 A 的内容送入 P1 端口（P1 是特殊功能寄存器，地址为 90H）
  ```

### 3. 寄存器寻址 (Register Addressing)
操作数存放在指定的寄存器中。
* **特点**：指令中直接指出寄存器的名称。
* **寻址范围**：通用寄存器 R0 ~ R7、累加器 A、双字节寄存器 B、数据指针 DPTR 等。
* **示例**：
  ```assembly
  MOV A, R5     ; 将寄存器 R5 中的内容送入累加器 A
  ADD A, R2     ; 将 A 与 R2 中的内容相加，结果存回 A
  ```

### 4. 寄存器间接寻址 (Register Indirect Addressing)
寄存器中存放的不是操作数本身，而是操作数所在的内存地址（即寄存器作为指针）。
* **特点**：在寄存器前加前缀 `@`。
* **寻址范围**：
  * **内部 RAM**：只能使用工作寄存器 **R0** 或 **R1** 进行间接寻址（访问低 128 字节，在 8052 等芯片中也可访问高 128 字节）。
  * **外部 RAM**：使用 **DPTR**（16位地址）或 **R0/R1**（8位地址，配合P2口）进行间接寻址。
* **示例**：
  ```assembly
  MOV A, @R0    ; 将 R0 指向的内部 RAM 单元中的内容送入 A
  MOVX A, @DPTR ; 将 DPTR 指向的外部 RAM 单元中的内容送入 A（注意使用 MOVX 指令）
  ```

### 5. 基址寄存器加变址寄存器间接寻址 / 变址寻址 (Indexed Addressing)
这种寻址方式专门用于读取程序存储器（ROM）中的数据（如常数表、字符点阵等）。
* **特点**：它以双字节寄存器（DPTR 或 PC）作为基址寄存器，以累加器 A 作为变址寄存器。两者相加的结果作为实际的数据地址。
* **指令限制**：只能使用 `MOVC` 指令，且 A 必须作为变址寄存器。
* **示例**：
  ```assembly
  MOVC A, @A+DPTR ; 将（A + DPTR）所指向的 ROM 单元中的数据送入 A
  MOVC A, @A+PC   ; 将（A + PC）所指向的 ROM 单元中的数据送入 A
  ```

### 6. 相对寻址 (Relative Addressing)
主要用于程序转移指令。它以当前程序计数器 PC 的值作为基准，加上指令中给出的 8 位带符号相对偏移量（rel），计算出实际的目标转移地址。
* **特点**：偏移量是一个带符号的 8 位二进制数，范围是 $-128$ 到 $+127$（即向后最多跳转 128 字节，向前最多跳转 127 字节）。在编写汇编代码时，程序员通常直接写目标标号，编译器会自动计算偏移量。
* **示例**：
  ```assembly
  JC LOOP       ; 如果进位标志 Cy = 1，则跳转到标号 LOOP 处执行
  SJMP BACK     ; 无条件相对跳转到标号 BACK 处执行
  ```

### 7. 位寻址 (Bit Addressing)
51单片机具有强大的位操作功能，位寻址就是对内部 RAM 或 SFR 中某个特定“位”进行读写或逻辑操作。
* **寻址范围**：
  * 内部 RAM 的位寻址区（20H ~ 2FH 单元，共 128 个可寻址位，位地址为 00H ~ 7FH）。
  * 具有位寻址功能的特殊功能寄存器（其地址能被 8 整除的 SFR，如 A、B、PSW、P0~P3 等）。
* **示例**：
  ```assembly
  SETB 20H      ; 将位地址为 20H 的位置 1（对应 RAM 单元 24H 的第 0 位）
  CLR P1.0      ; 将 P1 端口的第 0 位清零
  MOV C, ACC.7  ; 将累加器 A 的最高位（第 7 位）送入进位标志位 C
  ```

---

### 总结对照表

| 寻址方式        | 常见标识/符号               | 访问的目标物理空间           | 典型指令示例                         |
| :---------- | :-------------------- | :------------------ | :----------------------------- |
| **立即寻址**    | `#`                   | 程序存储器 ROM (常数)      | `MOV A, #45H`                  |
| **直接寻址**    | 纯数字/寄存器名              | 内部 RAM 低 128 字节、SFR | `MOV A, 30H`                   |
| **寄存器寻址**   | `R0~R7`, `A`, `AB` 等  | 工作寄存器、特殊寄存器         | `MOV A, R5`                    |
| **寄存器间接寻址** | `@R0`, `@R1`, `@DPTR` | 内部 RAM、外部 RAM       | `MOV A, @R0` / `MOVX A, @DPTR` |
| **变址寻址**    | `@A+DPTR`, `@A+PC`    | 程序存储器 ROM (查表)      | `MOVC A, @A+DPTR`              |
| **相对寻址**    | 目标标号（如 `LOOP`）        | 程序存储器 ROM (程序跳转)    | `SJMP LOOP`                    |
| **位寻址**     | `位地址` 或 `寄存器.位`       | 内部 RAM 位寻址区、部分 SFR  | `SETB P1.0` / `MOV C, 20H`     |
