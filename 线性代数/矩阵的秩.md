## 2. 矩阵的秩

### 2.1 行秩与列秩

- **列秩**（Column Rank）：矩阵 $A$ 的列向量组的**极大线性无关组**所含向量的个数，即列向量张成空间的维数。
- **行秩**（Row Rank）：矩阵 $A$ 的行向量组的**极大线性无关组**所含向量的个数，即行向量张成空间的维数。

**定理**：对任意矩阵 $A$，**行秩 = 列秩**。？

### 2.2 秩的定义

由上述定理，可以统一定义矩阵的**秩**（Rank）：

$$\text{rank}(A) = \text{列秩} = \text{行秩}$$

对于 $m \times n$ 矩阵 $A$，有 $0 \leq \text{rank}(A) \leq \min(m, n)$。

- 若 $\text{rank}(A) = \min(m, n)$，称 $A$ 为**满秩矩阵**
- 对于 $n$ 阶方阵，满秩即 $\text{rank}(A) = n$

### 2.3 计算方法：初等行变换法

**求秩的标准方法**：将矩阵通过初等行变换化为**行阶梯形矩阵**（Row Echelon Form），非零行的行数就是矩阵的秩。

$$A \xrightarrow{\text{初等行变换}} \text{行阶梯形} \implies \text{rank}(A) = \text{非零行的行数}$$

> 初等行变换不改变矩阵的秩（也不改变行空间，但会改变列空间——不过列空间的维数不变）。

**例子**：

$$A = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 3 & 5 \end{pmatrix} \xrightarrow{R_2 - 2R_1} \begin{pmatrix} 1 & 2 & 3 \\ 0 & 0 & 0 \\ 1 & 3 & 5 \end{pmatrix} \xrightarrow{R_3 - R_1} \begin{pmatrix} 1 & 2 & 3 \\ 0 & 0 & 0 \\ 0 & 1 & 2 \end{pmatrix}$$

交换第 2、3 行：

$$\begin{pmatrix} 1 & 2 & 3 \\ 0 & 1 & 2 \\ 0 & 0 & 0 \end{pmatrix}$$

有 2 个非零行，所以 $\text{rank}(A) = 2$。

> 这也说明 $A$ 的 3 个列向量**线性相关**（秩 < 列数 3），极大线性无关组含 2 个向量。

## 3. 秩的性质

设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times p$ 矩阵，则：

1. $\text{rank}(A) = \text{rank}(A^T)$
2. $\text{rank}(A + B) \leq \text{rank}(A) + \text{rank}(B)$（$A, B$ 同型时成立）
3. $\text{rank}(AB) \leq \min(\text{rank}(A),\, \text{rank}(B))$
4. 若 $P, Q$ 可逆，则 $\text{rank}(PAQ) = \text{rank}(A)$（可逆变换不改变秩）
5. $\text{rank}(A) = 0 \iff A = O$（零矩阵）

## 4. 秩与线性方程组

秩是分析线性方程组 $A\vec{x} = \vec{b}$ 解的核心工具。

### 4.1 齐次方程组 $A\vec{x} = \vec{0}$

设 $A$ 是 $m \times n$ 矩阵：

| 条件 | 解的情况 |
| :--- | :--- |
| $\text{rank}(A) = n$ | 只有**零解** $\vec{x} = \vec{0}$ |
| $\text{rank}(A) < n$ | 有**非零解**（无穷多解） |

> 对于**方阵** $A$（$m = n$）：有非零解 $\iff \text{rank}(A) < n \iff \det(A) = 0$

解空间的维数（即**基础解系**中向量的个数）为：

$$\dim(\ker A) = n - \text{rank}(A)$$

### 4.2 非齐次方程组 $A\vec{x} = \vec{b}$

设增广矩阵 $(A \mid \vec{b})$ 是在 $A$ 右侧拼接列向量 $\vec{b}$ 得到的 $m \times (n+1)$ 矩阵：

| 条件 | 解的情况 |
| :--- | :--- |
| $\text{rank}(A) \neq \text{rank}(A \mid \vec{b})$ | **无解** |
| $\text{rank}(A) = \text{rank}(A \mid \vec{b}) = n$ | **唯一解** |
| $\text{rank}(A) = \text{rank}(A \mid \vec{b}) < n$ | **无穷多解** |

> 这就是**Rouché-Capelli 定理**（也称 Kronecker-Capelli 定理）。

## 5. 秩-零化度定理（Rank-Nullity Theorem）

这是线性代数中最重要的定理之一，它将矩阵（或线性映射）的"信息保留量"和"信息丢失量"联系起来。

**定理**：设 $A$ 是 $m \times n$ 矩阵，则：

$$\text{rank}(A) + \dim(\ker A) = n$$

其中：
- $\text{rank}(A) = \dim(\text{Col}(A))$：列空间的维数，即映射后"保留的信息维度"
- $\dim(\ker A)$：零空间（核）的维数，即被映射"压缩为零"的方向数，也叫**零化度**（Nullity）
- $n$：定义域（列数），即输入的总维度

> **直觉**：一个 $m \times n$ 的矩阵把 $n$ 维空间映射到 $m$ 维空间。映射后，有些方向被"压扁"了（变成零），有些方向保留了。保留的维数 + 压扁的维数 = 原始维数。

**例子**：$A = \begin{pmatrix} 1 & 2 & 3 \\ 0 & 0 & 0 \end{pmatrix}$ 是 $2 \times 3$ 矩阵

- $\text{rank}(A) = 1$（只有 1 个非零行）
- $\dim(\ker A) = 3 - 1 = 2$
- 即 3 维空间被映射后，1 个维度保留了，2 个维度被压扁为零

## 6. 秩与方阵可逆性的等价条件

对于 $n$ 阶方阵 $A$，以下命题**全部等价**：

| 序号 | 命题 |
| :--- | :--- |
| 1 | $A$ 可逆（$A^{-1}$ 存在） |
| 2 | $\det(A) \neq 0$ |
| 3 | $\text{rank}(A) = n$（满秩） |
| 4 | $A$ 的列向量线性无关 |
| 5 | $A$ 的行向量线性无关 |
| 6 | $A\vec{x} = \vec{0}$ 只有零解 |
| 7 | 对任意 $\vec{b}$，$A\vec{x} = \vec{b}$ 有唯一解 |
| 8 | $A$ 可经初等行变换化为 $I_n$ |
| 9 | $0$ 不是 $A$ 的特征值 |

> 这张等价表是线性代数的"核心枢纽"。行列式、秩、线性相关性、方程组解、特征值等概念在此统一。

## 7. 小结

| 概念 | 要点 |
| :--- | :--- |
| **线性相关** | 存在不全为零的系数使线性组合为零向量 |
| **线性无关** | 线性组合为零 $\implies$ 系数全为零 |
| **张成空间** | 向量组所有线性组合的集合 |
| **秩** | 极大线性无关组的向量个数 = 行阶梯形非零行数 |
| **秩-零化度定理** | $\text{rank}(A) + \dim(\ker A) = n$ |
| **齐次方程组** | $\text{rank}(A) < n \iff$ 有非零解 |
| **非齐次方程组** | 比较 $\text{rank}(A)$ 与 $\text{rank}(A \mid \vec{b})$ 判断解的情况 |
