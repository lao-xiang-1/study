# 线性代数 课程大纲

## 第一章 行列式

- **1.1** 行列式的定义（递归定义 / 排列逆序数定义）

- **1.3** 行列式的计算
  - 按行（列）展开（余子式与代数余子式）
  - 三角化法
  - 递推法
- **1.4** 克拉默法则（Cramer's Rule）
- **1.5** 行列式的应用（面积、体积、判定可逆性）

## 第八章 矩阵的对角化

- **8.1** 可对角化的条件
  - $n$ 个线性无关的特征向量
  - 几何重数 = 代数重数
- **8.2** 对角化的计算 $A = PDP^{-1}$
- **8.3** 矩阵幂的计算 $A^k = PD^kP^{-1}$
- **8.4** 实对称矩阵的对角化
  - 特征值必为实数
  - 不同特征值的特征向量正交
  - 正交对角化 $A = Q\Lambda Q^T$
