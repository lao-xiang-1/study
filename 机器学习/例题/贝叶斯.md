## 题1
**【例题】** 细胞有正常($w_1$)，异常($w_2$)两类，其先验概率为$P(w_1) = 0.9, P(w_2) = 0.1$。有一个待识别的细胞，观测值为$x$，现在已知如果细胞是正常的，出现$x$的概率为0.2；如果细胞是异常的，出现$x$的概率是0.4。决策的损失表如下：

| 决策 | $w_1$ | $w_2$ |
| :---: | :---: | :---: |
| $w_1$ | 0 | 6 |
| $w_2$ | 1 | 0 |
1. 基于最小错误率原则对待识别细胞进行归类
2. 基于最小风险原则对待识别细胞进行归类

- **损失表**（也常称为损失矩阵，Loss Matrix）用于量化**分类器做出的决策（预测结果）**与**客观真实情况**不一致时，需要付出的“代价”或“惩罚”。

### 解答：
### **1. 基于最小错误率原则对待识别细胞进行归类**

最小错误率贝叶斯决策的准则是将样本归入**后验概率最大**的类别。

首先根据贝叶斯公式，计算在观测到特征 $x$ 后，细胞属于 $w_1$ 和 $w_2$ 的后验概率。

**第一步：计算联合概率（分子部分）**
*   $P(x, w_1) = p(x|w_1)P(w_1) = 0.2 \times 0.9 = 0.18$
*   $P(x, w_2) = p(x|w_2)P(w_2) = 0.4 \times 0.1 = 0.04$

**第二步：计算全概率（分母部分）**
*   $p(x) = p(x|w_1)P(w_1) + p(x|w_2)P(w_2) = 0.18 + 0.04 = 0.22$

**第三步：计算后验概率**
*   $P(w_1|x) = \frac{p(x|w_1)P(w_1)}{p(x)} = \frac{0.18}{0.22} = \frac{9}{11} \approx 0.818$
*   $P(w_2|x) = \frac{p(x|w_2)P(w_2)}{p(x)} = \frac{0.04}{0.22} = \frac{2}{11} \approx 0.182$

**决策结论：**
因为 $P(w_1|x) > P(w_2|x)$（即 $0.818 > 0.182$），根据最小错误率决策原则，应将该待识别细胞归为 **$w_1$（正常细胞）**。

---

### **2. 基于最小风险原则对待识别细胞进行归类**

最小风险贝叶斯决策的目标是使**条件平均风险最小**。设 $\alpha_1$ 代表归类为 $w_1$ 的决策，$\alpha_2$ 代表归类为 $w_2$ 的决策。

对于观测值 $x$，采取决策 $\alpha_i$ 的条件风险 $R(\alpha_i|x)$ 定义为：
$$R(\alpha_i|x) = \sum_{j=1}^{2} \lambda(\alpha_i, w_j) P(w_j|x)$$

**计算决策 $\alpha_1$（归为正常细胞）的条件风险：**
$$R(\alpha_1|x) = \lambda(\alpha_1, w_1) P(w_1|x) + \lambda(\alpha_1, w_2) P(w_2|x)$$
$$R(\alpha_1|x) = 0 \times \frac{9}{11} + 6 \times \frac{2}{11} = \frac{12}{11} \approx 1.091$$

**计算决策 $\alpha_2$（归为异常细胞）的条件风险：**
$$R(\alpha_2|x) = \lambda(\alpha_2, w_1) P(w_1|x) + \lambda(\alpha_2, w_2) P(w_2|x)$$
$$R(\alpha_2|x) = 1 \times \frac{9}{11} + 0 \times \frac{2}{11} = \frac{9}{11} \approx 0.818$$

*(注：也可以直接比较未归一化的风险值 $R'(\alpha_i|x) = R(\alpha_i|x) \cdot p(x)$，即 $R'(\alpha_1|x) = 6 \times 0.04 = 0.24$，$R'(\alpha_2|x) = 1 \times 0.18 = 0.18$，两者的相对大小是一致的。)*

**决策结论：**
因为 $R(\alpha_2|x) < R(\alpha_1|x)$（即 $0.818 < 1.091$），根据最小风险原则，选择决策 $\alpha_2$ 能带来更低的期望损失，因此应将该待识别细胞归为 **$w_2$（异常细胞）**。
