#ml

模拟退火（Simulated Annealing, SA）是一种启发式全局优化算法。在神经网络的超参数调优中，它的主要作用是帮助我们在巨大的超参数空间（如学习率、批次大小、隐藏层数量等）中，寻找能够让模型在验证集上表现最好的参数组合。

> [!直觉建立]
> 温度越高，参数变化越剧烈(更有可能选到差结果)。初始状态温度最高，广泛选择参数；之后温度逐渐降低，停留在较好解

以下是将模拟退火应用于神经网络超参数调优的具体步骤和核心概念：

### 1. 概念映射
在超参数调优的场景下，模拟退火的物理概念可以这样映射：
- **状态（State）**：一组特定的超参数组合（例如：学习率=0.001，层数=3，Dropout=0.2）。
- **能量（Energy / 目标函数）**：使用这组超参数训练出来的神经网络在验证集上的表现（通常是验证集Loss，因为能量越低越好；如果是准确率，则取负值）。
- **温度（Temperature, $T$）**：控制算法探索（Exploration）倾向的参数。温度越高，越容易接受表现变差的超参数组合；温度越低，越倾向于只接受表现变好的组合（收敛）。

### 2. 核心执行步骤

- **第一步：初始化**
  随机选择一组初始超参数作为当前状态 $S$，训练神经网络并计算其验证集损失 $E$。设定一个较高的初始温度 $T$ 和一个冷却率 $\alpha$（例如 0.95）。
- **第二步：产生新解（扰动）**
  在当前超参数 $S$ 的邻域内随机做一点微调，生成新的超参数组合 $S_{new}$。例如，将学习率稍微调大一点，或者将网络层数加一。
- **第三步：评估新解**
  使用 $S_{new}$ 重新训练（或微调）神经网络，得到新的验证集损失 $E_{new}$。
  计算能量差：$\Delta E = E_{new} - E$。
- **第四步：决定是否接受新解（Metropolis 准则）**
  如果 $\Delta E < 0$（新模型表现更好），则直接接受 $S_{new}$ 作为当前状态。
  如果 $\Delta E \ge 0$（新模型表现变差），则以概率 $P = \exp(-\Delta E / T)$ 接受 $S_{new}$。生成一个 0 到 1 的随机数，如果随机数小于 $P$，依然接受这个变差的结果（以此来跳出局部最优）。
- **第五步：降温（Cooling）**
  按照冷却方案降低温度，例如 $T = \alpha \times T$。
- **第六步：终止条件**
  重复步骤 2-5，直到温度 $T$ 降到一个非常低的阈值，或者达到了最大的评估次数限制。输出历史记录中表现最好的一组超参数。

### 3. 实际应用中的挑战与优化建议

在深度学习中，每次评估（即步骤3：训练一次神经网络）的时间成本非常高。因此，直接使用最原始的模拟退火可能会非常耗时。在实际操作中，可以采用以下策略：

- **结合早停机制（Early Stopping）**
  如果在评估 $S_{new}$ 的前几个 Epoch 中发现 Loss 下降极其缓慢甚至发散，可以直接提前终止训练，赋予其一个极高的“能量值”，节省时间。
- **代理模型（Surrogate Model）替代**
  通常人们会倾向于使用**贝叶斯优化**（如基于 TPE 或 Gaussian Process 的方法），因为它们能用更少的评估次数找到好参数。你可以将模拟退火作为优化代理模型获取函数（Acquisition Function）的内部求解器，而不是直接用来训练神经网络。
- **使用现有工具库**
  很多超参数调优框架内部集成了模拟退火或其改进算法。你可以直接使用现成的库：
  - **Optuna**：自带多种采样器，内部支持 Simulated Annealing 变体（如 `optuna.samplers.SimulatedAnnealingSampler`）。
  - **Hyperopt / Ray Tune**：支持集成各种底层优化算法，只需定义好搜索空间和目标函数即可自动执行退火搜索。

### 总结代码逻辑示例（伪代码）

```python
current_params = get_random_params()
current_loss = train_and_evaluate(current_params)
best_params = current_params
best_loss = current_loss

T = 100.0  # 初始温度
T_min = 0.1 # 最低温度
alpha = 0.95 # 降温系数

while T > T_min:
    # 在当前参数附近随机扰动生成新参数
    new_params = perturb_params(current_params)
    
    # 耗时步骤：训练神经网络
    new_loss = train_and_evaluate(new_params)
    
    delta_e = new_loss - current_loss
    
    # Metropolis 准则
    if delta_e < 0 or random.uniform(0, 1) < math.exp(-delta_e / T):
        current_params = new_params
        current_loss = new_loss
        
        # 记录全局最优
        if current_loss < best_loss:
            best_loss = current_loss
            best_params = current_params
            
    # 降温
    T = T * alpha

print("Best Hyperparameters:", best_params)
```
