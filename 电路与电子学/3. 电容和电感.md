
## 换路性质：
电容的电压不变
电感的电流不变

## 例题1
![509](电路与电子学/assets/3.%20电容和电感.png)
**题目分析与解答：**

**最终答案汇总：**
*  $u_C(0_+) = 4\text{ V}$
*  $i_C(0_+) = -1\text{ A}$
*  $u_L(0_+) = -4\text{ V}$
*  $i_L(0_+) = 2\text{ A}$

**步骤一：求换路前（$t = 0_-$ 时）的稳态值**
电感 $L$ 相当于短路，电容 $C$ 相当于开路。
1. 求电感电流 $i_L(0_-)$：
   $$i_L(0_-) = \frac{8\text{ V}}{2\,\Omega + 2\,\Omega} = 2\text{ A}$$
   （方向与图上 $i_L$ 的箭头方向一致）。
2. 求电容电压 $u_C(0_-)$：
   $$u_C(0_-) = i_L(0_-) \times 2\,\Omega = 2\text{ A} \times 2\,\Omega = 4\text{ V}$$
**步骤二：利用换路定理求 $t = 0_+$ 时的初始值**
根据换路定理（电容电压不能突变，电感电流不能突变），在 $t = 0_+$ 瞬间有：
1. **$u_C(0_+) = u_C(0_-) = 4\text{ V}$**
2. **$i_L(0_+) = i_L(0_-) = 2\text{ A}$**

**步骤三：分析 $t = 0_+$ 时的等效电路并求解其余量**
在 $t = 0_+$ 时，开关由 1 拨向 2，此时电源被断开，而并联支路的上下两端通过开关 2 的触点直接短接在了一起。
这意味着，右半部分的两条支路各自形成了一个独立的短接闭合回路。
1. 求解 $i_C(0_+)$：
   以上节点为参考，在 $t = 0_+$ 时含 C 的支路被短路（外电压为0），由于电容此时相当于一个 4V 的电压源，它与 4Ω 的电阻构成一个闭合回路，由此回路应用基尔霍夫电压定律（KVL）：
   $$u_C(0_+) + i_C(0_+) \times 4\,\Omega = 0$$
   代入 $u_C(0_+) = 4\text{ V}$，可得：
   $$4 + 4 \times i_C(0_+) = 0 \implies \textbf{ }i_C(0_+) = -1\text{ A}$$
   *(负号表示实际电流方向与图中所标箭头方向相反，即实际是从 4V 的电容正极经外短路线流向负极，此时电容放电)*。
2. 求解 $u_L(0_+)$：
   在 $t = 0_+$ 时，含 L 的支路同样被短路。电感此时相当于一个 2A 的电流源，与 2Ω 的电阻串联构成一个闭合回路。
   对这个独立闭合回路应用 KVL，顺着电流 $i_L$ 的方向（图中所标向下方向）：
   $$i_L(0_+) \times 2\,\Omega + u_L(0_+) = 0$$
   代入 $i_L(0_+) = 2\text{ A}$，可得：
   $$2 \times 2 + u_L(0_+) = 0 \implies \textbf{ }u_L(0_+) = -4\text{ V}$$
   *(负号表示电感两端实际感应电势上负下正，根据楞次定律，磁场在减弱时产生的感应电势企图维持原电流继续从上方流入，所以上方为负)*。


## 例题2
![478](电路与电子学/assets/3.%20电容和电感-1.png)
求解：
### **第一步：分析 t = 0⁻ 时的状态（开关S打开前）**
$$u_C(0^-) = 0\text{V}$$

$$i_L(0^-) = \frac{6\text{V}}{2\,\Omega} = 3\text{A}$$
### **第二步：应用换路定律（计算 t = 0⁺ 初始值）**
根据换路定律（储能元件不能突变），在 t = 0⁺ 瞬间：
*   **电容电压不突变**：$u_C(0^+) = u_C(0^-) = 0\text{V}$
*   **电感电流不突变**：$i_L(0^+) = i_L(0^-) = 3\text{A}$

### **第三步：画 t = 0⁺ 瞬间的等效电路**
在 t = 0⁺ 瞬间，我们画出开关S刚打开时的等效电路图：
1.  电容 \(C\) 两端电压初值为 0V，可以等效为**一条短路线**（导线直接连通）。
2.  电感 \(L\) 中的电流初值为 3A，方向向左，因此等效为一个**3A的恒流源**（方向从右向左流过电感，即注入中间节点 A）。

### **第四步：计算中间节点 A 的电位及各参数**
设中间节点 A 的电位为 $u_A(0^+)$，则：
$$3\text{A} = \frac{u_A(0^+)}{2} + \frac{u_A(0^+)}{4}$$
解得：
$$u_A(0^+) = 4\text{V}$$


由此我们可以求出：
1.  **流过中间4Ω电阻的电流**：
$$i_1(0^+) = \frac{4\text{V}}{4\,\Omega} = 1\text{A}$$
2.  **流过左侧支路电容的电流**：
$$i_C(0^+) = \frac{4\text{V}}{2\,\Omega} = 2\text{A}$$
3.  **电感两端的电压**：
    我们察看右侧支路。地（0V）向上经过6V电源（假设正极在上，负极在下），电源正极端电位为 $+6\text{V}$；
    3A的电流从此向左流过2Ω电阻，因此电阻左侧（电感右侧）的电位为：$6\text{V} - 3\text{A} \times 2\,\Omega = 0\text{V}$；
    而电感左侧即是节点A，电位为 $4\text{V}$。
    所以电感两端的电位差大小为 $U_L = 0\text{V} - 4\text{V} = -4\text{V}$。
