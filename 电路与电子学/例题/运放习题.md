## 例1
如图所示电路，求输入电压 $U_i$ 与输出电压 $U_o$ 之间的关系，并说明该电路的主要功能。

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//ff798636-a24f-4893-a30f-04ea47719afb/markdown_4/imgs/img_in_image_box_888_259_1421_663.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A24Z%2F-1%2F%2F36145ec69546fe511a2e42cb154f5c7d5547339907b5066dedf7dd3444736a13" alt="Image" width="31%" /></div>

解：根据运放的虚断可知，

$$U_+ = \frac{R_3}{R_2 + R_3} U_i$$

由同相比例电路输入与输出之间的关系：

$$U_o = \left(1 + \frac{R_f}{R_1}\right) U_+$$

可得：

$$U_o = \left(1 + \frac{R_f}{R_1}\right) U_+ = \left(1 + \frac{R_f}{R_1}\right) \frac{R_3}{R_2 + R_3} U_i$$

输出电压与输入电压同相，大小成一定比例关系，电路实现同相比例运算。

## 例2
电路如图所示，已知 $U_o = -33 U_i$，求 $R_3$、$R_5$、$R_6$。

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//f4ac9ef7-463e-42d0-b944-3472dfa1f619/markdown_0/imgs/img_in_image_box_325_230_1243_557.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A22Z%2F-1%2F%2Fa226a760a92c348d26865121c4e0c9ac7d0cb9fa64622b7101962450b23a9c23" alt="Image" width="54%" /></div>

解：$A_1$ 为同相比例电路：

$$U_{o1} = \left(1 + \frac{R_2}{R_1}\right) U_i = 11 U_i$$

$R_3$ 为平衡电阻：

$$R_3 = R_1 // R_2 = 9.1 \, k\Omega$$

$A_2$ 为反相比例电路：

$$U_o = -\frac{R_5}{R_4} U_{o1} = -\frac{R_5}{R_4} \times 11 U_i = -33 U_i$$

$R_6$ 为平衡电阻：

$$R_6 = R_4 // R_5 = 75 \, k\Omega, \quad R_5 = 3 R_4 = 300 \, k\Omega$$


## 例3
电路如图所示，(1) 试分别说明 $A_1$、$A_2$、$A_3$ 各构成什么运算电路；(2) 求 $U_o$ 的表达式。

解：(1) $A_1$、$A_2$、$A_3$ 均为差放电路（减法电路）。

(2) 利用叠加原理可得：

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//c3db2bd3-ba1d-410c-be07-75cf22c07633/markdown_3/imgs/img_in_image_box_158_187_1489_760.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A24Z%2F-1%2F%2F98d605d9dd8d8968a31449717731b488eba7855afe85d39070734abd64209791" alt="Image" width="79%" /></div>

$$U_o = -\frac{R_4}{R_3} \left(1 + 2\frac{R_2}{R_1}\right) (U_{i1} - U_{i2})$$

实现了差分放大。
