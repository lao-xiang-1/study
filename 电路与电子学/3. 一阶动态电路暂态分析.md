# 一阶动态电路暂态分析

> 一阶电路：只含一个独立储能元件（电容 $C$ 或电感 $L$）的电路，其微分方程为一阶线性常微分方程。

---

## 3.1 三要素法

### 3.1.1 三要素法的核心思想

三要素法是求解**一阶电路暂态响应**的快捷方法，避免了求解微分方程的繁琐过程。

一阶电路任意支路的电压或电流 $f(t)$ 均满足同一规律：

$$f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-\frac{t}{\tau}}$$

其中包含三个关键量——**三要素**：

| 要素 | 符号 | 含义 | 求解方法 |
|------|------|------|----------|
| 初始值 | $f(0_+)$ | 换路后瞬间的值 | $t=0_+$ 等效电路 |
| 稳态值 | $f(\infty)$ | $t \to \infty$ 时的稳定值 | $t=\infty$ 等效电路 |
| 时间常数 | $\tau$ | 衰减快慢的量度 | $\tau = RC$ 或 $\tau = \frac{L}{R}$ |

> **适用条件**：电路必须是**一阶线性电路**，且激励为直流或阶跃信号。

---

### 3.1.2 初始值 $f(0_+)$ 的求解

#### 换路定则

在换路瞬间（$t=0$），储能元件的能量不能突变：

- **电容电压不突变**：$u_C(0_+) = u_C(0_-)$
- **电感电流不突变**：$i_L(0_+) = i_L(0_-)$

#### 求解步骤

**（1）求换路前稳态值**

画 $t=0_-$ 等效电路（换路前已稳定）：
- 电容 → 开路
- 电感 → 短路

求出 $u_C(0_-)$ 和 $i_L(0_-)$。

**（2）由换路定则确定独立初始条件**

$$u_C(0_+) = u_C(0_-), \quad i_L(0_+) = i_L(0_-)$$

**（3）画 $t=0_+$ 等效电路**

- 电容 → 电压源 $u_C(0_+)$
- 电感 → 电流源 $i_L(0_+)$
- 其他元件保持不变

求解目标支路的电压或电流，即为 $f(0_+)$。

> **注意**：非储能元件的电压/电流**可以突变**，如电阻电压、电容电流、电感电压等。

---

### 3.1.3 稳态值 $f(\infty)$ 的求解

画 $t=\infty$ 等效电路（换路后新稳态）：
- 电容 → 开路
- 电感 → 短路

用直流电路分析方法求目标支路的电压或电流，即为 $f(\infty)$。

---

### 3.1.4 时间常数 $\tau$ 的求解

#### 时间常数的物理意义

- $\tau$ 决定暂态过程的**快慢**
- $t = \tau$ 时，响应衰减到初始差的 $36.8\%$（即完成 $63.2\%$ 的变化）
- $t = 3\tau \sim 5\tau$ 时，认为暂态过程**基本结束**

#### 计算公式

将独立源置零（电压源短路、电流源开路）后，从储能元件两端看进去的等效电阻为 $R_{eq}$：

- **RC 电路**：
  $$\tau = R_{eq}C$$

- **RL 电路**：
  $$\tau = \frac{L}{R_{eq}}$$

> **关键**：求 $R_{eq}$ 时必须将所有**独立源置零**，保留受控源。

---

### 3.1.5 三要素法公式总结

$$\boxed{f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-\frac{t}{\tau}}}$$

三种典型响应形式：

| 响应类型 | 条件 | 公式 |
|----------|------|------|
| **零输入响应** | $f(\infty) = 0$ | $f(t) = f(0_+)e^{-\frac{t}{\tau}}$ |
| **零状态响应** | $f(0_+) = 0$ | $f(t) = f(\infty)(1 - e^{-\frac{t}{\tau}})$ |
| **全响应** | 一般情况 | $f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-\frac{t}{\tau}}$ |

> 全响应 = 零输入响应 + 零状态响应（**叠加定理**在一阶电路中的体现）

---

### 3.1.6 应用三要素法的解题步骤

**（1）判断**电路是否为一阶电路

**（2）求初始值** $f(0_+)$
- 画 $t=0_-$ 电路，求 $u_C(0_-)$ 或 $i_L(0_-)$
- 换路定则得 $u_C(0_+)$ 或 $i_L(0_+)$
- 画 $t=0_+$ 等效电路，求目标 $f(0_+)$

**（3）求稳态值** $f(\infty)$
- 画 $t=\infty$ 等效电路，求目标 $f(\infty)$

**（4）求时间常数** $\tau$
- 独立源置零，求 $R_{eq}$
- $\tau = R_{eq}C$ 或 $\tau = \frac{L}{R_{eq}}$

**（5）代入公式**
$$f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-\frac{t}{\tau}}$$

---

### 3.1.7 注意事项与常见错误

- **换路定则的适用条件**：仅适用于 $u_C$ 和 $i_L$，不适用于其他量
- **跃变情况**：当换路后出现纯电容回路或纯电感割集时，换路定则可能不成立（需用电荷守恒/磁链守恒）
- **多个储能元件**：若可等效为单个 $C$ 或 $L$，仍可用三要素法；否则需列写状态方程
- **$R_{eq}$ 的计算**：务必置零独立源，注意串并联及含受控源时的等效方法

## 3.2 一阶电路的阶跃响应与冲激响应

### 3.2.1 阶跃函数与阶跃响应

**单位阶跃函数**：

$$\varepsilon(t) = \begin{cases} 0, & t < 0 \\ 1, & t > 0 \end{cases}$$

**阶跃响应** $s(t)$：电路在**单位阶跃信号**激励下的**零状态响应**。

- RC 电路电容电压阶跃响应：
  $$u_C(t) = (1 - e^{-\frac{t}{\tau}})\varepsilon(t)$$

- RL 电路电感电流阶跃响应：
  $$i_L(t) = (1 - e^{-\frac{t}{\tau}})\varepsilon(t)$$

> 利用阶跃函数的延迟特性 $\varepsilon(t-t_0)$，可求解分段恒定激励下的响应。

### 3.2.2 冲激函数与冲激响应

**单位冲激函数** $\delta(t)$：

$$\delta(t) = \frac{d\varepsilon(t)}{dt}, \quad \int_{-\infty}^{+\infty}\delta(t)dt = 1$$

**冲激响应** $h(t)$：电路在**单位冲激信号**激励下的**零状态响应**。

两种求解方法：

**（1）由阶跃响应求导**
$$h(t) = \frac{ds(t)}{dt}$$

**（2）三要素法 + 初始值跃变**

冲激信号作用期间（$t=0$），对电路方程积分求 $u_C(0_+)$ 或 $i_L(0_+)$ 的跃变量，然后以该值为初始值用三要素法求 $t>0$ 的响应。

- RC 电路：冲激电流使电容电压跃变
  $$u_C(0_+) = u_C(0_-) + \frac{1}{C}\int_{0_-}^{0_+}i_C(t)dt$$

- RL 电路：冲激电压使电感电流跃变
  $$i_L(0_+) = i_L(0_-) + \frac{1}{L}\int_{0_-}^{0_+}u_L(t)dt$$

## 3.3 一阶电路的典型应用

### 3.3.1 RC 电路应用

- **延时电路**：利用电容充电时间实现时间延迟
- **微分电路**：$\tau \ll t_p$（脉冲宽度），输出近似输入的微分
- **积分电路**：$\tau \gg t_p$，输出近似输入的积分
- **滤波电路**：利用 RC 充放电特性构成低通/高通滤波器

### 3.3.2 RL 电路应用

- **继电器延时**：利用电感电流不能突变的特性
- **灭弧电路**：RL 电路换路时产生的高电压可用于熄弧
- **镇流器**：日光灯启动时利用自感电动势产生高压

## 3.4 例题速查

### 3.4.1 三要素法基本例题

**例**：图示电路中，$t=0$ 时开关 $S$ 闭合，开关闭合前电路已达稳态。求 $t>0$ 时的 $u_C(t)$。

**解**：

**（1）求 $u_C(0_+)$**

$t=0_-$ 时，电容开路：
$$u_C(0_-) = U_S$$

由换路定则：
$$u_C(0_+) = u_C(0_-) = U_S$$

**（2）求 $u_C(\infty)$**

$t=\infty$ 时，电容开路，用分压公式：
$$u_C(\infty) = \frac{R_2}{R_1+R_2}U_S$$

**（3）求 $\tau$**

独立源置零，从电容两端看：
$$R_{eq} = R_1 // R_2 = \frac{R_1R_2}{R_1+R_2}$$
$$\tau = R_{eq}C = \frac{R_1R_2}{R_1+R_2}C$$

**（4）代入三要素公式**

$$u_C(t) = u_C(\infty) + [u_C(0_+) - u_C(\infty)]e^{-\frac{t}{\tau}}$$

$$u_C(t) = \frac{R_2}{R_1+R_2}U_S + \left[U_S - \frac{R_2}{R_1+R_2}U_S\right]e^{-\frac{t}{\tau}}$$

$$u_C(t) = \frac{R_2}{R_1+R_2}U_S + \frac{R_1}{R_1+R_2}U_S \cdot e^{-\frac{t}{\tau}} \quad (t>0)$$

---

## 易错点速记

- **$f(0_+)$ 与 $f(0_-)$**：只有 $u_C$ 和 $i_L$ 满足换路定则，其他量需通过 $t=0_+$ 等效电路重新计算
- **$R_{eq}$ 的求法**：必须独立源置零后再求等效电阻，不要与戴维南等效混淆
- **时间常数单位**：$\tau$ 的单位为秒（s），$RC$ 中 $R$ 为 $\Omega$，$C$ 为 $F$；$L/R$ 中 $L$ 为 $H$，$R$ 为 $\Omega$
- **指数项符号**：三要素公式中是 $e^{-t/\tau}$，不要漏掉负号
- **全响应分解**：$f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-t/\tau}$ 中，$f(\infty)$ 是稳态分量，$[f(0_+)-f(\infty)]e^{-t/\tau}$ 是暂态分量
