# 6.3 基本运算电路

**比例运算电路**：将信号按比例放大的电路。运算放大电路有反相（-）和同相（+）两个输入端，故可分为反相输入和同相输入。

## 6.3.2 反相比例运算电路

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//5ad5a629-64e7-4079-879f-84ff2e4ec903/markdown_2/imgs/img_in_image_box_863_518_1387_905.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A22Z%2F-1%2F%2Fc73b0c50cbcae6b3b37721e10fe107497c57905dc8c25d1e57cb6d0991b315fd" alt="Image" width="31%" /></div>

**输出与输入的关系**：
$$U_o = -\frac{R_f}{R_1} U_i$$
**证明**：
1. 根据"虚短"可得：$U_- = U_+ = 0$（虚地）
2. 根据"虚断"可得：$I_1 = I_f$

而：$I_1 = \dfrac{U_i}{R_1}$，$I_f = -\dfrac{U_o}{R_f}$

由此可得：
$$U_o = -\frac{R_f}{R_1} U_i$$

*可见，输出电压与输入电压的相位相反，大小成一定的比例关系，电路实现反相比例运算。*
- 当 $R_f = R_1$ 时，$A_{uf} = -1$，称为反相器。
- 放大倍数$A_{uf} = -\frac{R_f}{R_1}$

**电路组成**
- $R_f$ 是反馈电阻
- $R_1$ 是比例电阻
- $R_p$ 是平衡电阻

为了保证运放电路工作在平衡（输入端对称）的状态下，同相输入端的电阻：
$$R_p = R_f // R_1$$
**输入电阻**：$R_i = \frac{U_i}{I_1} = R_1$

**输出电阻**：0
由于理想运放的输出电阻 $r_o = 0$，故反相比例运算电路的输出电阻为 0，等效为恒压源，因此带负载能力很强。

**结论**
反相比例运算电路在理想情况下，反相输入端的电位为零，称为"虚地"，共模输入电压很低。
- 实现了反相比例运算，$|A_{uf}|$ 可大于 1、等于 1 或小于 1。
- 电路的输入电阻不高，输出电阻很低。
- 虽然理想运放的输入电阻为无穷大，由于引入了负反馈，电路的输入电阻变小了。要提高反相比例运算电路的输入电阻，需要加大 $R_1$ 的值，同时 $R_f$ 的值也需加大，电路的噪声也加大，电路的稳定性变差。

## 6.3.3 同相比例运算电路

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//fe39e019-7c4d-4639-99d9-fda82ba36516/markdown_2/imgs/img_in_image_box_798_314_1334_633.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A23Z%2F-1%2F%2F118274b714d2d49182f23d92ee971211cc2759cb41d532ab7a5cb00dbf7b346d" alt="Image" width="31%" /></div>
**输入与输出的关系**：
$$U_o = \left(1 + \frac{R_f}{R_1}\right) U_i$$

**证明**：
根据"虚短"和"虚断"，可知：
$$U_- = U_+ = U_i, \quad I_- = I_+ = 0, \quad I_-=I_f$$
根据欧姆定律，可得：
$$I_1 = \frac{0 - U_-}{R_1}, \quad I_f = \frac{U_- - U_o}{R_f}$$
由此可得：
$$U_o = \left(1 + \frac{R_f}{R_1}\right) U_- = \left(1 + \frac{R_f}{R_1}\right) U_+ = \left(1 + \frac{R_f}{R_1}\right) U_i$$
*可见，输出电压与输入电压的相位相同，大小成一定的比例关系，电路实现同相比例运算。*

#flashcards 平衡电阻$R_p$的阻值::$R_p = R_f // R_1$
**（1）电路组成**
- $R_f$ 是反馈电阻
- $R_1$ 是比例电阻
- $R_p$ 是平衡电阻
为了保证运放电路工作在平衡（输入端对称）的状态下，同相输入端的电阻：
$$R_p = R_f // R_1$$
**（2）电压放大倍数**：$A_{uf} = 1 + \frac{R_f}{R_1}$

**（3）输入电阻**
由于同相输入端的电流为零，故输入电阻为 $\infty$。

**（4）输出电阻**
由于理想运放的输出电阻 $r_o = 0$，故同相比例运算电路的输出电阻为 0，等效为恒压源，因此带负载能力很强。

**（5）共模输入电压**
由于输入端的电压 $U_- = U_+ = U_i$，故：
$$U_{ic} = \frac{U_+ + U_-}{2} = U_i$$

**结论**
- 同相比例运算电路在理想情况下，同相输入端的电流为零，故输入电阻很高。
- 实现了同相比例运算，$|A_{uf}|$ 可大于 1 或等于 1。
- 电路的输出电阻很低。
- 由于同相比例运算电路中不存在虚地，且运放存在共模输入信号，因此要求运放有较高的共模抑制比。

### 电压跟随器

负载上的电压：
$$u_o = \frac{R_L}{R_s + R_L} \cdot u_s = \frac{1}{100 + 1} \cdot u_s \approx 0.01 u_s$$

**加上电压跟随器后**：
<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//ff798636-a24f-4893-a30f-04ea47719afb/markdown_3/imgs/img_in_image_box_598_243_1005_522.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A24Z%2F-1%2F%2Ff95211aa6a3bbba57a7e0d22123765834bc3a2ffe6427ea055db7bd6a10d7aea" alt="Image" width="24%" /></div>

## 6.3.4 加法运算电路

加法电路也称为求和电路，电路的输出电压取决于多个输入电压相加的结果。利用集成运放实现求和运算时，**可采用反相输入方式，也可以采用同相输入方式**。

### 反相求和
多个输入信号同时作用于集成运放的反相输入端，就构成了反相加法电路。

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//f4ac9ef7-463e-42d0-b944-3472dfa1f619/markdown_1/imgs/img_in_image_box_254_568_851_929.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A22Z%2F-1%2F%2F03afad1ab75aaa3737ed0eb1186afeb93c628ceff2c13ee987e7735a4be5e978" alt="Image" width="35%" /></div>

**方法一：节点电流法**

根据"虚断"和"虚短"：

$$I_- = I_+ = 0, \quad U_- = U_+ = 0$$

$$I_f = I_1 + I_2 + I_3$$

$$-\frac{U_o}{R_f} = \frac{U_{i1}}{R_1} + \frac{U_{i2}}{R_2} + \frac{U_{i3}}{R_3}$$

**方法二：利用叠加原理**

首先求解每个输入信号单独作用时的输出电压，然后将所有结果相加，即得到所有输入信号同时作用时的输出电压。

$$u_{o1} = -\frac{R_f}{R_1} \cdot u_{i1}$$
同理可得：

$$u_{o2} = -\frac{R_f}{R_2} \cdot u_{i2}, \quad u_{o3} = -\frac{R_f}{R_3} \cdot u_{i3}$$

$$u_o = u_{o1} + u_{o2} + u_{o3} = -\frac{R_f}{R_1} u_{i1} - \frac{R_f}{R_2} u_{i2} - \frac{R_f}{R_3} u_{i3}$$

### 同相求和
多个输入信号同时作用于集成运放的同相输入端，就构成了同相加法电路。

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//f4ac9ef7-463e-42d0-b944-3472dfa1f619/markdown_3/imgs/img_in_image_box_231_294_1495_813.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A24Z%2F-1%2F%2Fe0de69de49a32a7b0b2b683679ce6cbb51fd5f84cd329dd64fbac947ca71793e" alt="Image" width="75%" /></div>

$$U_o = \left(1 + \frac{R_f}{R_1}\right) U_+ = \left(1 + \frac{R_f}{R_1}\right) \left(\frac{R_3 // R_4}{R_2 + R_3 // R_4} U_{i1} + \frac{R_2 // R_4}{R_3 + R_2 // R_4} U_{i2}\right)$$
>这里的$R_4$在理论上是可以去掉的。但在实际工作中，$R_4$可以 增加增益调节的自由度、静态偏置电流补偿、提供直流偏置通道 etc.

## 6.3.5 减法运算电路

**减法运算电路**：将输入信号**同时**接到集成运放的**反相和同相**输入端时，就可以构成减法运算电路。
减法运算电路分为**单运放电路**和**双运放电路**。

### 单运放减法电路

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//f4ac9ef7-463e-42d0-b944-3472dfa1f619/markdown_4/imgs/img_in_image_box_257_517_797_958.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A25Z%2F-1%2F%2Fc72bfe740b8331e73f35602d8e5c2424bb8dd245f4f0f6231fdb4688fc290080" alt="Image" width="32%" /></div>

电路平衡条件为：
$$R_1 // R_f = R_2 // R_3$$
根据叠加原理可得：
$U_{i1}$ 单独作用时为反相比例运算电路，可得：
$$U'_o = -\frac{R_f}{R_1} U_{i1}$$
$U_{i2}$ 单独作用时为同相比例运算电路，可得：
$$U_+ = \frac{R_3}{R_2 + R_3} U_{i2}$$
$$U''_o = \left(1 + \frac{R_f}{R_1}\right) U_+$$
$$U_o = U'_o + U''_o = \left(1 + \frac{R_f}{R_1}\right) \frac{R_3}{R_2 + R_3} U_{i2} - \frac{R_f}{R_1} U_{i1}$$
当电路电阻满足条件 $\dfrac{R_f}{R_1} = \dfrac{R_3}{R_2}$：
$$U_o = -\frac{R_f}{R_1} (U_{i1} - U_{i2})$$
实现了差分放大。

### 双运放减法运算电路

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-16-online//c3db2bd3-ba1d-410c-be07-75cf22c07633/markdown_1/imgs/img_in_image_box_419_221_1385_647.jpg?authorization=bce-auth-v1%2FALTAKDN8mY5KlNI7zaRpLmOqrw%2F2026-06-20T15%3A06%3A22Z%2F-1%2F%2F0586ef4842882153f6c05c02a2524cad35576671733c660bbd958949ab4b609a" alt="Image" width="57%" /></div>

$A_1$ 为反相比例运算电路：

$$U_{o1} = -\frac{R_2}{R_1} U_{i1}$$

$A_2$ 为反相加法运算电路：

$$U_o = -R_5 \left(\frac{U_{o1}}{R_4} + \frac{U_{i2}}{R_3}\right)$$

$$U_o = -R_5 \left(-\frac{R_2}{R_1 R_4} U_{i1} + \frac{U_{i2}}{R_3}\right)$$

## 6.3.6 积分运算电路

积分运算电路：将反相比例运算电路中的反馈电阻 $R_f$ 换成电容 $C_f$，就构成了反相积分电路。
![348](assets/6.3%20基本运算电路.pdf_by_PaddleOCR-VL-1.6-1.png)
由"虚断"和"虚短"：$i_f = i_1$,  $u_- = u_+ = 0$
而：
$$i_1 = \frac{u_i}{R_1}, \quad i_f = -C_f \frac{du_o}{dt}$$
所以：
$$\frac{u_i}{R_1} = -C_f \frac{du_o}{dt}$$
整理得到：
$$u_o = -\frac{1}{R_1 C_f} \int u_i \, dt$$

通用公式（定积分）：
?
$$u_o =  -\frac{1}{R_1 C_f} \int_{t_1}^{t_2} u_i \, dt + u_o(t_1)$$
若 $u_i$ 在 $t_1 \sim t_2$ 为常量，则：
$$u_o = -\frac{1}{R_1 C_f} \cdot u_i \cdot (t_2 - t_1) + u_o(t_1)$$

### 差动积分电路
将输入信号同时接入反相和同相输入端时，就构成了差动积分电路。

利用叠加原理可得：

## 6.3.7 微分运算电路

微分运算电路：将积分运算电路中的反馈电阻 $R_f$ 与电容 $C_f$ 位置互换，就构成了微分电路。
![346](assets/6.3%20基本运算电路.pdf_by_PaddleOCR-VL-1.6.png)

流过电容的电流：

$$i_1 = C \frac{du_i}{dt}$$

根据"虚断"和"虚短"，可得：
$$i_f = i_1$$
$$\therefore u_o = -R_f i_f = -R_f C \frac{du_i}{dt}$$
#flashcards
此微分电路很少直接使用，若 $u_i = U_m \sin \omega t$，则：
?
$$u_o = -R_f C \omega U_m \cos \omega t$$
<!--SR:!2026-06-29,1,219-->

随 $\omega \uparrow$，$|U_o| \uparrow$。可见，高频噪声幅值非常高。
