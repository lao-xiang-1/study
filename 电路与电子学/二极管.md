
## 二极管的基本结构
从物理结构上看，二极管非常简单，主要由以下几部分组成：
- **半导体芯片：** 一块 P 型半导体和一块 N 型半导体结合在一起，它们的交界面就形成了 **PN 结**。
- **电极引线：** 从 P 型区引出的电极称为**正极（阳极，Anode）**，从 N 型区引出的电极称为**负极（阴极，Cathode）**。

## 二极管的伏安特性（V-I 特性）

**1. 正向特性**
- **死区（开启前）：** 当施加的正向电压较低时，外加电场不足以克服内部PN结的死区电压，正向电流几乎为零。这个电压区间称为“死区”（硅管约在 0~0.5V，锗管约在 0~0.1V）。
- **导通区：** 当正向电压超过死区电压（开启电压）后，电流随电压的升高呈指数级急剧增大，二极管充分导通。此时二极管两端的压降基本维持恒定
（硅管正常导通压降约 0.7V，锗管约 0.3V）。

**2. 反向特性**
- **反向截止区：** 当给二极管施加反向电压时，在未达到击穿电压之前，只有极微弱的、由少数载流子漂移运动形成的反向电流（又称反向饱和电流或漏电流）。该电流基本不随反向电压的变化而变化，此时二极管处于截止状态。
- **反向击穿区：** 当反向电压继续增大并达到某一临界值（反向击穿电压）时，反向电流会突然急剧增大，这种现象称为“反向击穿”。如果在此区域不加限流措施，二极管会因过热而发生不可逆的永久损坏（稳压二极管除外，它就是工作在反向击穿区的）。

## 例题1
![](电路与电子学/assets/Pasted%20image%2020260507195900.jpg)

**先假设二极管断路，计算两端电压，比较电压是否大于导通电压，判断通断**
1. 开关S断开时：
   - 二极管VD阳极接5V，阴极通过电阻R接地。
   - 若假设VD截止，则阴极电位为0V，阳极-阴极电压为5V > 0.7V，矛盾，故VD必导通。
   - 导通后，输出电压为：  
     
     U_0 = U_1 - U_{D(on)} = 5V - 0.7V = 4.3V
     

2. 开关S闭合时：
   - 右侧支路形成分压电路：12V电源经两个等值电阻R分压，输出端位于中点。
   - 若假设VD截止，则输出电压为：  
     
     U_0 = frac{R}{R + R} times 12V = 6V
     
   - 此时二极管阳极电位为5V，阴极电位为6V， U_D = 5V - 6V = -1V < 0.7V ，满足截止条件，假设成立。
   - 故输出电压为6V。

最终结果：
- 开关断开时， U_0 = 4.3V 
- 开关闭合时， U_0 = 6V
