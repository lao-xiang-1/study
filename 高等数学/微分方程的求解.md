
## 概念
1. **齐次微分方程**：方程右边为0，系统没有外界输入
2. **非齐次微分方程**：方程右边不为0，系统受到外部输入

## 通用步骤：
以二阶常系数线性非齐次微分方程为例：
$$
y'' + p y' + qy = f(x)
$$

1. **先求对应齐次方程的通解 $y_h$**：
   将右边的非齐次项 $f(x)$ 改成 $0$，得到对应的齐次方程：
   $$
   y'' + p y' + qy = 0
   $$
   再写出特征方程：
   $$
   r^2 + pr + q = 0
   $$
   根据特征根写出齐次通解 $y_h$。
   - **两个不相等实根** $r_1,r_2$：$y_h = C_1 e^{r_1x} + C_2 e^{r_2x}$
   - **二重实根** $r$：$y_h = (C_1 + C_2x)e^{rx}$
   - **一对共轭复根** $\alpha \pm \beta i$：$y_h = e^{\alpha x}(C_1\cos \beta x + C_2\sin \beta x)$

2. **再求原非齐次方程的一个特解 $y^*$**：
   特解是满足原方程 $y'' + p y' + qy = f(x)$ 的某一个具体函数。
   它只需要找到一个即可，通常不含任意常数。

   常用方法是**待定系数法**：根据右边 $f(x)$ 的形式猜 $y^*$，再代回原方程求出未知系数。
   
*猜 特解的形式 一般如下表格所示：*

| $f(x)$ 的类型                      | 设特解 $y^*$ 的形式                             |
| ------------------------------- | ----------------------------------------- |
| $P_n(x)$（$n$ 次多项式）              | $x^s \cdot Q_n(x)$                        |
| $e^{\alpha x}$                  | $x^s \cdot Ae^{\alpha x}$                 |
| $\cos \beta x$ 或 $\sin \beta x$ | $x^s \cdot (A\cos\beta x + B\sin\beta x)$ |
| 上述类型的乘积                         | 对应形式的乘积                                   |


3. **把齐次通解和特解相加，得到原方程通解**：
   $$
   y = y_h + y^*
   $$
   其中，$y_h$ 表示齐次方程的通解，$y^*$ 表示非齐次方程的一个特解。

4. **若题目给了初始条件，再代入求常数**：
   例如给出 $y(0)$、$y'(0)$，就把它们代入通解，求出 $C_1,C_2$ 的具体值。
   这样得到的就是满足初始条件的唯一解。



## 📝 例题

求下列二阶常系数线性微分方程的特解（满足初始条件的解）：
$$y'' - 5y' + 6y = 2e^x$$
**初始条件：** $y(0) = 1, \quad y'(0) = 0$

### 方法一、特征方程法

#### 第一步：求齐次通解 $y_h$
对应齐次方程：
$$y'' - 5y' + 6y = 0$$

特征方程：
$$r^2 - 5r + 6 = 0 \implies (r-2)(r-3) = 0$$

特征根 $r_1 = 2, \; r_2 = 3$，齐次通解：
$$y_h = C_1 e^{2x} + C_2 e^{3x}$$

#### 第二步：求非齐次特解 $y^*$
右边 $f(x) = 2e^x$，而指数系数 $1$ 不是特征根，设：*这里的特解选择和右边同形式的*
$$y^* = Ae^x$$

求导代入：
$$(y^*)' = Ae^x, \quad (y^*)'' = Ae^x$$
$$Ae^x - 5Ae^x + 6Ae^x = 2e^x \implies 2Ae^x = 2e^x$$

得 $A = 1$，故：
$$y^* = e^x$$

#### 第三步：写出通解
$$y = y_h + y^* = C_1 e^{2x} + C_2 e^{3x} + e^x$$

#### 第四步：代入初始条件
由 $y(0) = 1$：
$$C_1 + C_2 + 1 = 1 \implies C_1 + C_2 = 0 \quad \text{①}$$

求导：
$$y' = 2C_1 e^{2x} + 3C_2 e^{3x} + e^x$$

由 $y'(0) = 0$：
$$2C_1 + 3C_2 + 1 = 0 \implies 2C_1 + 3C_2 = -1 \quad \text{②}$$

联立①②：$C_1 = 1, \; C_2 = -1$

#### 最终结果
$$y = e^{2x} - e^{3x} + e^x$$

### 方法二、拉氏变换求解

设 $\mathcal{L}[y(x)] = Y(s)$，对两边取拉氏变换：

$$s^2Y(s) - sy(0) - y'(0) - 5[sY(s) - y(0)] + 6Y(s) = \frac{2}{s-1}$$

代入 $y(0)=1, y'(0)=0$：

$$s^2Y(s) - s - 5sY(s) + 5 + 6Y(s) = \frac{2}{s-1}$$

$$(s^2 - 5s + 6)Y(s) = \frac{2}{s-1} + s - 5$$

$$(s-2)(s-3)Y(s) = \frac{2 + (s-5)(s-1)}{s-1} = \frac{s^2 - 6s + 7}{s-1}$$

$$Y(s) = \frac{s^2 - 6s + 7}{(s-1)(s-2)(s-3)}$$

部分分式分解后可得：

$$Y(s) = \frac{1}{s-2} - \frac{1}{s-3} + \frac{1}{s-1}$$

逆变换后：

$$\boxed{y(x) = e^{2x} - e^{3x} + e^x}$$
与第一种方法完全一致
