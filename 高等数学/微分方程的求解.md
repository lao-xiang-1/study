
## 概念
1. **齐次微分方程**：方程右边为0，系统没有外界输入
2. **非齐次微分方程**：方程右边不为0，系统受到外部输入

## 通用步骤：
以二阶常系数线性非齐次微分方程为例：
$$
y'' + p y' + qy = f(x)
$$

1. **先求对应齐次方程的通解 $y_h$**：
   将右边的非齐次项 $f(x)$ 改成 $0$，得到对应的齐次方程：
   $$
   y'' + p y' + qy = 0
   $$
   再写出特征方程：
   $$
   r^2 + pr + q = 0
   $$
   根据特征根写出齐次通解 $y_h$。
   - **两个不相等实根** $r_1,r_2$：$y_h = C_1 e^{r_1x} + C_2 e^{r_2x}$
   - **二重实根** $r$：$y_h = (C_1 + C_2x)e^{rx}$
   - **一对共轭复根** $\alpha \pm \beta i$：$y_h = e^{\alpha x}(C_1\cos \beta x + C_2\sin \beta x)$

2. **再求原非齐次方程的一个特解 $y^*$**：
   特解是满足原方程 $y'' + p y' + qy = f(x)$ 的某一个具体函数。
   它只需要找到一个即可，通常不含任意常数。

   常用方法是**待定系数法**：根据右边 $f(x)$ 的形式猜 $y^*$，再代回原方程求出未知系数。

3. **把齐次通解和特解相加，得到原方程通解**：
   $$
   y = y_h + y^*
   $$
   其中，$y_h$ 表示齐次方程的通解，$y^*$ 表示非齐次方程的一个特解。

4. **若题目给了初始条件，再代入求常数**：
   例如给出 $y(0)$、$y'(0)$，就把它们代入通解，求出 $C_1,C_2$ 的具体值。
   这样得到的就是满足初始条件的唯一解。



## 📝 例题

求下列二阶常系数线性微分方程的特解（满足初始条件的解）：
$$y'' - 5y' + 6y = 2e^x$$
**初始条件：** $y(0) = 1, \quad y'(0) = 0$

### 💡 求解过程

#### 第一步：求对应的“齐次方程”的通解 $Y$
首先，我们把等号右边的非齐次项 $2e^x$ 变成 $0$，得到对应的齐次方程：
$$y'' - 5y' + 6y = 0$$

1.  **写出特征方程**：把 $y''$ 换成 $r^2$，$y'$ 换成 $r^1$，$y$ 换成 $r^0$（即 1）。
    $$r^2 - 5r + 6 = 0$$
2.  **解特征方程**：用十字相乘法因式分解。
    $$(r - 2)(r - 3) = 0$$
    解得两个不相等的实数根：$r_1 = 2, \quad r_2 = 3$。
3.  **写出齐次通解 $Y$**：根据两个不相等的实根的情况，直接套用公式：
    $$Y = C_1 e^{2x} + C_2 e^{3x}$$
    *(其中 $C_1, C_2$ 为任意常数)*

#### 第二步：求原“非齐次方程”的一个特解 $y^*$
现在回到原方程 $y'' - 5y' + 6y = 2e^x$。等号右边是指数函数形式 $f(x) = 2e^x$。
我们使用**待定系数法**。

1.  **观察并猜测特解形式**：
    右边是 $2e^x$（指数上的系数是 1，即 $1 \cdot x$）。因为 $r=1$ **不是**我们刚才求出的特征根（特征根是 2 和 3），所以不需要乘 $x$ 来避免重复。
    我们大胆猜测特解的形式为：
    $$y^* = A e^x$$
    *(其中 $A$ 是我们需要求出的待定系数)*
2.  **求导并代入原方程**：
    对 $y^*$ 求一阶导和二阶导：
    $$(y^*)' = A e^x$$
    $$(y^*)'' = A e^x$$
    把 $y^*, (y^*)', (y^*)''$ 代入原方程 $y'' - 5y' + 6y = 2e^x$ 中：
    $$A e^x - 5(A e^x) + 6(A e^x) = 2e^x$$
3.  **解出待定系数 $A$**：
    合并同类项：
    $$(1 - 5 + 6) A e^x = 2e^x$$
    $$2A e^x = 2e^x$$
    对比两边系数，显然有 $2A = 2$，解得 **$A = 1$**。
    所以，非齐次方程的一个特解为：
    $$y^* = 1 \cdot e^x = e^x$$

#### 第三步：写出原方程的通解 $y$
根据原理：**原方程通解 = 齐次方程通解 + 非齐次方程特解** ($y = Y + y^*$)。
将第一步和第二步的结果相加：
$$y = C_1 e^{2x} + C_2 e^{3x} + e^x$$
*(这就是该微分方程的一般通解，代表了无数条曲线)*

#### 第四步：代入初始条件，求出特定的 $C_1$ 和 $C_2$
题目给定了初始条件：$y(0) = 1$ 且 $y'(0) = 0$。我们需要用它们来确定 $C_1$ 和 $C_2$ 的具体数值。

1.  **利用 $y(0) = 1$**：
    把 $x = 0$ 代入通解式中（注意 $e^0 = 1$）：
    $$y(0) = C_1 e^0 + C_2 e^0 + e^0 = C_1 + C_2 + 1$$
    因为 $y(0) = 1$，所以：
    $$C_1 + C_2 + 1 = 1 \implies C_1 + C_2 = 0 \quad \text{—— (式 ①)}$$

2.  **利用 $y'(0) = 0$**：
    先对通解 $y$ 求导：
    $$y' = 2C_1 e^{2x} + 3C_2 e^{3x} + e^x$$
    把 $x = 0$ 代入导数式中：
    $$y'(0) = 2C_1 e^0 + 3C_2 e^0 + e^0 = 2C_1 + 3C_2 + 1$$
    因为 $y'(0) = 0$，所以：
    $$2C_1 + 3C_2 + 1 = 0 \implies 2C_1 + 3C_2 = -1 \quad \text{—— (式 ②)}$$

3.  **联立方程组求 $C_1, C_2$**：
    由 (式 ①) 得到 $C_2 = -C_1$，代入 (式 ②) 中：
    $$2C_1 + 3(-C_1) = -1$$
    $$-C_1 = -1 \implies C_1 = 1$$
    进而得出：
    $$C_2 = -1$$

#### 最终结果
将 $C_1 = 1, C_2 = -1$ 代回通解，得到满足初始条件的唯一特解：
$$y = e^{2x} - e^{3x} + e^x$$

---

**小贴士（验算）：**
你可以把最终答案求两次导，代入 $y'' - 5y' + 6y$ 看看结果是不是等于 $2e^x$；再把 $x=0$ 代入看看 $y$ 是否等于 1，$y'$ 是否等于 0。这能保证你的计算 100% 准确！
