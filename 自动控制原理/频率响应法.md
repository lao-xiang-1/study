# 频率响应法

## 1. 基本概念

频率特性: 稳态响应与输入信号的复数比

频率特性的指数形式可以表示为：

$G(j\omega) = A(\omega) e^{j\phi(\omega)}$

其中：
- $A(\omega) = |G(j\omega)|$ 称为**幅频特性**，表示输出信号与输入信号的幅值比随频率 $\omega$ 变化的规律。
- $\phi(\omega) = \angle G(j\omega)$ 称为**相频特性**（Phase Frequency Characteristic），表示输出信号与输入信号的相位差随频率 $\omega$ 变化的规律。

如果将频率特性写成代数形式 $G(j\omega) = U(\omega) + jV(\omega)$（其中 $U(\omega)$ 为实频特性，$V(\omega)$ 为虚频特性），那么它们与指数形式的关系为：

- 幅频特性：$A(\omega) = \sqrt{U^2(\omega) + V^2(\omega)}$
- 相频特性：$\phi(\omega) = \arctan \left( \frac{V(\omega)}{U(\omega)} \right)$

## Nyquist图详解

### 1. 基本概念

**Nyquist图**（奈奎斯特图）是将频率特性 $G(j\omega)$ 以**极坐标形式**绘制在复平面上的曲线。

- 横轴：实部 $\operatorname{Re}[G(j\omega)]$ -> $X(\omega)$
- 纵轴：虚部 $\operatorname{Im}[G(j\omega)]$ -> $Y(\omega)$
- 参数：频率 $\omega$ 从 $0$ 变化到 $+\infty$

**核心思想**：利用**复变函数映射定理**（Cauchy定理），通过开环频率特性曲线对临界点 $(-1,j0)$ 的**包围情况**来判断闭环系统的稳定性。

**Nyquist曲线完整绘制**：
- 绘制 $\omega:0^+\to +\infty$ 的曲线（实线）
- 补上 $\omega:-\infty\to 0^-$ 的**镜像对称**曲线（虚线）
- 若存在 $s=0$ 处的极点，需用半径无穷大的顺时针半圆封闭

### 2. Nyquist图绘制步骤与技巧

1. **确定起点**（$\omega=0$ 时）：
   - Ⅰ型系统（含一个积分环节）：起点在无穷远处，相角 $-90^\circ$
   - Ⅱ型系统：起点在无穷远处，相角 $-180^\circ$

2. **确定终点**（$\omega\to\infty$ 时）：
   - 系统相对阶次 $n-m>0$ 时，终点趋近于原点
   - 相对阶次每增加1，终点相角多转 $-90^\circ$

3. **与实轴交点**（相位交界频率 $\omega_c$）：
   - 令 $\angle G(j\omega)=-180^\circ$，求 $|G(j\omega)|$

4. **与虚轴交点**（增益交界频率 $\omega_g$）：
   - 令 $|G(j\omega)|=1$，求 $\angle G(j\omega)$

5. **典型环节对曲线形状的影响**：
   - 积分环节：使曲线**顺时针旋转** $90^\circ$
   - 惯性环节：使曲线向**原点弯曲**
   - 微分环节：使曲线**逆时针旋转** $90^\circ$

**绘制原则**：先画**渐近线**，再找**关键交点**，最后用**光滑曲线**连接。

### 3. Nyquist稳定判据（核心公式）

设：
- $P$ = 开环传递函数 $G(s)H(s)$ 在右半 $s$ 平面的极点个数（不稳定开环极点）
- $N$ = Nyquist曲线**逆时针**包围临界点 $(-1,j0)$ 的次数（顺时针包围记为负）
- $Z$ = 闭环系统在右半 $s$ 平面的极点个数（不稳定闭环极点）

则有映射定理关系：
$$
Z = P - N
$$

**系统稳定的充要条件**：$Z=0$，即：
$$
N = P
$$

**实际判断方法**：
- 若开环稳定（$P=0$），则Nyquist曲线**不能包围** $(-1,j0)$ 点（$N=0$）
- 若开环不稳定（$P\neq0$），曲线必须**逆时针包围** $(-1,j0)$ 点恰好 $P$ 次

> **注意**：教材中“包围次数”的正负定义可能略有差异，胡寿松版以**逆时针为正**。

## 典型环节的频率特性

以下是去掉Bode图特征后，八种常见典型环节的基本频率特性（传递函数、幅频、相频）与对数频率特性（对数幅频）的完整整合：

在频域分析中，传递函数 $G(s)$ 令 $s = j\omega$ 得到频率特性 $G(j\omega)$。其中，幅频特性为 $A(\omega) = |G(j\omega)|$，相频特性为 $\phi(\omega) = \angle G(j\omega)$，对数幅频特性为 $L(\omega) = 20 \lg A(\omega)$（单位：分贝 dB）。

- **比例环节 (Proportional Element)**
  - **传递函数**：$G(s) = K$ （$K > 0$）
  - **频率特性**：$G(j\omega) = K$
  - **幅频特性**：$A(\omega) = K$
  - **对数幅频特性**：$L(\omega) = 20 \lg K$
  - **相频特性**：$\phi(\omega) = 0^\circ$

- **积分环节 (Integral Element)**
  - **传递函数**：$G(s) = \frac{1}{s}$
  - **频率特性**：$G(j\omega) = \frac{1}{j\omega} = -j\frac{1}{\omega}$
  - **幅频特性**：$A(\omega) = \frac{1}{\omega}$
  - **对数幅频特性**：$L(\omega) = -20 \lg \omega$
  - **相频特性**：$\phi(\omega) = -90^\circ$

- **微分环节 (Derivative Element)**
  - **传递函数**：$G(s) = s$
  - **频率特性**：$G(j\omega) = j\omega$
  - **幅频特性**：$A(\omega) = \omega$
  - **对数幅频特性**：$L(\omega) = 20 \lg \omega$
  - **相频特性**：$\phi(\omega) = 90^\circ$

- **惯性环节 / 一阶滞后环节 (Inertial Element)**
  - **传递函数**：$G(s) = \frac{1}{Ts+1}$ （$T$ 为时间常数）
  - **频率特性**：$G(j\omega) = \frac{1}{1 + j\omega T}$
  - **幅频特性**：$A(\omega) = \frac{1}{\sqrt{1 + (\omega T)^2}}$
  - **对数幅频特性**：$L(\omega) = -20 \lg \sqrt{1 + (\omega T)^2}$
  - **相频特性**：$\phi(\omega) = -\arctan(\omega T)$

- **一阶微分环节 (First-order Derivative Element)**
  - **传递函数**：$G(s) = \tau s + 1$
  - **频率特性**：$G(j\omega) = 1 + j\omega \tau$
  - **幅频特性**：$A(\omega) = \sqrt{1 + (\omega \tau)^2}$
  - **对数幅频特性**：$L(\omega) = 20 \lg \sqrt{1 + (\omega \tau)^2}$
  - **相频特性**：$\phi(\omega) = \arctan(\omega \tau)$

- **振荡环节 / 二阶滞后环节 (Oscillatory Element)**
  - **传递函数**：$G(s) = \frac{1}{T^2 s^2 + 2\zeta T s + 1}$ （$0 < \zeta < 1$）
  - **频率特性**：$G(j\omega) = \frac{1}{1 - \omega^2 T^2 + j2\zeta\omega T}$
  - **幅频特性**：$A(\omega) = \frac{1}{\sqrt{(1 - \omega^2 T^2)^2 + (2\zeta\omega T)^2}}$
  - **对数幅频特性**：$L(\omega) = -20 \lg \sqrt{(1 - \omega^2 T^2)^2 + (2\zeta\omega T)^2}$
  - **相频特性**：$\phi(\omega) = -\arctan\left(\frac{2\zeta\omega T}{1 - \omega^2 T^2}\right)$

- **二阶微分环节 (Second-order Derivative Element)**
  - **传递函数**：$G(s) = T^2 s^2 + 2\zeta T s + 1$
  - **频率特性**：$G(j\omega) = 1 - \omega^2 T^2 + j2\zeta\omega T$
  - **幅频特性**：$A(\omega) = \sqrt{(1 - \omega^2 T^2)^2 + (2\zeta\omega T)^2}$
  - **对数幅频特性**：$L(\omega) = 20 \lg \sqrt{(1 - \omega^2 T^2)^2 + (2\zeta\omega T)^2}$
  - **相频特性**：$\phi(\omega) = \arctan\left(\frac{2\zeta\omega T}{1 - \omega^2 T^2}\right)$

- **延迟环节 (Delay Element)**
  - **传递函数**：$G(s) = e^{-\tau s}$ （$\tau$ 为延迟时间）
  - **频率特性**：$G(j\omega) = e^{-j\omega \tau}$
  - **幅频特性**：$A(\omega) = 1$
  - **对数幅频特性**：$L(\omega) = 20 \lg 1 = 0$
  - **相频特性**：$\phi(\omega) = -\omega \tau$ （弧度）或 $-\omega \tau \times \frac{180^\circ}{\pi}$ （角度）


## 惯性环节bode图幅频曲线渐进线详解

### 1. 基本公式
- 传递函数：$G(s) = \frac{1}{Ts + 1}$ （其中 $T$ 为时间常数，$T > 0$）
- 频率特性：将 $s = j\omega$ 代入，得到 $G(j\omega) = \frac{1}{j\omega T + 1}$
- 精确对数幅频特性：$$L(\omega) = 20 \lg |G(j\omega)| = 20 \lg \left( \frac{1}{\sqrt{1 + (\omega T)^2}} \right) = -20 \lg \sqrt{1 + \omega^2 T^2}$$

### 2. 渐近线的划分（转折频率）
为了简化上述复杂的对数函数，我们根据 $\omega T$ 与 $1$ 的大小关系，将频率范围分为低频段和高频段。分界点称为**转折频率**（或交接频率）：
- **转折频率**：$\omega_c = \frac{1}{T}$

### 3. 低频段渐近线（$\omega \ll \frac{1}{T}$）
- 当 $\omega$ 远小于 $\frac{1}{T}$ 时，$\omega T \ll 1$。
- 此时根号内的 $\omega^2 T^2$ 可以忽略不计，即 $1 + \omega^2 T^2 \approx 1$。
- 幅频特性近似为：$L(\omega) \approx -20 \lg \sqrt{1} = 0 \text{ dB}$
- **结论**：低频段渐近线是一条重合于横轴（$0 \text{ dB}$）的**水平直线**，斜率为 $0 \text{ dB/dec}$。

### 4. 高频段渐近线（$\omega \gg \frac{1}{T}$）
- 当 $\omega$ 远大于 $\frac{1}{T}$ 时，$\omega T \gg 1$。
- 此时根号内的 $1$ 可以忽略不计，即 $1 + \omega^2 T^2 \approx \omega^2 T^2$。
- 幅频特性近似为：$$L(\omega) \approx -20 \lg \sqrt{\omega^2 T^2} = -20 \lg(\omega T) = -20 \lg \omega - 20 \lg T$$
- **结论**：高频段渐近线是一条**斜率为 $-20 \text{ dB/dec}$ 的直线**（即频率每增加十倍，幅值下降 $20 \text{ dB}$）。这条直线如果向低频方向延长，它与 $\omega$ 轴（$0 \text{ dB}$ 线）的交点正好是 $\omega = \frac{1}{T}$。

### 5. 渐近线的误差分析
使用折线（渐近线）代替实际平滑曲线会产生误差，误差在转折频率 $\omega_c = \frac{1}{T}$ 处达到最大：
- **实际值**：在 $\omega = \frac{1}{T}$ 时，精确值为 $L(\frac{1}{T}) = -20 \lg \sqrt{1 + 1^2} = -20 \lg \sqrt{2} \approx -3 \text{ dB}$。
- **渐近线值**：在 $\omega = \frac{1}{T}$ 时，渐近线的值为 $0 \text{ dB}$。
- **最大误差**：在转折频率处，实际曲线在渐近线下方约 **$3 \text{ dB}$** 处。
- **其他点误差**：在 $\omega = \frac{1}{2T}$ 和 $\omega = \frac{2}{T}$ 处（即转折频率的二分之一和两倍处），误差约为 **$1 \text{ dB}$**。

### 总结绘制步骤
在绘制惯性环节 $G(s) = \frac{1}{Ts+1}$ 的 Bode 图幅频曲线时，通常只需两步：
1. 找到转折频率 $\omega_c = \frac{1}{T}$。
2. 在 $\omega < \frac{1}{T}$ 处画一条 $0 \text{ dB}$ 的水平线；在 $\omega > \frac{1}{T}$ 处，从转折频率点开始画一条斜率为 $-20 \text{ dB/dec}$ 的下降直线。
*(如果需要高精度，可以在转折频率处向下偏移 3dB 画一条平滑的过渡曲线将两条直线连接起来。)*
