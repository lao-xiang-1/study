# 图像的矩（Moments）

## 1. 什么是图像的矩

图像的矩（Image Moments）是图像像素灰度值的一种**加权求和**统计量，类比于概率论中随机变量的"矩"。它将图像的像素分布用一个有限维的数值特征来描述，从而提取出目标的**几何特征**，如面积、质心、方向、形状等。

> 直观理解：矩就是对图像像素进行加权求和，不同阶数的矩反映图像不同层次的特征——零阶矩是面积，一阶矩确定质心，二阶矩描述形状和方向。

---

## 2. 矩的数学定义

### 2.1 空间矩（Spatial Moments / Raw Moments）

对于一幅图像 $f(x,y)$（可以是灰度图或二值图），其 $(p+q)$ 阶空间矩定义为：

$$
M_{pq} = \sum_{x}\sum_{y} x^p \, y^q \, f(x,y)
$$

- $p, q$ 为非负整数，$p+q$ 为矩的**阶数（order）**
- 对于二值图像，$f(x,y) \in \{0, 1\}$，只统计前景像素
- 对于灰度图像，$f(x,y)$ 为该点的灰度值（加权矩）

**低阶空间矩的含义：**

| 矩 | 公式 | 含义 |
:---:|:---|:---|
| $M_{00}$ | $\sum\sum f(x,y)$ | 图像的"总质量"（二值图中 = 前景面积/像素数） |
| $M_{10}$ | $\sum\sum x \cdot f(x,y)$ | $x$ 方向的一阶矩 |
| $M_{01}$ | $\sum\sum y \cdot f(x,y)$ | $y$ 方向的一阶矩 |
| $M_{20}$ | $\sum\sum x^2 \cdot f(x,y)$ | $x$ 方向的二阶矩 |
| $M_{02}$ | $\sum\sum y^2 \cdot f(x,y)$ | $y$ 方向的二阶矩 |
| $M_{11}$ | $\sum\sum x \cdot y \cdot f(x,y)$ | $xy$ 交叉二阶矩 |

---

### 2.2 质心（Centroid）

利用空间矩可以直接计算目标的质心坐标：

$$
\bar{x} = \frac{M_{10}}{M_{00}}, \quad \bar{y} = \frac{M_{01}}{M_{00}}
$$

> 当 $M_{00} = 0$ 时（无前景像素），质心无定义，需要特殊处理。

---

### 2.3 中心矩（Central Moments）

空间矩依赖于坐标系的原点位置，**平移会改变空间矩的值**。为消除平移影响，引入中心矩——以质心 $(\bar{x}, \bar{y})$ 为原点：

$$
\mu_{pq} = \sum_{x}\sum_{y} (x - \bar{x})^p \, (y - \bar{y})^q \, f(x,y)
$$

**中心矩具有平移不变性**：图像整体平移后，中心矩不变。

**常用中心矩：**

| 矩 | 含义 |
:---:|:---|
| $\mu_{00} = M_{00}$ | 与零阶空间矩相同（面积） |
| $\mu_{10} = \mu_{01} = 0$ | 因为以质心为原点，一阶中心矩恒为零 |
| $\mu_{20}$ | 反映目标在 $x$ 方向的分散程度（类似方差） |
| $\mu_{02}$ | 反映目标在 $y$ 方向的分散程度 |
| $\mu_{11}$ | 反映目标的 $xy$ 协方差（倾斜程度） |

> 空间矩与中心矩的转换关系（由二项式展开可得）：
> $$\mu_{pq} = \sum_{i=0}^{p}\sum_{j=0}^{q} \binom{p}{i}\binom{q}{j} (-\bar{x})^{p-i} (-\bar{y})^{q-j} M_{ij}$$

---

### 2.4 归一化中心矩（Normalized Central Moments）

中心矩虽然消除了平移影响，但仍受**缩放（尺度）** 影响。归一化中心矩进一步消除尺度变化：

$$
\eta_{pq} = \frac{\mu_{pq}}{\mu_{00}^{\gamma}}, \quad \gamma = \frac{p+q}{2} + 1 \quad (p+q \geq 2)
$$

**归一化中心矩同时具有平移不变性和尺度不变性。**

---

## 3. Hu 矩（Hu Moments）——旋转不变矩

### 3.1 概念

1962 年，Ming-Kuei Hu 基于归一化中心矩构造了 **7 个不变矩**，这 7 个矩同时对**平移、缩放、旋转**保持不变。这在物体识别和模板匹配中非常有用。

### 3.2 七个 Hu 矩公式

$$
\begin{aligned}
h_1 &= \eta_{20} + \eta_{02} \\
h_2 &= (\eta_{20} - \eta_{02})^2 + 4\eta_{11}^2 \\
h_3 &= (\eta_{30} - 3\eta_{12})^2 + (3\eta_{21} - \eta_{03})^2 \\
h_4 &= (\eta_{30} + \eta_{12})^2 + (\eta_{21} + \eta_{03})^2 \\
h_5 &= (\eta_{30} - 3\eta_{12})(\eta_{30} + \eta_{12})[(\eta_{30} + \eta_{12})^2 - 3(\eta_{21} + \eta_{03})^2] \\
    &\quad + (3\eta_{21} - \eta_{03})(\eta_{21} + \eta_{03})[3(\eta_{30} + \eta_{12})^2 - (\eta_{21} + \eta_{03})^2] \\
h_6 &= (\eta_{20} - \eta_{02})[(\eta_{30} + \eta_{12})^2 - (\eta_{21} + \eta_{03})^2] \\
    &\quad + 4\eta_{11}(\eta_{30} + \eta_{12})(\eta_{21} + \eta_{03}) \\
h_7 &= (3\eta_{21} - \eta_{03})(\eta_{30} + \eta_{12})[(\eta_{30} + \eta_{12})^2 - 3(\eta_{21} + \eta_{03})^2] \\
    &\quad - (\eta_{30} - 3\eta_{12})(\eta_{21} + \eta_{03})[3(\eta_{30} + \eta_{12})^2 - (\eta_{21} + \eta_{03})^2]
\end{aligned}
$$

> - $h_1$ ~ $h_6$ 具有镜像（反射）不变性
> - $h_7$ **不具有镜像不变性**，可以区分目标与其镜像（即手性判断）
> - 实际应用中，通常对 Hu 矩取**对数**（$\log|h_i|$）来压缩数值范围，避免浮点溢出

## 4. OpenCV 中的实现

### 4.1 cv2.moments()

```python
import cv2
import numpy as np

# 读取图像并转为二值图
img = cv2.imread('shape.png', cv2.IMREAD_GRAYSCALE)
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)

# 查找轮廓
contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 计算某个轮廓的矩
cnt = contours[0]
M = cv2.moments(cnt)

# M 是一个字典，包含所有计算出的矩
print(M)
# 输出示例：{'m00': 12345.0, 'm10': 617250.0, 'm01': 370350.0, ...}
```

**参数说明：**

```python
cv2.moments(array, binaryImage=False)
```

- `array`：轮廓点集（`contours[i]`）或光栅图像（2D array）
- `binaryImage`：`True` 时将非零像素视为 1（二值图模式）；`False` 时使用实际灰度值
- 返回值：字典，键为 `m00, m10, m01, mu20, mu11, mu02, nu02, ...` 等

**返回的字典包含：**

| 键 | 含义 |
:---|:---|
| `m00, m10, m01, ...` | 空间矩 $M_{pq}$ |
| `mu20, mu11, mu02, mu30, ...` | 中心矩 $\mu_{pq}$ |
| `nu20, nu11, nu02, nu30, ...` | 归一化中心矩 $\eta_{pq}$ |

---

### 4.2 利用矩计算质心和面积

```python
M = cv2.moments(cnt)

# 面积（零阶矩）
area = M['m00']

# 质心坐标
if M['m00'] != 0:
    cx = int(M['m10'] / M['m00'])
    cy = int(M['m01'] / M['m00'])
else:
    cx, cy = 0, 0

print(f"面积: {area}")
print(f"质心: ({cx}, {cy})")

# 在图像上标记质心
cv2.circle(img, (cx, cy), 5, (0, 0, 255), -1)
```

> 对比：`cv2.contourArea(cnt)` 底层就是用 $M_{00}$ 计算的（通过格林公式求面积），结果等价于 `M['m00']`。

---

### 4.3 利用矩计算目标方向（Orientation）

利用二阶中心矩可以拟合目标为一个**等效椭圆**，并求出其倾斜角度：

$$
\theta = \frac{1}{2} \arctan\left(\frac{2\mu_{11}}{\mu_{20} - \mu_{02}}\right)
$$

```python
M = cv2.moments(cnt)

# 目标方向角（弧度）
theta = 0.5 * np.arctan2(2 * M['mu11'], M['mu20'] - M['mu02'])
theta_deg = np.degrees(theta)
print(f"方向角: {theta_deg:.1f}°")
```

> 这等价于对目标的协方差矩阵 $\begin{pmatrix} \mu_{20} & \mu_{11} \\ \mu_{11} & \mu_{02} \end{pmatrix}$ 做特征值分解，长轴方向即为目标主方向。

---

### 4.4 等效椭圆拟合

由二阶中心矩可以得到与目标具有相同质心和面积的椭圆参数：

```python
# 等效椭圆的长短轴和旋转角
(x, y), (MA, ma), angle = cv2.fitEllipse(cnt)

# 或手动从矩计算
M = cv2.moments(cnt)
mu20 = M['mu20'] / M['m00']
mu02 = M['mu02'] / M['m00']
mu11 = M['mu11'] / M['m00']

# 协方差矩阵的特征值
delta = np.sqrt((mu20 - mu02)**2 + 4 * mu11**2)
lambda1 = (mu20 + mu02 + delta) / 2  # 大特征值 → 长轴方向
lambda2 = (mu20 + mu02 - delta) / 2  # 小特征值 → 短轴方向

# 等效椭圆长短半轴（4倍是为了匹配实际目标尺度）
a = 2 * np.sqrt(lambda1)  # 长半轴
b = 2 * np.sqrt(lambda2)  # 短半轴
```

### 4.5 cv2.HuMoments()

```python
M = cv2.moments(cnt)
hu = cv2.HuMoments(M)

print(hu)
# 输出 7×1 的数组，即 h1~h7

# 通常取对数压缩
hu_log = -np.sign(hu) * np.log10(np.abs(hu) + 1e-30)
print(hu_log.flatten())
```

**参数说明：**

```python
cv2.HuMoments(moments)
```

- `moments`：`cv2.moments()` 的返回值（字典）
- 返回值：$7 \times 1$ 的 `float64` 数组

---

### 4.6 cv2.matchShapes() —— 基于 Hu 矩的形状匹配

```python
# 比较两个轮廓的形状相似度
ret = cv2.matchShapes(cnt1, cnt2, cv2.CONTOURS_MATCH_I1, 0.0)
print(f"形状相似度: {ret}")  # 值越小越相似
```

**匹配方法（method 参数）：**

| 方法 | 公式 |
:---|:---|
| `cv2.CONTOURS_MATCH_I1` | $\sum_{i=1}^{7} \|m_i^A - m_i^B\|$，其中 $m_i = \text{sign}(h_i)\log|h_i|$ |
| `cv2.CONTOURS_MATCH_I2` | $\sum_{i=1}^{7} \frac{\|m_i^A - m_i^B\|}{\|m_i^A\|}$ |
| `cv2.CONTOURS_MATCH_I3` | $\max_i \frac{\|m_i^A - m_i^B\|}{\|m_i^A\|}$ |

> 返回值越小表示两个形状越相似；返回 0 表示完全一致。

## 5. 矩的体系总结

```
空间矩 M_pq（平移相关）
  │
  ├──→ 质心 (x̄, ȳ) = (M₁₀/M₀₀, M₀₁/M₀₀)
  │
  ▼
中心矩 μ_pq（平移不变）
  │
  ▼
归一化中心矩 η_pq（平移 + 尺度不变）
  │
  ▼
Hu 矩 h₁~h₇（平移 + 尺度 + 旋转不变）
```

| 矩类型 | 平移不变 | 尺度不变 | 旋转不变 |
:---|:---:|:---:|:---:|
| 空间矩 | ✗ | ✗ | ✗ |
| 中心矩 | ✓ | ✗ | ✗ |
| 归一化中心矩 | ✓ | ✓ | ✗ |
| Hu 矩 | ✓ | ✓ | ✓ |

---

## 6. 典型应用场景

- **目标检测与识别**：用 Hu 矩作为形状描述子，判断目标类型（圆形、方形、不规则形状）
- **形状匹配**：`matchShapes()` 比较两个轮廓的相似度
- **目标跟踪**：通过质心变化追踪目标运动轨迹
- **图像分析**：利用矩判断目标方向、偏心率、面积等几何属性
- **缺陷检测**：比较标准件与待检件的 Hu 矩差异

---

## 7. 完整示例

```python
import cv2
import numpy as np

# 1. 读取并二值化
img = cv2.imread('shapes.png')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# 2. 查找轮廓
contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

for i, cnt in enumerate(contours):
    # 3. 计算矩
    M = cv2.moments(cnt)
    area = M['m00']

    # 4. 质心
    if area > 0:
        cx = int(M['m10'] / area)
        cy = int(M['m01'] / area)
        cv2.circle(img, (cx, cy), 5, (0, 255, 0), -1)

    # 5. Hu 矩
    hu = cv2.HuMoments(M).flatten()
    hu_log = -np.sign(hu) * np.log10(np.abs(hu) + 1e-30)

    # 6. 方向角
    theta = 0.5 * np.arctan2(2 * M['mu11'], M['mu20'] - M['mu02'])

    print(f"轮廓 {i}: 面积={area:.0f}, 质心=({cx},{cy}), "
          f"方向={np.degrees(theta):.1f}°")
    print(f"  Hu矩(log): {hu_log.round(2)}")

cv2.imshow('Result', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```
