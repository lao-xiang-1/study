
## OTSU二值化算法
大津法（OTSU）由日本学者大津展之在1979年提出，是一种**完全基于图像直方图、自动选取全局最佳阈值**的算法。它的核心思想是：找到一个阈值 $t$，将图像像素分为**前景**和**背景**两类，使得这两类之间的**类间方差最大**（尽可能的分开两类）。

>OTSU 适用于**具有双峰直方图的图像**（前景和背景灰度分布明显分离）

---

### 1. 问题建模
设灰度图像 的 总像素数 $N$。  
灰度级 $i$ 的像素个数为 $n_i$，其概率为：
$$
p_i = \frac{n_i}{N}
$$
概率之和为1：$$\sum_{i=0}^{L-1} p_i = 1$$
选择一个阈值 $t$，将像素划分为两类：
- 背景（暗） $C_0$：灰度级 $[0, t]$
- 前景（亮） $C_1$：灰度级 $[t+1, L-1]$

---

### 2. 核心推导：最大化类间方差

#### 2.1 各参数定义
>认为背景的灰度值低，而前景的高

$\omega_0$：背景的概率
$\omega_1$：前景的概率

$\mu_0$：背景的平均灰度
$\mu_1$：前景的平均灰度

$\mu_T$：全局平均灰度

#### 2.2 类间方差定义
>$\sigma_0^2$ ：背景方差
>$\sigma_1^2$：前景方差
>$\sigma_W^2(t)$：类内方差
>$\sigma_B^2(t)$：类间方差
>$\sigma_T^2$：总方差

类间方差衡量的是两类均值相对于全局均值的离散程度：
$$
\sigma_B^2(t) = \omega_0(\mu_0 - \mu_T)^2 + \omega_1(\mu_1 - \mu_T)^2
$$
代入 $\mu_T = \omega_0\mu_0 + \omega_1\mu_1$ 可化简为更常用的形式：
$$
\sigma_B^2(t) = \omega_0(t)\,\omega_1(t)\,[\,\mu_0(t) - \mu_1(t)\,]^2
$$

**OTSU 的最佳阈值 $t^*$ 就是使 $\sigma_B^2(t)$ 取得最大值的 $t$：**
$$
t^* = \arg\max_{0 \le t < L} \sigma_B^2(t)
$$

> 同时，类间方差最大化 **等价于类内方差最小化**，因为图像的总方差 $\sigma_T^2$ 是固定的常数：
>$$\sigma_T^2 = \sigma_W^2(t) + \sigma_B^2(t)$$
>   其中 $\sigma_W^2(t) = \omega_0\sigma_0^2 + \omega_1\sigma_1^2$ 是类内方差。最大化 $\sigma_B^2$ 就是最小化 $\sigma_W^2$，使得每一类内部的像素灰度尽量“纯净”。

---

### 3. 算法步骤
1. 计算灰度直方图并归一化，得到概率数组 `p[0..255]`。
2. 遍历所有可能的阈值 `t = 0, 1, …, 254`（或 255，但分为空类无意义）：
   - 计算累积概率 `ω0` 和累积均值 `μ_temp = Σ i*p[i]`，进而求得：
     - `μ0 = μ_temp / ω0` （若 ω0=0，则 μ0=0）
     - `μ1 = (μT - μ_temp) / (1 - ω0)` （若 ω1=0，则 μ1=0）
   - 计算类间方差 `σB2 = ω0 * (1-ω0) * (μ0 - μ1)^2`
   - 若当前 `σB2` 大于最大值，更新最佳阈值 `t*`
3. 用得到的最佳阈值 `t*` 对原图进行二值化。

实际实现中可以**增量计算**避免重复求和，加快速度。

---

### 4. OpenCV 中的应用
OpenCV 提供了封装好的 OTSU，只需在 `cv2.threshold()` 的类型参数中组合 `cv2.THRESH_OTSU` 即可。

```python
import cv2

img = cv2.imread('input.jpg', 0)  # 灰度图
ret, otsu_binary = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(f"OTSU 计算的最佳阈值: {ret}")

cv2.imshow('OTSU Binary', otsu_binary)
cv2.waitKey(0)
```
- 函数返回的 `ret` 就是自动计算出的最佳阈值 `t*`。
- 此时手动设置的阈值 `0` 会被忽略。

---

### 5. 直观理解与适用条件
OTSU 最适用于**具有双峰直方图的图像**（前景和背景灰度分布明显分离）。例如：
- 文档扫描件：浅色背景 + 深色文字
- 工件缺陷检测：均匀表面 + 深色划痕

当直方图为单峰或受噪声严重干扰时，OTSU 可能会给出一个偏离理想阈值的结果，这时就需要考虑**自适应阈值**或预处理去噪。

## adaptiveThreshold自适应阈值

OTSU 和固定阈值都是**全局阈值**：整幅图共用同一个 $t$。一旦图像光照不均（一侧亮、一侧暗），无论 $t$ 取多少，都会出现“亮处过曝、暗处全黑”的情况。**自适应阈值（Adaptive Threshold）**的思路是：让阈值随位置变化，每个像素都用**自己邻域内统计出的阈值**来判定。

---

### 1. 问题建模

全局阈值可以写成：
$$
g(x,y) =
\begin{cases}
255, & f(x,y) > t \\[4pt]
0,   & f(x,y) \le t
\end{cases}
$$
其中 $f(x,y)$ 是原图灰度，$g(x,y)$ 是输出。问题在于 $t$ 是常数。

自适应阈值把常数 $t$ 换成**位置相关的阈值函数** $T(x,y)$：
$$
g(x,y) =
\begin{cases}
255, & f(x,y) > T(x,y) \\[4pt]
0,   & f(x,y) \le T(x,y)
\end{cases}
$$

> $T(x,y)$ 由 $(x,y)$ 周围一个小窗口 $S_{xy}$ 内的像素统计得到，所以光照缓慢变化时，阈值也跟着一起变，从而抵消光照不均的影响。

---

### 2. 邻域阈值的两种计算方式

设邻域窗口 $S_{xy}$ 的大小为 $\text{blockSize} \times \text{blockSize}$，窗口内像素个数为 $n$。

#### 2.1 均值法（Mean）

$$
T(x,y) = \frac{1}{n}\sum_{(i,j)\in S_{xy}} f(i,j) \;-\; C
$$

即邻域**算术平均**再减去常数 $C$。

#### 2.2 高斯加权法（Gaussian）

$$
T(x,y) = \sum_{(i,j)\in S_{xy}} w(i,j)\, f(i,j) \;-\; C,
\qquad \sum_{(i,j)\in S_{xy}} w(i,j) = 1
$$

其中 $w(i,j)$ 是二维高斯核的权重：离中心越近权重越大，越远越小。

> 两种方式只差在“均值”怎么算。高斯法对**中心像素更敏感**、对远处的干扰更钝，边缘处过渡更平滑，抗噪性更好；均值法计算更简单，但对窗口内的离群点（噪声）一视同仁。

#### 2.3 关于常数 $C$

$C$ 是一个**偏置项**，从算出的均值中**减去**：

- $C$ 越大 $\Rightarrow$ 阈值 $T$ 越低 $\Rightarrow$ 条件 $f > T$ 越容易成立 $\Rightarrow$ **更多像素被判为前景（白）**。
- $C$ 可以为负，效果相反。

它的作用是**抑制噪声引起的误判**，是一个需要手动调节的经验参数。

#### 2.4 参数约束

- `blockSize` 必须是**大于 1 的奇数**（3、5、7、…），这样才能保证窗口有唯一的中心像素。
- 边界像素没有完整邻域，OpenCV 采用 `BORDER_REPLICATE | BORDER_ISOLATED`，即**复制边界像素**来补全窗口。

---

### 3. 算法步骤

1. 对每个像素 $(x,y)$，取以它为中心、大小为 $\text{blockSize}\times\text{blockSize}$ 的邻域 $S_{xy}$。
2. 计算该邻域的均值（或高斯加权均值）$m(x,y)$。
3. 求阈值 $T(x,y) = m(x,y) - C$。
4. 比较：若 $f(x,y) > T(x,y)$ 输出 `maxValue`，否则输出 0。
5. 对全图逐像素重复。

> 实现上并不真的对每个像素都重新求和：OpenCV 用 `boxFilter` / `GaussianBlur` 做**滑动窗口**的增量更新，相邻窗口只差一列（或一行）像素，因此每像素的均摊复杂度是 $O(1)$，与 `blockSize` 大小无关。

---

### 4. OpenCV 中的应用

```python
import cv2

img = cv2.imread('input.jpg', 0)   # 必须是 8 位单通道灰度图

# 均值法
mean_bin = cv2.adaptiveThreshold(
    img, 255,
    cv2.ADAPTIVE_THRESH_MEAN_C,      # 邻域均值
    cv2.THRESH_BINARY,
    blockSize=11,
    C=2)

# 高斯加权法
gauss_bin = cv2.adaptiveThreshold(
    img, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,  # 高斯加权
    cv2.THRESH_BINARY,
    blockSize=11,
    C=2)

cv2.imshow('mean', mean_bin)
cv2.imshow('gaussian', gauss_bin)
cv2.waitKey(0)
```

函数原型：
```python
cv2.adaptiveThreshold(src, maxValue, adaptiveMethod,
                      thresholdType, blockSize, C)
```

| 参数 | 含义 |
| :--- | :--- |
| `src` | 8 位单通道灰度图（`CV_8UC1`），**只支持这一种** |
| `maxValue` | 满足条件时赋的值，通常取 255 |
| `adaptiveMethod` | `ADAPTIVE_THRESH_MEAN_C`（均值）或 `ADAPTIVE_THRESH_GAUSSIAN_C`（高斯加权） |
| `thresholdType` | **只能是** `THRESH_BINARY` 或 `THRESH_BINARY_INV` |
| `blockSize` | 邻域窗口边长，大于 1 的奇数 |
| `C` | 从邻域均值中减去的常数偏置 |

> 注意 `thresholdType` 只允许 `BINARY` 和 `BINARY_INV` 两种，不能和 `THRESH_OTSU` 组合——OTSU 算的是**全局**阈值，与自适应的局部阈值在概念上互斥。

**调参经验：**
- `blockSize` 太小 $\Rightarrow$ 窗口内几乎全是噪声，结果出现大量“椒盐”噪点；太大 $\Rightarrow$ 阈值退化成接近全局阈值，失去自适应意义。
- 一般取 `blockSize ≈ 目标笔画/文字宽度的 1~2 倍`，例如文档文字用 11、15、21。
- 平坦区域的伪影：在灰度近似均匀的区域，邻域均值 $m \approx f(x,y)$，于是 $f - T = C$。
  - 若 $C > 0$，则 $f > T$ 恒成立，**整片平坦区域被染成白色**；
  - 若 $C < 0$，则整片被染成黑色。
  这是自适应阈值最常见的“大面积糊掉”现象，调小 $|C|$ 可以缓解。

---

### 5. 直观理解与适用条件

自适应阈值本质上是**局部对比度增强**：它不关心像素的绝对灰度，只关心“这个像素比周围亮还是暗”。因此特别适合**光照不均、背景渐变**的图像：

- 手机拍摄的文档：纸张一侧有阴影、光照不匀
- 条形码 / 车牌识别：需要先去除光照梯度
- 纹理表面的划痕、缺陷检测
- 显微图像中细胞与背景的分割

不适用或需要额外处理的情况：

- 图像整体对比度很低、目标与背景灰度本身接近时，局部均值区分不出来
- 噪声较大时，局部统计量本身就被噪声污染，**建议先用高斯滤波或中值滤波去噪**再调用
- 计算量比全局阈值大（虽然每像素均摊 $O(1)$，但仍是两次滤波的代价）

**与 OTSU 的对比：**

| 对比项 | OTSU | adaptiveThreshold |
| :--- | :--- | :--- |
| 阈值 | 全局唯一 $t^*$ | 逐像素 $T(x,y)$ |
| 依据 | 直方图，类间方差最大 | 邻域均值 / 高斯加权均值 |
| 适用 | 双峰直方图、光照均匀 | 光照不均、背景渐变 |
| 参数 | 无（自动） | `blockSize`、`C` 需人工调 |
| 速度 | 快（一遍直方图） | 较慢（两遍滤波） |

> 实践中常见的组合：先做光照校正（如顶帽变换、形态学闭运算）再用 OTSU，效果与自适应阈值相近且结果更“干净”；自适应阈值则胜在实现简单、无需预处理。
