**grep** 是 Linux/Unix 中最强大的文本搜索工具，全称是 **Global Regular Expression Print**（全局正则表达式打印）。它的核心功能是：**在文件或输入流中，逐行搜索匹配指定模式（Pattern）的文本，并将匹配的行打印出来。**

### 1. 最基础语法（入门三件套）
```bash
# 在文件中搜索
grep "关键字" 文件名.txt

# 在多个文件中搜索
grep "关键字" 文件1.txt 文件2.txt

# 从管道（其他命令的输出）中搜索
ps aux | grep "nginx"
```

### 2. 必记的实用选项（日常开发够用）
| 选项 | 全称/含义 | 实战场景 |
| :--- | :--- | :--- |
| **`-i`** | ignore-case（忽略大小写） | 搜日志时忘了大小写，用 `grep -i error` |
| **`-v`** | invert-match（反选） | 过滤掉空行或注释：`grep -v "^#"` |
| **`-n`** | line-number（显示行号） | 调试代码时快速定位到第几行 |
| **`-c`** | count（计数） | 只统计匹配了多少行，不显示内容 |
| **`-r` / `-R`** | recursive（递归） | 在当前文件夹及子文件夹所有文件中搜索 |
| **`-l`** | files-with-matches | 只列出包含匹配内容的**文件名**（不展示内容） |
| **`-E`** | Extended Regex（扩展正则） | **强烈推荐**，直接支持 `+`、`?`、`|` 等高级正则，不用加反斜杠 |
| **`-A 3`** / **`-B 2`** / **`-C 3`** | After / Before / Context | 显示匹配行的**后**3行、**前**2行、**前后**各3行（查日志堆栈必备） |

### 3. 正则表达式核心（灵魂所在）
grep 的精髓不在于"搜单词"，而在于"搜模式"。使用 `-E` 选项后，你可以这样玩：

- `^` 匹配行首：`grep -E "^ERROR"` （找以 ERROR 开头的行）
- `$` 匹配行尾：`grep -E "500$"` （找以 500 结尾的行）
- `.` 匹配任意单个字符：`grep -E "a.c"` （匹配 abc, a1c, a-c）
- `*` 匹配前面的字符 0 次或多次
- `+` 匹配前面的字符 1 次或多次：`grep -E "[0-9]+"` （匹配纯数字）
- `|` 或逻辑：`grep -E "error|fatal"` （匹配 error 或 fatal）
- `[ ]` 匹配集合内的字符：`grep -E "[Gg]rep"` （匹配 Grep 或 grep）

### 4. 实战中的黄金搭档
单独用 grep 较少，通常组合使用：

- **查看实时日志（动态过滤）**：`tail -f app.log | grep -i exception`
- **排除注释查看配置文件**：`grep -E -v "^$|^#" /etc/nginx/nginx.conf` （去掉空行和#开头的注释行）
- **只统计某个函数出现在多少个文件里**：`grep -rl "main()" ./src/ | wc -l`

### 5. 进阶冷知识（避开新手坑）
- **注意引号**：**强烈建议**把模式用**单引号** `' '` 括起来，防止 Shell 将 `$`、`*` 等特殊符号错误解析为环境变量。
- **关于 `egrep` 和 `fgrep`**：旧版系统有独立命令，但在现代 Linux 中，`egrep` 等同于 `grep -E`，`fgrep` 等同于 `grep -F`（快速搜索固定字符串）。建议直接使用 `grep -E`。
- **大文件提速**：如果不需要正则，只搜索固定字符串，加上 `-F` 或使用 `fgrep` 会显著提高搜索大文件的速度。
