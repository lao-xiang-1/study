`find` 是 Linux 中最强大、最常用的**文件查找命令**。`find` 会**实时遍历指定目录树**，根据文件名、类型、大小、时间、权限等极其丰富的条件进行精准搜索，并对搜索结果执行后续操作。

### 1. 基本语法结构

```bash
find [搜索路径] [匹配条件] [处理动作]
```

- **搜索路径**：指定从哪个目录开始找（默认为当前目录 `.`）。
- **匹配条件**：指定查找标准（如“名字叫什么”或“修改时间是什么时候”）。
- **处理动作**：对找出的文件做什么（如打印、删除、复制等）。


### 2. 核心匹配条件（按“找什么”分类）

#### ① 按文件名查找（最常用）
- **`-name "文件名"`**：严格区分大小写。
- **`-iname "文件名"`**：忽略大小写。
- **`-regex "正则"`**：使用正则表达式匹配完整路径。
- **通配符支持**：必须用引号括起来，防止 shell 扩展。

```bash
find /var/log -name "*.log"      # 查找所有 .log 结尾的文件
find . -iname "readme*"          # 查找 README, ReadMe 等
```

#### ② 按文件类型查找
- **`-type f`**：普通文件。
- **`-type d`**：目录。
- **`-type l`**：软链接。
- **`-type b`**：块设备。
- **`-type c`**：字符设备。

```bash
find /etc -type d -name "conf*"  # 在 /etc 下找名字以 conf 开头的目录
```

#### ③ 按文件大小查找
- **`-size +100M`**：大于 100MB（`+` 大于，`-` 小于，无符号等于）。
- 单位：`c`（字节）、`k`（KB）、`M`（MB）、`G`（GB）。

```bash
find / -size +1G -type f        # 查找全盘所有大于 1GB 的文件
find . -size -10k               # 查找小于 10KB 的小文件
```

#### ④ 按时间戳查找（最常用的运维技巧）
Linux 文件有三种时间，对应三个参数：

| 参数 | 含义 | 应用场景 |
| :--- | :--- | :--- |
| **`-mtime`** | **修改时间**（内容被改） | 找昨天改过的代码文件 |
| **`-ctime`** | **状态改变时间**（权限/硬链接数等被改） | 找昨天被改过权限的配置文件 |
| **`-atime`** | **访问时间**（被读取过） | 找昨天被日志分析脚本读过的文件 |

- **`+n`** 表示 **n 天之前**（超过 n 天），**`-n`** 表示 **n 天之内**（最近 n 天）。
- 还有分钟级别的变体：`-mmin`、`-cmin`、`-amin`。

```bash
find . -mtime -3                # 最近 3 天内修改过的文件
find /var/log -mtime +30 -type f # 30 天前修改的日志文件（可考虑归档）
find . -mmin -5                 # 最近 5 分钟内修改的文件
```

#### ⑤ 按权限和所有者查找
- **`-user username`**：按属主。
- **`-group groupname`**：按属组。
- **`-perm 644`**：精确权限匹配。
- **`-perm -644`**：文件权限至少包含 644（如 755 符合）。

```bash
find /home -user tom            # 找 tom 的所有文件
find . -perm -4000              # 查找设置了 SUID 位的文件（安全审计常用）
```

#### ⑥ 逻辑组合（高级筛选）
- **`-a`**（与，默认）、**`-o`**（或）、**`!`**（非）。
- 使用括号 `\( ... \)` 组合条件（必须转义，防止 shell 误解）。

```bash
find /tmp \( -name "*.tmp" -o -name "*.temp" \) -type f  # 找 .tmp 或 .temp 文件
find /var -type f ! -name "*.log"                        # 找不是 .log 结尾的文件
```

### 3. 核心处理动作（找到后“做什么”）

| 动作 | 说明 |
| :--- | :--- |
| **`-print`** | 打印路径（默认动作）。 |
| **`-ls`** | 以 `ls -l` 格式显示详细信息。 |
| **`-delete`** | 直接删除找到的文件（**操作危险，谨慎使用**）。 |
| **`-exec 命令 {} \;`** | 对每个找到的文件执行命令（`{}` 代表文件名，`\;` 是结束符）。 |
| **`-exec 命令 {} +`** | 将找到的文件**批量**传给命令（效率更高，类似 `xargs`）。 |
| **`-ok`** | 与 `-exec` 类似，但**执行前会询问确认**，更安全。 |

```bash
# 1. 找到所有 .txt 并强制删除（危险！）
find . -name "*.tmp" -delete

# 2. 批量修改所有 .html 文件的权限为 644
find . -name "*.html" -exec chmod 644 {} \;

# 3. 找到大日志文件并一次性打包
find /var/log -name "*.log" -exec tar -rvf logs.tar {} +

# 4. 找到后复制到指定备份目录（用 -ok 安全测试）
find . -name "*.conf" -ok cp {} /backup/ \;
```

### 4. 性能优化与限制（避免卡死）

在根目录 `/` 搜索时，`find` 会遍历所有挂载点（包括网络盘、虚拟文件系统），容易导致卡顿。

- **`-maxdepth N`**：限制最大搜索深度（最常用优化）。
- **`-mindepth N`**：限制最小搜索深度。
- **`-xdev`**：**不进入其他文件系统分区**（仅搜索当前挂载点）。

```bash
find / -maxdepth 3 -name "nginx.conf"   # 只在根目录往下3层内找，极快
find / -xdev -name "*.log"              # 不会进入 /mnt, /media 等挂载盘
```

### 5. 进阶妙用：与 `xargs` 黄金搭档

虽然 `-exec +` 已经很好用，但 `xargs` 在批量处理上更灵活，尤其适合处理大量文件：

```bash
# 找出所有图片并压缩（使用 xargs 并行处理，加快速度）
find . -name "*.jpg" -type f | xargs -P 4 -I {} convert {} -resize 50% {}

# 找出所有 .log 并统计总行数
find . -name "*.log" -print0 | xargs -0 wc -l
```
*（`-print0` 和 `xargs -0` 用于处理文件名中的空格和特殊字符）*

### 6. 常见问题与避坑指南

| 问题 | 解决方法 |
| :--- | :--- |
| **报错 `Permission denied`** | 因权限不足无法进入某些目录。可以忽略错误：`find / -name "x" 2>/dev/null`，或使用 `sudo`。 |
| **文件名有空格** | 在 `-exec` 中必须用 `{}` 加引号：`-exec cp "{}" /target \;`，或使用 `-print0 \| xargs -0`。 |
| **`find` 跑得太慢** | 务必使用 `-maxdepth` 限制深度，或使用 `-xdev` 排除远程挂载盘。 |
| **误删文件** | 在执行破坏性操作（如 `-delete` 或 `rm`）前，**先用 `-exec echo {}` 预览**一遍结果。 |

### 7. 实战举例：日常必用指令

1. **清理 7 天前的日志（运维标配）**：
   ```bash
   find /var/log/myapp/ -type f -mtime +7 -delete
   ```

2. **查找修改时间在 2 小时以内的核心配置**：
   ```bash
   find /etc -type f -mmin -120 -name "*.conf"
   ```

3. **找出目录下占用空间最大的前 5 个文件**：
   ```bash
   find . -type f -exec du -h {} + | sort -rh | head -5
   ```

4. **查找所有空目录并删除（清理项目脏数据）**：
   ```bash
   find . -type d -empty -delete
   ```
