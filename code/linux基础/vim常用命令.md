## 模式切换
?

| 命令                      | 作用                  |
| ----------------------- | ------------------- |
| `Esc`                   | 回到普通模式              |
| `i`                     | 光标前插入               |
| `I`                     | 行首插入                |
| `A`                     | 行尾插入（等价于 `$a`）      |
| `o`                     | 下方打开新行并插入           |
| `O`                     | 上方打开新行并插入           |
| `R`                     | 进入替换模式              |
| `v`                     | 字符可视模式              |
| `V`                     | 行可视模式               |
| `ctrl+v`（wsl中是`ctrl+q`） | 块可视模式，使用后可对行 进行批量操作 |
| `:`                     | 进入命令行模式             |
> `ctrl+v` 的常见操作：`ctrl+v I # <Esc>` 可视化 批量注释（在行首添加`# `）

### 行内字符搜索

| 命令                  | 作用                           |
| --------------------- | ------------------------------ |
| `f<char>`             | 向右查找字符，光标停在该字符上   |
| `F<char>`             | 向左查找字符，光标停在该字符上   |
| `t<char>`             | 向右查找字符，光标停在该字符**前** |
| `T<char>`             | 向左查找字符，光标停在该字符**后** |
| `;`                   | 重复上一次 `f`/`F`/`t`/`T`（同一方向） |
| `,`                   | 重复上一次 `f`/`F`/`t`/`T`（反方向） |

> `f` 是 **find**，`t` 是 **till**。例如 `fi` 跳到右边第一个 `i` 上，`ti` 则跳到 `i` 前面一个字符。配合 `;` 和 `,` 可在多个匹配间快速跳转。

## 编辑操作
?
### 删除（delete）

| 命令       | 效果            |
| -------- | ------------- |
| `x`      | 删除光标处字符       |
| `dd`     | 删除（剪切）整行      |
| `dw`     | 删除到词尾（包括空格）   |
| `daw`    | 删除整个单词及随后的空格  |
| `d$`/`D` | 删除到行尾         |
| `d0`     | 删除到行首         |

> 删除操作相当于 剪切，可以用p来粘贴

### 修改（change）
> 等价于删除并进入插入模式

| 命令 | 作用 |
|------|------|
| `cc` | 修改整行 |
| `cw` | 修改到词尾 |
| `ciw` | 修改整个单词 |
| `C` | 修改到行尾 |
| `s` | 删除当前字符并插入 |
| `S` | 删除整行并插入 |
> 显然就是把删除操作中的`d` (delete) 换成了`c` (change)

## 复制（Yank）
?

| 命令    | 作用        |
| ----- | --------- |
| `yy`  | 复制光标所在的整行 |
| `y$`  | 复制到行尾     |
| `y0`  | 复制到行首     |

### 可视模式复制

1. 按 `v` 进入字符可视模式（`V` 行可视，`Ctrl+v` 块可视）
2. 移动光标选中内容
3. 按 `y` 复制

| `ctrl+r 0` | 粘贴到命令界面（:之后）         |

#code/Vim
## 编辑操作进阶（配合光标移动）
?
### 文本对象（Text Object）

文本对象表示一段有结构的文本区域，格式为 `<操作>i/a<边界>`：

- **`i`** = `inside`，只包含**内部**内容（不含包围符号）
- **`a`** = `around`，包含包围符号**本身**

`c`、`d`、`y`、`v` 都可以与文本对象组合：

| 命令 | inside 效果 | around 效果 |
|------|------------|------------|
| `ci(` / `ci)` | 修改圆括号**内**的内容 | `ca(` 同时删除括号 |
| `ci[` / `ci]` | 修改方括号**内**的内容 | `ca[` 同时删除方括号 |
| `ci{` / `ci}` | 修改花括号**内**的内容 | `ca{` 同时删除花括号 |
| `ci<` | 修改尖括号**内**的内容 | `ca<` 同时删除尖括号 |
| `ci"` | 修改双引号**内**的字符串 | `ca"` 同时删除双引号 |
| `ci'` | 修改单引号**内**的字符串 | `ca'` 同时删除单引号 |
| `` ci` `` | 修改反引号**内**的内容 | `` ca` `` 同时删除反引号 |
| `cit` | 修改 HTML/XML tag **内**的内容 | `cat` 同时删除 tag 本身 |
| `ciw` | 修改**单词**（不含空格） | `caw` 修改单词及空格 |
| `cis` | 修改当前**句子** | `cas` 修改句子及标点 |
| `cip` | 修改当前**段落** | `cap` 修改段落及空行 |

| 组合 | 作用 |
|------|------|
| `di"` | 删除双引号内的内容 |
| `yi(` | 复制圆括号内的内容 |
| `va{` | 选中花括号及其内部内容 |
| `da"` | 删除双引号及其中内容 |

### 行内查找

`d`、`c`、`y` 可以与 `t`/`f` 组合，对行内特定区域进行操作：

| 命令 | 效果 |
|------|------|
| `dt"` | 删除到右边第一个 `"` **之前**（不含 `"`） |
| `df"` | 删除到右边第一个 `"` **之上**（含 `"`） |
| `dT"` | 删除到左边第一个 `"` **之后**（不含 `"`） |
| `dF"` | 删除到左边第一个 `"` **之上**（含 `"`） |
| `ct)` | 修改到右边第一个 `)` **之前**，并进入插入模式 |
| `yt{` | 复制到右边第一个 `{` **之前** |

> `t` 不含目标字符，`f` 含目标字符；大写方向相反。

#code/Vim
## 数字前缀与重复
?
Vim 中很多命令前可以加数字 `n`，表示**重复执行 n 次**。

| 命令 | 效果 |
|------|------|
| `3w` | 向前跳 3 个单词 |
| `3b` | 向后跳 3 个单词 |
| `3j` | 向下移动 3 行 |
| `3yy` | 复制 3 行 |
| `3dd` | 删除 3 行 |
| `d3w` | 删除 3 个单词 |

> `[n]yy` 与 `d[n]w` 中数字的位置不同，但效果一致：`3yy` = `y3y`，`d3w` = `3dw`。

# 其他使用命令

## 多窗口操作

| 命令                 | 作用        |
| ------------------ | --------- |
| `:split` / `:sp`   | 水平分割窗口    |
| `:vsplit` / `:vsp` | 垂直分割窗口    |
| `Ctrl+w h/j/k/l`   | 在分割窗口间切换  |
| `Ctrl+w q`         | 关闭当前窗口    |

## 系统剪贴板

> 需要 Vim 编译时启用 `+clipboard` 支持，可通过 `vim --version | grep clipboard` 检查。

| 命令 | 作用 |
|------|------|
| `"+yy` | 复制当前行到系统剪贴板 |
| `"+y` | 复制选中内容到系统剪贴板 |
| `"+p` | 从系统剪贴板粘贴 |
| `:reg` | 查看所有寄存器内容 |

### 其他编辑

| 命令          | 作用                |
| ----------- | ----------------- |
| `r<char>`   | 替换光标处单个字符（不进插入模式） |
| `~`         | 切换字符大小写           |
| `>>` / `<<` | 增加 / 减少缩进         |
| `J`         | 将下一行合并到当前行尾       |
| `.`         | 重复上一次操作           |
