#code 

`dmesg` 是 Linux 系统中一个基础且强大的命令行工具，用于**查看和控制内核的环形缓冲区（kernel ring buffer）**。

### 📓 什么是内核环形缓冲区？

内核环形缓冲区是内核在内存中开辟的一块固定大小的空间，用于循环存储内核产生的日志消息。这些消息包括：

*   **硬件检测**：如CPU、内存、硬盘、网卡等设备的识别和初始化信息。
*   **驱动加载**：各硬件驱动程序加载、初始化的状态和结果。
*   **系统事件**：内核运行过程中的各种事件、警告和错误信息。

由于其“环形”特性，当缓冲区写满后，新的消息会覆盖最旧的消息。因此，`dmesg` 默认显示的是从**本次开机到当前时刻**缓冲区中**最新的**内核消息。

### 🔧 常见用法与选项

直接输入 `dmesg` 即可显示所有内核消息。但为了更高效地使用，通常会结合各种选项。这里是一些最常用的选项：

#### 消息过滤
*   **`-l, --level <list>`**：按**日志级别**过滤。
    *   **示例**：`dmesg -l err` 只显示错误级别的消息；`dmesg -l err,warn` 显示错误和警告消息。
*   **`-f, --facility <list>`**：按**设施/来源**过滤。
    *   **示例**：`dmesg -f daemon` 只显示来自系统守护进程（如 `sshd`）的消息。
*   **`-k, --kernel` 与 `-u, --userspace`**：分别只显示内核或用户空间的消息。

#### 输出格式
*   **`-T, --ctime`**：将时间戳转换为**人类可读的日期和时间**格式。
*   **`-H, --human`**：启用**人类友好**的输出模式，包含易读的时间戳和颜色高亮。
*   **`-d, --show-delta`**：显示每条消息之间的**时间间隔**。
*   **`-J, --json`**：以 **JSON 格式**输出，便于程序解析。

#### 其他实用操作
*   **`-w, --follow`**：**实时跟踪**新消息，类似 `tail -f`。
*   **`-c, --read-clear`**：**打印并清除**当前缓冲区内容。
*   **`-C, --clear`**：**仅清除**缓冲区内容，不打印。
*   **`-n, --console-level <level>`**：**设置**输出到物理控制台的消息**最低级别**，高于此级别的消息才显示。（不打印，只设置参数）
