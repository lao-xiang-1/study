## 间隔
在 LaTeX 中，直接按空格键通常无效（多个空格会被编译为一个，甚至被忽略），必须使用**专用命令**来表示间距。按使用场景分为以下几类：

### 1. 水平间距（行内）
- **固定标准间距**（适用于文本和数学模式）：
  - `\quad`：约为当前字体宽度（`1em`），是最常用的中等间隔。
  - `\qquad`：两个 `\quad`（`2em`），用于较大分隔。
- **自定义精确间距**：
  - `\hspace{长度}`：例如 `\hspace{1cm}`、`\hspace{20pt}`。
  - `\hspace*{长度}`：带星号版本可保证在行首或行尾的间距不被吞掉。
- **弹性填充间距**（用于撑满整行）：
  - `\hfill`：将元素推向左右两端（相当于左中右对齐分割）。

### 2. 数学模式专用间距（仅限 `$...$` 或 `\[...\]` 内）
数学模式下字母和符号会自动调整间距，但以下命令可微调：

| 命令 | 效果 | 长度近似 |
| :--- | :--- | :--- |
| `\,` | 窄间距（最常用） | 3/18 em |
| `\:` | 中等间距 | 4/18 em |
| `\;` | 宽间距 | 5/18 em |
| `\!` | **负间距**（向左回退） | -3/18 em |

*示例*：`$\int x \, dx$`（在 `x` 和 `dx` 间加小空格）。

### 3. 垂直间距（段落间或图表上下）
- **自定义精确间距**：`\vspace{1cm}`（上下增加垂直空白）。
- **预定义快捷间距**（常用于换行后）：
  - `\smallskip`（约 3pt）
  - `\medskip`（约 6pt）
  - `\bigskip`（约 12pt）
- **弹性填充**：`\vfill`（将内容垂直撑满整页，常用于实现居中或底部对齐）。

### 4. 特殊隐形间距（占位）
- `\phantom{内容}`：生成与“内容”宽度和高度完全相同的**隐形空白**，用于对齐上下标或公式。
  *示例*：`\phantom{0}123` 会让数字与 `0123` 对齐。
