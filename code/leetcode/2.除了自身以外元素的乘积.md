
## 双向遍历
```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        L, R = [1,], (len(nums) - 1) * [0] + [1]
        for i in range(0, len(nums) - 1):
            L.append(L[i] * nums[i])
        for i in range(len(nums) - 1, 0, -1):
            R[i - 1] = R[i] * nums[i]
        ans = []
        for i in range(len(L)):
            ans.append(L[i] * R[i])
        return ans
```

## 省去R数组
>$O(1)$空间复杂度，不包括输出数组

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        L  = [1,]
        cache = 1
        for i in range(0, len(nums) - 1):
            L.append(L[i] * nums[i])
        for i in range(len(nums) - 1, -1, -1):
            L[i] = L[i] * cache
            cache *= nums[i]
        return L
```
