# Python 高级语法（二）：星号 `*` 的用法

> 基于 PCX 项目实际代码，介绍 Python 中 `*` 和 `**` 的各种高级用法。

## 1. `*args` —— 可变位置参数

`*args` 允许函数接受**任意数量**的位置参数，它们被打包成一个元组。

**工作机制**：
```python
def example(*args):
    print(type(args))  # <class 'tuple'>
    print(args)        # ('a', 2, 3.0)

example('a', 2, 3.0)
```

> [!位置参数和关键字参数]
> - 位置参数：按传入函数的排列顺序来确定参数
> - 关键字参数：指定参数名
> 如：`greet("Alice", 25, city="Beijing")` 前两个是位置参数，后一个指定参数名 `city`，是关键字参数

## 2. `**kwargs` —— 可变关键字参数

`**kwargs` 允许函数接受**任意数量**的关键字参数，被打包成一个字典。

```python
def greet(name, **kwargs):
    #                ^^^^^^^ 捕获任意关键字参数
    print(f"Hello, {name}!")

    for key, value in kwargs.items():
        print(f"  {key}: {value}")

greet("Alice", age=25, city="Beijing")
# 输出：
# Hello, Alice!
#   age: 25
#   city: Beijing
```

### 2.1 `*args` 的边界规则

#### 参数分配的铁律

Python 按以下优先级分配实参：

1. **`*args` 之前的具名参数**：按位置顺序各取所需，有最高优先权
2. **`*args` 自身**：吃掉上面取完之后剩余的**所有位置参数**（打包成元组）
3. **`*args` 之后的参数**：已经没有任何位置参数可用，**只能通过关键字方式传递**
4. **`**kwargs`**：吃掉所有不匹配任何具名参数签名的**关键字参数**（打包成字典）

用一幅图表示：

```
def f(a, b, *args, c, **kwargs):
        ^^^  ^^^^^^  ^  ^^^^^^^
         │     │     │     └── 吞掉所有剩余关键字参数
         │     │     └── keyword-only：只能用 f(..., c=val) 传递
         │     └── 吞掉 a, b 之后的所有位置参数
         └── 按顺序先拿走位置实参
```

#### 用 PCX 实际代码

以 [pcx/nn/_layer.py:44-56](pcx/nn/_layer.py#L44-L56) 的 `Layer.__init__` 为例：

```python
class Layer(Module):
    def __init__(
        self,
        cls,          # 第1个位置参数（*args 之前）
        *args,        # ← 吞掉所有剩余位置参数
        filter=eqx._filters.is_array,  # 在 *args 之后，只能用关键字传递
        **kwargs,     # ← 吞掉所有剩余关键字参数
    ):
```

实际调用：

```python
Layer(eqx.nn.Linear, 128, 64, False, filter=my_filter, key=my_key)
#     ^^^^^^^^^^^^^ |^^^^^^^^^^^^^^ |^^^^^^^^^^^^^^^^ |^^^^^^^^^^
#     → cls          → *args         → filter          → **kwargs
```

**分配过程**：

1. `cls`  → `eqx.nn.Linear`
2. `*args` →  `128`, `64`, `False` 
3. `filter` 匹配到具名参数 → 赋值给 `filter`
4. `key` 不匹配任何具名参数 → 进入 `**kwargs`

## 3. `*,` —— 强制关键字参数

单独的 `*` 作为分隔符，强制其**后面的所有参数**必须以关键字形式传递。

```python
# pcx/nn/_layer.py:77-81 —— Linear
class Linear(Layer):
    def __init__(
        self,
        in_features: int,
        out_features: int,
        bias: bool = True,
        *,                         # ← 分隔符：之后的所有参数必须用关键字传递
        rkg: RandomKeyGenerator = RKG,
        **kwargs,
    ):
        super().__init__(eqx.nn.Linear, in_features, out_features, bias, key=rkg(), **kwargs)
```

**为什么这样做？** `rkg` 是可选参数，使用位置传递容易搞乱顺序。强制关键字参数让调用更清晰：

```python
# ✅ 正确 —— rkg 必须用关键字传递
Linear(128, 64, False, rkg=my_rkg)

# ❌ 错误 —— 不能用位置传递
Linear(128, 64, False, my_rkg)  # TypeError!
```

## 4. `*` 用于解包

`*` 可以将列表/元组**展开**为位置参数，`**` 可以将字典**展开**为关键字参数。

### 4.1 解包列表/元组

```python
# 基本用法
args = [1, 2, 3]
func(*args)   # 等价于 func(1, 2, 3)
```

### 4.2 解包字典

#### 第一层：`**dict` 在函数调用中解包

```python
def func(a, b, c):
    print(a, b, c)

d = {"a": 1, "b": 2, "c": 3}
func(**d)   # 等价于 func(a=1, b=2, c=3)
```

`**` 把字典的键值对"拆开"变成 `key=value` 形式的关键字参数。

#### 第二层：`{**d1, **d2}` 在字典字面量中合并

```python
base = {"x": 1, "y": 2}
merged = {**base, "z": 3}  # → {"x": 1, "y": 2, "z": 3}
```

`{**d}` 在花括号内部表示"把字典 d 的所有键值对复制进来"。后面的键会**覆盖**前面的同名键：

```python
base = {"a": 1, "b": 2}
merged = {**base, "a": 999}  # → {"a": 999, "b": 2}  ← "a" 被覆盖
```

## 6. `*param_args, **param_kwargs` —— 透传参数

```python
# pcx/predictive_coding/_vode.py:172-198
class Vode(EnergyModule):
    def __init__(
        self,
        energy_fn: Callable[["Vode", RandomKeyGenerator], jax.Array] = se_energy,
        ruleset: dict = {},
        tforms: dict = {},
        param_type: type[VodeParam] = VodeParam,  # 待构造的类型
        *param_args,                               # 该类型的构造参数（位置）
        **param_kwargs,                            # 该类型的构造参数（关键字）
    ):
        super().__init__()

        # 用透传的参数构造实例 —— Vode 不需要知道 VodeParam 的签名！
        self.h = param_type(*param_args, **param_kwargs)
        self.cache = param_type.Cache()
```

**设计优势**：`Vode` 不需要知道 `VodeParam` 接受什么参数。如果将来 `VodeParam` 的签名变了，`Vode` 的代码无需修改。
