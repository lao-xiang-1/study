# Python 高级语法（六）：装饰器

> 基于 PCX 项目实际代码，介绍 Python 装饰器的基本原理和 `@property`、`@staticmethod`、`@classmethod` 等内置装饰器的用法。

## 1. 装饰器基础

### 1.1 什么是装饰器

装饰器（decorator）本质上是一个**接受函数、返回函数**的可调用对象（通常是函数或类）。

```python
# 这两种写法完全等价：

@decorator
def func():
    ...

# 等价于：
def func():
    ...
func = decorator(func)
```

### 1.2 装饰器的本质：函数工厂

```python
# 装饰器就是一个"函数工厂"——输入一个函数，输出一个新函数
def bold(fn):
    def wrapper(*args, **kwargs):
        return f"<b>{fn(*args, **kwargs)}</b>"
    return wrapper

@bold
def say(name):
    return f"Hi {name}"

say("Aoi")  # → "<b>Hi Aoi</b>"
# 等价于：bold(say)("Aoi")
```

### 1.3 装饰器的执行时机

> 在 `@<decorator>` 这一行就会执行装饰器

```python
def log(fn):
    print(f"装饰 {fn.__name__}")
    return fn          # 如果这里返回的不是函数，那么greet()就无法被调用

@log      # 这一行就会 print "装饰 greet"
def greet():
    print("Hello!")

greet()  # 输出: Hello!   （调用时不再触发装饰器内部逻辑）
```

### 1.4 `functools.wraps` —— 保留元信息

装饰器替换函数后，原函数的 `__name__`、`__doc__` 等元信息会丢失：

```python
from functools import wraps

def bold(fn):
    @wraps(fn)            # ← 复制 fn 的元信息到 wrapper
    def wrapper(*a, **kw):
        return f"<b>{fn(*a, **kw)}</b>"
    return wrapper

@bold
def say(name):
    """Say hi to someone."""
    return f"Hi {name}"

say.__name__  # "say"      （不加 @wraps 会是 "wrapper"）
say.__doc__   # "Say hi to someone."
```

> 大部分内置装饰器已经自动处理了元信息保留，如 `@property` / `@staticmethod` / `@classmethod`

## 2. 内置装饰器（一）：`@property`

### 2.1 基本用法 —— 方法伪装成属性

```python
# pcx/core/_module.py:201-204
class Module(BaseModule):
    @property
    def is_train(self) -> bool:
        return self._mode.get() == Module.MODE.TRAIN
```

这样就可以直接写`module.is_train`，而不用加`()`，也就是把`is_train`当作类属性来用，代码更直观。
- 但是这样实现的属性是只读的，只能读取`module.is_train`，而不能写`module.is_train = ...`
- 要想让属性能够赋值，要使用`property`的`setter()`方法

### 2.2 `.setter` 的原理

```python
# property 是一个类
# property(fget) → 返回 property 实例，该实例有 .getter/.setter/.deleter 方法

# pcx/predictive_coding/_energy_module.py:65-71
class EnergyModule(Module):
	# Step 1:
	@property                       # → status = property(status)
	def status(self):               #    status 现在是 property 实例（只有 getter）
	    return self._status.get()
	
	# Step 2:
	@status.setter                  # → status = status.setter(status)
	def status(self, value):        #    .setter() 返回新的 property 实例（getter + setter）
	    self._status.set(value)
```

#### python的底层机制
当你尝试给这个属性赋值时：`obj.status = "new_value"`
Python 的底层机制（描述符协议）会拦截这个赋值动作，并自动将等号右边的值 `"new_value"` 作为参数，传递给被 `@status.setter` 装饰的方法，相当于`obj.status("new_value")`

## 3. 内置装饰器（二）：`@staticmethod`

```python
# pcx/core/_parameter.py:58-67 —— 元类的静态方法
class _BaseParamMeta(abc.ABCMeta):
    @staticmethod
    def unflatten_parameter(aux_data, children, *, cls):
        _param = object.__new__(cls)
        ...
        return _param
```

**`@staticmethod` vs 普通函数**：静态方法在类命名空间中，但不需要 `self` 或 `cls` 参数。把它们放在类中是为了**组织代码**（逻辑归属），实际调用时不依赖实例。

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b

# 两种调用方式等价：
Math.add(1, 2)          # 通过类调用（推荐）
Math().add(1, 2)        # 通过实例调用（也能工作，但不推荐）
```
