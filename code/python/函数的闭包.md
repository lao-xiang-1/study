#code 

闭包（closure）是 Python 中一个非常重要的概念。简单说：**闭包是一个函数，它记住了自己被定义时所处的环境，即使外部函数已经执行结束，它仍然可以访问那些外部变量。**

在 micrograd 的代码里，`_backward` 就是典型的闭包。下面从基础到应用完整解释。

---

## 1. 一个最简单的闭包例子

```python
def outer(x):
    def inner(y):
        return x + y
    return inner

add5 = outer(5)
print(add5(3))  # 输出 8
```

这里：

- `outer` 是外部函数，接收参数 `x`。
- `inner` 是内部函数，它使用了 `x` 和 `y`。
- `outer` 返回了 `inner` 函数对象。
- 调用 `outer(5)` 后，按常理 `x` 应该被销毁，但 `inner` 仍然记住了 `x=5`。
- 所以 `add5(3)` 能算出 `5 + 3 = 8`。

`inner` 就是一个闭包。它捕获了外部变量 `x`。

---

## 2. 形成闭包的三个条件

在 Python 中，一个闭包通常满足：

1. **有嵌套函数**：一个函数定义在另一个函数内部。
2. **内部函数引用了外部函数的变量**：这些变量叫“自由变量”。
3. **外部函数返回了内部函数**，或者内部函数被保存到其他地方，导致它比外部函数活得更久。

只要满足这些，Python 就会把外部变量保存在一个叫做 **cell** 的对象里，让内部函数一直能访问。

---

## 3. 闭包如何保存变量

看这个例子：

```python
def outer():
    x = 10
    def inner():
        print(x)
    return inner

f = outer()
f()  # 输出 10
```

`outer()` 执行完后，局部变量 `x` 并没有消失。因为 `inner` 引用了它，Python 把 `x` 打包进 `inner` 的闭包中。

可以通过 `f.__closure__` 查看：

```python
print(f.__closure__)        # (<cell at 0x...: int object at 0x...>,)
print(f.__closure__[0].cell_contents)  # 10
```

每个闭包变量对应一个 cell，cell 里存着实际的值。

## 1. `_backward` 是闭包，不是类的方法

在 `__mul__` 里：

```python
def __mul__(self, other):
    other = other if isinstance(other, Value) else Value(other)
    out = Value(self.data * other.data, (self, other), '*')

    def _backward():
        self.grad += other.data * out.grad
        other.grad += self.data * out.grad

    out._backward = _backward
    return out
```

这里的 `_backward` 是一个**普通函数**，定义在 `__mul__` 内部。  
它被赋值给 `out._backward`，只是把函数对象存到了 `out` 这个实例的属性里。

注意：`_backward` **不是**定义在 `Value` 类里的方法。  
所以当你写：

```python
out._backward()
```

时，Python **不会**自动把 `out` 当作 `self` 传进去。  
它只是调用那个普通的闭包函数，没有参数。

那 `_backward` 里的 `self` 是谁？  
是 `__mul__` 被调用时的第一个参数，也就是乘法左边的 `Value`。  
`other` 是右边的 `Value`。  
`out` 是这次乘法产生的结果 `Value`。

这些都被闭包捕获了。

---

## 6. 闭包捕获的是变量，不是值

注意一个细节：闭包捕获的是变量本身，而不是当时的值。如果外部变量在闭包定义后被修改，闭包看到的是修改后的值。

例如：

```python
def outer():
    x = 1
    def inner():
        print(x)
    x = 2
    return inner

f = outer()
f()  # 输出 2，不是 1
```

但在 micrograd 的 `__add__` 中，`self`、`other`、`out` 在 `_backward` 定义之后不会再被重新赋值，所以不存在这个问题。

如果是在循环中创建闭包，就要特别小心：

```python
funcs = []
for i in range(3):
    funcs.append(lambda: print(i))

for f in funcs:
    f()
# 输出 2 2 2，而不是 0 1 2
```

因为三个 lambda 共享同一个变量 `i`。解决办法是用默认参数固定：

```python
funcs.append(lambda i=i: print(i))
```

micrograd 中每次运算都在独立的函数调用里，每次调用都有新的 `self`、`other`、`out`，所以闭包之间互不影响。

---

## 7. 闭包与普通函数的区别

| 普通函数 | 闭包 |
|---------|------|
| 只能访问自己的局部变量和全局变量 | 还能访问外部函数的局部变量 |
| 没有记忆环境的能力 | 记住定义时的环境 |
| 每次调用行为相同（除非依赖全局状态） | 每个闭包可以有不同的“环境” |

在 `_backward` 中，每个闭包都绑定了一组特定的输入输出节点，所以它们虽然代码看起来一样，但行为不同。

---

## 8. 闭包在自动求导中的作用总结

- 每个运算（加、乘、幂、ReLU）在创建结果节点时，同时定义一个 `_backward` 闭包。
- 这个闭包捕获了：
  - 输入节点（用于累加梯度）
  - 输出节点（用于读取上游梯度）
  - 前向传播时保存的数据（比如乘法的 `other.data`、`self.data`）
- 闭包被保存在结果节点的 `_backward` 属性中。
- 当调用最终输出的 `backward()` 时，它会按逆拓扑序调用每个节点的 `_backward()`。
- 每个闭包执行时，都能准确地知道自己对应的运算和节点。

所以，闭包让“每个节点的反向传播规则”可以独立保存，不需要额外的类或参数传递，代码非常简洁。

---

## 9. 一句话总结

**闭包 = 函数 + 定义时的环境。**  
它让内部函数在外部函数结束后，仍然能访问外部变量。在 micrograd 中，`_backward` 闭包捕获了本次运算的输入节点和输出节点，从而实现了每个节点独立的反向传播逻辑。
