## 1. `*` 与 `@` 的区别
?
### 1.1 一句话

| 符号 | 含义 | 函数形式 |
|---|---|---|
| `*` | **逐元素相乘**（对应位置相乘，Hadamard 积） | `torch.mul(a, b)` |
| `@` | **矩阵相乘**（矩阵乘法） | `torch.matmul(a, b)` |

### 1.2 示例

```python
a = torch.tensor([[1, 2],
                  [3, 4]])       # [2, 2]
b = torch.tensor([[5, 6],
                  [7, 8]])

a * b   # 逐元素：对应位置相乘
# tensor([[ 5, 12],
#         [21, 32]])

a @ b   # 矩阵乘：行 × 列
# tensor([[19, 22],
#         [43, 50]])
```

### 1.3 形状要求不同

- `*`：走**广播规则**——形状可广播即可，不要求维度数相同。[Broadcasting](Broadcasting.md)
- `@`：对最后两维做矩阵乘法——最后两维要满足 `[m, n] @ [n, p] → [m, p]`；而前面的维度必须广播对齐

```python
q   = torch.randn(2, 512, 8, 64)
sin = torch.randn(512, 1, 64)

q * sin   # ✅ 广播后逐元素乘，结果 [2, 512, 8, 64]
q @ sin   # ❌ 报错：最后两维 8×64 与 1×64 内维不匹配
```

## 2. `unsqueeze` 的用法
?
### 2.1 基本用法

`x.unsqueeze(dim)` 在指定位置 `dim` **插入一个尺寸为 1 的维度**，返回**视图**（view，不复制数据）。

```python
x = torch.randn(3, 4)   # [3, 4]

x.unsqueeze(0)    # [1, 3, 4]  在最前插一维
x.unsqueeze(1)    # [3, 1, 4]  在中间插一维
x.unsqueeze(2)    # [3, 4, 1]  在最后插一维
```
