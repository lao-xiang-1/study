
> 记录两个容易混淆的基础操作：乘法符号 `*` 与 `@` 的区别，以及 `unsqueeze` 的用法。广播规则详见 [[Broadcasting]]。

---

## 1. `*` 与 `@` 的区别

### 1.1 一句话

| 符号 | 含义 | 函数形式 |
|---|---|---|
| `*` | **逐元素相乘**（对应位置相乘，Hadamard 积） | `torch.mul(a, b)` |
| `@` | **矩阵相乘**（矩阵乘法） | `torch.matmul(a, b)` |

### 1.2 示例

```python
a = torch.tensor([[1, 2],
                  [3, 4]])       # [2, 2]
b = torch.tensor([[5, 6],
                  [7, 8]])

a * b   # 逐元素：对应位置相乘
# tensor([[ 5, 12],
#         [21, 32]])

a @ b   # 矩阵乘：行 × 列
# tensor([[19, 22],
#         [43, 50]])
```

### 1.3 形状要求不同

- `*`：走**广播规则**——形状可广播即可，不要求维度数相同。
- `@`：走**矩阵乘规则**——最后两维要满足 `[m, n] @ [n, p] → [m, p]`；更高维按**批量矩阵乘**对齐（batch 维可广播，但矩阵两维必须严格匹配）。

```python
q   = torch.randn(2, 512, 8, 64)
sin = torch.randn(512, 1, 64)

q * sin   # ✅ 广播后逐元素乘，结果 [2, 512, 8, 64]
q @ sin   # ❌ 报错：最后两维 8×64 与 1×64 内维不匹配
```

> 这是 RoPE 里 `q * cos.unsqueeze(1)` 用 `*` 而非 `@` 的根本原因：旋转被写成了逐元素乘加（O(d)），而不是构造旋转矩阵做矩阵乘（O(d²)）。

## 2. `unsqueeze` 的用法

### 2.1 基本用法

`x.unsqueeze(dim)` 在指定位置 `dim` **插入一个尺寸为 1 的维度**，返回**视图**（view，不复制数据）。

```python
x = torch.randn(3, 4)   # [3, 4]

x.unsqueeze(0)    # [1, 3, 4]  在最前插一维
x.unsqueeze(1)    # [3, 1, 4]  在中间插一维
x.unsqueeze(2)    # [3, 4, 1]  在最后插一维
```

### 2.2 负索引

`dim` 支持负数，从右往左数：`-1` = 最后一维之后，最前可用 `-dim()-1`。

```python
x = torch.randn(3, 4)   # 2 维，dim 合法范围 [-3, 2]

x.unsqueeze(-1)   # [3, 4, 1]  等价 unsqueeze(2)
x.unsqueeze(-3)   # [1, 3, 4]  等价 unsqueeze(0)
```

### 2.3 常见场景

| 场景 | 写法 | 结果 |
|---|---|---|
| 1D 加 batch 维 | `x[d].unsqueeze(0)` | `[1, d]` |
| 让向量与矩阵广播 | `bias[d].unsqueeze(0)` | `[1, d]` 对 `[b, d]` 广播 |
| RoPE 广播到所有头 | `cos[seq,d].unsqueeze(1)` | `[seq, 1, d]` 对 `[b, seq, heads, d]` 广播 |
| 矩阵乘前补 batch 维 | `x.unsqueeze(0) @ W` | 手动补批后做矩阵乘 |

### 2.4 与 view / expand / repeat 的区别

| 操作 | 作用 | 是否复制 |
|---|---|---|
| `unsqueeze(dim)` | 只插入一个尺寸 1 的维 | 否（view） |
| `view(shape)` / `reshape` | 任意重组形状（元素数不变） | 否（多数是 view，必要时 copy） |
| `expand(shape)` | 把尺寸 1 的维撑大 | 否（stride=0 view） |
| `repeat(shape)` | 真的复制数据 | **是** |

```python
x = torch.randn(512, 1, 64)
y = x.expand(2, 512, 8, 64)   # 不占额外内存
z = x.repeat(2, 1, 8, 1)      # 真的复制
```

> `unsqueeze` 只负责"加维"，真正把 1 撑大的是广播或 `expand`。二者常搭配：先 `unsqueeze` 插出 1，再靠广播铺到目标形状。
