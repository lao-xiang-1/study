
## 摄像头显示画面 基本命令

### ffplay基本使用
```bash
# v4l2后端 mjpeg编码格式（需摄像头支持）
ffplay -f v4l2 -input_format mjpeg -video_size 1280x720 -framerate 30 -i /dev/video0
```

### gstreamer

ffplay在rk3588上直接使用无法使用硬解码，退回cpu处理，720p视频占用200%以上

而gstreamer直接硬解码

> [!NOTE]
> #### 视频编码格式
> 1. mjpg
> 压缩格式，需要经过解码才能显示
> 2. YUYV(YUY2)
> 未压缩格式

```bash
# 使用yuy2（yuyv的别名）格式
gst-launch-1.0 v4l2src device=/dev/video22 ! \
    video/x-raw,format=NV12,width=640,height=480,framerate=30/1 ! \
    videoconvert ! xvimagesink

# 使用mjpg格式
# 中间需要经过jpegdec，即解码
gst-launch-1.0 v4l2src device=/dev/video0 ! \
    image/jpeg,width=1280,height=720,framerate=30/1 ! \
    jpegdec ! videoconvert ! xvimagesink
```
其中xvimagesink是x11专用显示，可尝试换成其他的

## 树莓派使用mjpg-streamer推流
```bash
# 设置动态链接库路径
export LD_LIBRARY_PATH=/usr/local/bin

libcamerify mjpg_streamer -i "input_uvc.so -d /dev/video0 -r 640x480  -f 30" -o "output_http.so -w ./www"
```
其中libcamerify负责指令翻译：将mjpg_streamer发出的旧指令 转换为 目前驱动支持的新指令
input_uvc.so表示使用uvc协议
output_http.so -w ./www表示使用自带的网页

## pc端查看推流画面

### 1. ffplay查看tcp推流
```bash
# 替换ip为板子的ip
ffplay -i "tcp://192.168.0.111:5000?tcp_nodelay=1" -fflags nobuffer -flags low_delay -framedrop
```

### 2. 使用播放器
potplayer等播放器原生支持该方式，但延迟较大
可使用开源低延迟播放器[Easyplayer](https://github.com/tsingsee/EasyPlayer)
