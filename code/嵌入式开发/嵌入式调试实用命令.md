
# 板端使用pc端代理

## pc端设置：
1. 开启clash的allow lan（允许局域网使用 此代理）
2. 在防火墙中 新建一个规则，**允许 TCP 端口 7890 的网络连接**。可直接在命令行中运行`New-NetFirewallRule -DisplayName "Allow LAN Proxy 7890" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 7890`（需要管理员权限）

## 板端设置：
```bash
# 示例：
# pc端ip地址：192.168.240.216
# clash运行的端口号：7890

# 设置环境变量
export https_proxy=http://192.168.137.1:7890 # 注意这里也要用http
export http_proxy=http://192.168.137.1:7890

# 测试端口是否可用
nc -vz 192.168.137.1 7890
# netcat, -v（Verbose），-z（Zero I/O）

# 测试是否成功，若输出"HTTP/1.1 200 Connection established"，则成功
curl -I https://www.google.com
```
 
## 注意事项：
- 可能ping不通电脑ip，这是防火墙拦截了。但是只要7890端口能通就不影响。

# 强制关闭进程
```bash
sudo -S killall -9 python3
```


# 自动追加.bash_history
加到.bashrc中
```bash
# 1. 让历史记录追加而不是覆盖（解决多终端冲突）
shopt -s histappend

# 2. 每次执行完一条命令，立刻写入到 .bash_history 中（防断电丢失）
export PROMPT_COMMAND="history -a; history -c; history -r; $PROMPT_COMMAND"
```

# `mobaxterm` 中设置输出画面到显示器

mobaxterm默认设置x11转发，gui程序会通过ssh输出到pc，此时若是想重新输出到显示器，运行以下命令：
```bash
export DISPLAY=:0 && xhost +local:
```
