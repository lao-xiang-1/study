
## 设置默认分辨率
```bash
# 自动生成模式
   cat@lubancat:/etc/X11/xorg.conf.d$ cvt 800 600
# 800x600 59.86 Hz (CVT 0.48M3) hsync: 37.35 kHz; pclk: 38.25 MHz
Modeline "800x600_60.00"   38.25  800 832 912 1024  600 603 607 624 -hsync +vsync

# 设置显示模式
xrandr --newmode "800x600_72" 50.00 800 856 976 1040 600 637 643 666 +HSync +VSync
xrandr --addmode HDMI-1 "800x600_72"
xrandr --output HDMI-1 --mode 800x600_72

# 它好像只支持它自己的分辨率，新增的模式不支持
```

## 查看显示服务信息
```bash
# 查看系统版本
cat /etc/os-release

# 查看当前显示服务器
echo "XDG_SESSION_TYPE: $XDG_SESSION_TYPE"

echo "WAYLAND_DISPLAY: $WAYLAND_DISPLAY" 
echo "DISPLAY: $DISPLAY"

# 查看当前桌面环境
echo $XDG_CURRENT_DESKTOP

# 查看当前运行的显示管理器服务
systemctl status display-manager
```

## 查看显示器信息
```bash
# 内核级别的查看
ls /sys/class/drm/
# ssh连接时调整显示设备
export DISPLAY=:0

# 检查显示设备
ls -la /dev/dri/
ls -la /dev/fb*

# 查看显示信息
xrandr
# 调分辨率
xrandr --output HDMI-1 --mode 1280x720
```
