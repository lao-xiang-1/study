### 方法一：使用 `nohup` 命令（最简单常用）
`nohup`（no hang up）的意思是“不挂断”，它可以让程序忽略终端关闭时发送的 SIGHUP 信号。结合 `&` 符号可以将其放入后台。

**用法：**
```bash
nohup ./你的程序 &
```

**关于输出日志：**
* 默认情况下，程序的输出会被自动保存到当前目录下的 `nohup.out` 文件中。
* 如果你想自定义输出的文件，或者不需要输出，可以重定向：
  * **保存日志到指定文件：**
    ```bash
    nohup ./你的程序 > my_log.txt 2>&1 &
    ```
  * **丢弃所有输出（不产生日志文件）：**
    ```bash
    nohup ./你的程序 > /dev/null 2>&1 &
    ```

### 方法二：使用 `tmux` 或 `screen`
这是一个“终端复用器”。它的原理是创建一个“虚拟终端”，你在里面运行程序，然后把这个虚拟终端“挂起”（detach），即使你关闭了真实的终端，虚拟终端依然在后台运行。**下次登录时，你还可以重新连上去看程序的实时运行情况。**

**使用 `tmux`（推荐，大多数现代 Linux 都自带或极易安装）：**
1. **新建并进入一个 tmux 会话：**
   ```bash
   tmux
   ```
2. **在里面运行你的程序：**
   ```bash
   ./你的程序
   ```
   
3. **将程序挂载到后台（退出但不关闭）：**
>不运行这一步，程序也已经在后台运行，关闭终端不受影响

   按下键盘上的 `Ctrl + B`，松开后，再按 `D` 键（Detach）。
   此时你会回到原来的终端，可以放心关闭窗口了。
   
4. **以后如何重新连上去查看：**
   ```bash
   tmux attach
   ```

*screen 为 tmux 的旧版，tmux 更现代*

### 方法三：如果你已经运行了程序，忘记加 `nohup` 怎么办？（补救措施）
如果你的程序已经在前台运行了，但你现在想关掉终端，可以使用 `disown` 命令将其从当前终端剥离。

**步骤：**
1. **暂停程序：** 按下 `Ctrl + Z`，程序会暂停并退回命令行。
2. **放入后台继续运行：** 输入 `bg` 并回车。
3. **与当前终端解除绑定：** 输入 `disown` 并回车。
*(现在你可以安全地关闭终端了)*

### 方法四：使用 Systemd 注册为系统服务（适合需要长期稳定运行的服务）
如果是 Web 服务器、数据库或长期运行的脚本，并且**希望服务器重启后它能自动启动**，推荐写成 Systemd 服务。

1. 在 `/etc/systemd/system/` 目录下创建一个文件，比如 `myprogram.service`：
   ```bash
   sudo nano /etc/systemd/system/myprogram.service
   ```
2. 填入以下基础内容（根据实际情况修改路径）：
   ```ini
   [Unit]
   Description=My Background Program

   [Service]
   ExecStart=/完整路径/你的程序
   Restart=always
   User=你的用户名

   [Install]
   WantedBy=multi-user.target
   ```
3. 启动并设置开机自启：
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl start myprogram    # 启动程序
   sudo systemctl enable myprogram   # 设置开机自启
   ```
