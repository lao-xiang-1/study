## nmcli

### 1. 扫描与列出 WiFi

```bash
# 重新扫描周围 WiFi
sudo nmcli dev wifi rescan

# 列出可用 WiFi
nmcli dev wifi list
```

### 2. 连接与断开 WiFi

```bash
# 连接已保存的 WiFi
sudo nmcli connection up xyt

# 使用密码连接新的 WiFi
sudo nmcli device wifi connect "Xiaomi_D66A" password "12345678"
```

### 3. 管理已保存连接

```bash
# 列出已保存的连接
nmcli connection show

# 删除特定已保存连接
sudo nmcli connection delete "Wi-Fi名称"
```

### 4. 连接优先级

```bash
# 设置连接优先级（数值越大优先级越高）
sudo nmcli connection modify "xyt" connection.autoconnect-priority 20

# 查看各连接的优先级
nmcli -f NAME,AUTOCONNECT-PRIORITY connection
```

### 5. 断开当前连接

```bash
sudo nmcli connection down "xyt"
```

### 6. 查看连接状态

```bash
# 查看所有网络设备状态
nmcli device status

# 查看当前活跃的连接
nmcli connection show --active
```

### 7. 开机自动连接

```bash
sudo nmcli connection modify "xyt" connection.autoconnect yes
```

### 8. 连接隐藏 WiFi

```bash
sudo nmcli device wifi connect "Hidden_SSID" hidden yes password "12345678"
```

### 9. 配置静态 IP

```bash
sudo nmcli connection modify "xyt" \
  ipv4.addresses 192.168.1.10/24 \
  ipv4.gateway 192.168.1.1 \
  ipv4.dns 8.8.8.8 \
  ipv4.method manual

# 应用更改
sudo nmcli connection up "xyt"
```

### 10. 以太网连接

```bash
# 通过 DHCP 连接有线网络
sudo nmcli device ethernet connect eth0
```

### 11. WiFi 射频开关

```bash
# 关闭 WiFi
nmcli radio wifi off

# 打开 WiFi
nmcli radio wifi on

# 查看射频状态
nmcli radio wifi
```
