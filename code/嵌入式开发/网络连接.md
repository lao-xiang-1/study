
## nmcli

NetworkManager 的命令行工具，用于控制网络连接、设备与状态。命令按「顶层参数」划分为 `general` / `networking` / `radio` / `connection` / `device` / `agent` / `monitor`。

### 常用命令

```bash
# 扫描 / 列出 WiFi
sudo nmcli dev wifi rescan
nmcli dev wifi list

# 连接 WiFi
sudo nmcli connection up xyt                                          # 连接已保存的 WiFi
sudo nmcli device wifi connect "SSID" password "密码"                  # 密码连接新 WiFi
sudo nmcli device wifi connect "隐藏SSID" hidden yes password "密码"   # 连接隐藏 WiFi

# 查看 / 断开
nmcli connection show              # 列出已保存连接
nmcli device status                # 查看设备状态
nmcli connection show --active     # 查看当前活跃连接
sudo nmcli connection down "xyt"   # 断开当前连接

# 删除连接
sudo nmcli connection delete "Wi-Fi名称"

# 连接属性
sudo nmcli connection modify "xyt" connection.autoconnect yes          # 开机自动连接
sudo nmcli connection modify "xyt" connection.autoconnect-priority 20  # 优先级，越大越高

# 配置静态 IP
sudo nmcli connection modify "xyt" ipv4.method manual \
  ipv4.addresses 192.168.1.10/24 \
  ipv4.gateway 192.168.1.1 \
  ipv4.dns 8.8.8.8

# 以太网（DHCP 有线）
sudo nmcli device connect eth0
```

### Options（全局选项）

```bash
-a, --ask               # 缺少必需参数时交互式询问（勿用于脚本）
-c, --colors {yes|no|auto}   # 彩色输出，默认 auto
-f, --fields 字段       # 只输出指定字段（列名），默认 common
-g, --get-values 字段   # 只打印字段值，每行一个、无表头（= -m tabular -t -f）
-h, --help              # 打印帮助
-m, --mode {tabular|multiline}   # 输出模式，默认 tabular
-p, --pretty            # 对齐、带表头，便于人阅读
-s, --show-secrets      # 显示密码等敏感信息
-t, --terse             # 精简输出，适合脚本处理
-v, --version           # 显示版本
-w, --wait 秒           # 等待操作完成的超时；0 表示不等待
--offline               # 脱离守护进程，经 stdin/stdout 处理连接数据
```

### general（总体状态）

```bash
nmcli general status                # 查看总体状态（默认动作）
nmcli general hostname              # 查看系统主机名
sudo nmcli general hostname 名称    # 修改主机名（写入 /etc/hostname）
nmcli general permissions           # 查看当前用户的权限
nmcli general logging               # 查看日志级别与域
sudo nmcli general reload           # 重载配置（可用 conf / dns-rc / dns-full 细粒度控制）
```

### networking（联网开关）

```bash
nmcli networking on / off             # 开启 / 关闭全部网络（所有受管接口）
nmcli networking connectivity [check] # 查看连通性（none / portal / limited / full / unknown）
```

### radio（射频开关）

```bash
nmcli radio wifi [on|off]   # 查看 / 开关 WiFi（无参数时查看状态）
nmcli radio wwan [on|off]   # 查看 / 开关移动宽带
nmcli radio all  [on|off]   # 同时查看 / 开关所有射频
```

### connection（连接管理）

```bash
# 列出连接
nmcli connection show              # 列出已保存的连接
nmcli connection show --active     # 只看当前活跃的连接
nmcli -s connection show "xyt"     # 查看详情（-s 同时显示密码）

# 激活 / 停用
sudo nmcli connection up "xyt"     # 激活（默认等待 90 秒）
sudo nmcli connection down "xyt"   # 停用（默认等待 10 秒）

# 修改属性
sudo nmcli connection modify "xyt" connection.autoconnect yes              # 开机自动连接
sudo nmcli connection modify "xyt" connection.autoconnect-priority 20      # 优先级，越大越高
sudo nmcli connection modify "xyt" ipv4.method manual \
  ipv4.addresses 192.168.1.10/24 \
  ipv4.gateway 192.168.1.1 \
  ipv4.dns 8.8.8.8                                                        # 配置静态 IP

# 新建 / 删除
sudo nmcli connection add type ethernet autoconnect no ifname eth0   # 新增以太网连接（DHCP）
sudo nmcli connection delete "名称"                                  # 删除连接

# 编辑 / 克隆 / 监视
sudo nmcli connection edit "xyt"          # 菜单式交互编辑
sudo nmcli connection clone "xyt" 新名字  # 克隆（生成新 UUID）
nmcli connection monitor "xyt"            # 监视指定连接变化

# 重载 / VPN
sudo nmcli connection reload                        # 从磁盘重读所有连接文件
sudo nmcli connection load 文件                     # 重载指定连接文件
sudo nmcli connection import type openvpn file ~/xx.ovpn   # 导入 VPN 配置
nmcli connection export 名称 [文件]                 # 导出 VPN 配置
```

> `modify` / `add` 用 `+`、`-` 前缀可追加或删除多值属性（如 `+ipv4.dns 8.8.8.8`）；`""` 可将属性重置为默认值。

### device（设备管理）

```bash
nmcli device status               # 查看所有设备状态（默认动作）
nmcli device show [接口]          # 查看设备详情

# WiFi 扫描 / 列表
sudo nmcli device wifi rescan     # 立即重新扫描
nmcli device wifi list            # 列出可用 WiFi（--rescan yes|no|auto 控制扫描）

# 连接 WiFi
sudo nmcli device wifi connect "SSID" password "密码"                 # 新建并连接
sudo nmcli device wifi connect "隐藏SSID" hidden yes password "密码"  # 连接隐藏网络

# 热点 / 密码
nmcli device wifi hotspot [ssid ...] [password ...]   # 创建热点（默认 WPA）
nmcli device wifi show-password [ifname ...]          # 查看活跃 WiFi 详情（含密钥）

# 设备连接 / 断开
sudo nmcli device connect eth0        # 激活设备（= device up，自动找合适连接）
sudo nmcli device disconnect eth0     # 断开并禁止自动连接（= device down）
sudo nmcli device reapply eth0        # 应用当前活跃连接的改动
sudo nmcli device modify eth0 ipv4.method shared   # 临时修改设备设置（不写入 profile）
```

### agent（密钥 / 授权代理）

```bash
nmcli agent secret    # 作为 NetworkManager 密钥代理
nmcli agent polkit    # 作为 polkit 授权代理
nmcli agent all       # 两者同时
```

### monitor（活动监视）

```bash
nmcli monitor         # 观察 NetworkManager 活动（连接 / 设备 / 连接状态变化）
```

## 网线
>有没有不共享网络的方法？（快速连接）

这里介绍共享网络的方法：

1. 电脑连接网线到开发板
2. 打开 控制面板/查看网络连接（直接在开始菜单搜索）
3. 选择当前电脑连接的网络（能用来上网的），比如“WLAN”。点开属性页面，勾选“允许其他网络用户通过此计算机的 Internet 来连接”，并选择一个专用网络连接。这里的专用网络就是 用来连接开发板的网口，一般为“以太网”
4. 点开这个以太网，进入状态界面，能看到发送和接收的数据包数量，如果有接收到数据包，说明已连接。（注意：一开始接收到的数据包数量可能不为0，这是因为先前用过网线联网，而不是开发板发送的）

成功连接之后，需要获取开发板的IP地址：
在电脑终端运行 `arp -a` ，可以看到本机最近在局域网内与哪些设备通信过。以下是**示例信息**

```bash
PS C:\Users\26971> arp -a

接口: 192.168.0.101 --- 0x4
  Internet 地址         物理地址              类型
  192.168.0.1           48-7d-2e-cd-88-41     动态
  192.168.0.255         ff-ff-ff-ff-ff-ff     静态
  224.0.0.22            01-00-5e-00-00-16     静态
  224.0.0.251           01-00-5e-00-00-fb     静态
  224.0.0.252           01-00-5e-00-00-fc     静态
  239.255.255.250       01-00-5e-7f-ff-fa     静态
  255.255.255.255       ff-ff-ff-ff-ff-ff     静态
```

`接口: 192.168.0.101` 表示 这条记录属于本机的哪一块网卡（按本机的 IP 地址区分）。
下面的 `Internet 地址` 表示这个IP地址连接的网络。在连接的网络中，除了真实的设备，通常还会有一些凌乱的广播地址。比如在以上示例中，只有第一个 `192.168.0.1` 是我家的路由器IP，其余的全都不是真实设备。
所以在运行该命令之后，还需要辨别哪个是开发板地址。其实很简单——通常就是第一个，类型一般是动态。
