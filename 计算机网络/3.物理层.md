# 物理层（Physical Layer）

> 物理层解决的是**最底层的问题**：怎样在传输介质上传输**比特流**。它不关心比特的含义，只要求**透明传输**——发什么比特，就收什么比特。

## 一、基本概念
?
### 数据、信号与码元

- **码元（Symbol / Baud）**：**承载数据的基本信号单位**，一个码元可以携带 1 位或多位比特。
  - 二进制码元：一个码元 = 1 个比特。
  - $M$ 进制码元：一个码元 = $\log_2 M$ 个比特。

### 码元速率与比特率

| 名称 | 符号 | 单位 | 含义 |
| :--- | :--- | :--- | :--- |
| **码元速率（波特率）** | $R_B$ | 波特（Baud） | 每秒传输的**码元个数** |
| **信息速率（比特率）** | $R_b$ | bit/s（bps） | 每秒传输的**比特个数** |

二者关系：
$$R_b = R_B \times \log_2 M \quad (\text{bit/s})$$

其中 $M$ 为一个码元可取的**离散状态数**（即 $M$ 进制码元）。
比如码元是十六进制的，那么一个码元带4位bit，比特率就是波特率的4倍。

> **关键**：一个码元带 $n$ 位比特时，比特率是波特率的 $n$ 倍。带宽有限时，提高比特率的办法就是**让每个码元携带更多比特**（提高 $M$），但代价是抗噪能力下降。

### 4. 信息交互方式（通信方式）

| 方式 | 英文 | 方向 | 特点 | 典型例子 |
| :--- | :--- | :--- | :--- | :--- |
| **单工** | Simplex | 单向 | 只能沿**一个固定方向**传输，收发角色不可互换 | 广播、电视、键盘→主机 |
| **半双工** | Half-duplex | 双向、不同时 | 两个方向都能传，但**同一时刻只能一个方向**，需**切换**（Turn-around） | 对讲机、早期集线器（Hub） |
| **全双工** | Full-duplex | 双向、同时 | 两个方向**可同时**收发，无需切换 | 电话、交换机、现代以太网 |

## 二、信号的频谱与带宽

### 1. 傅里叶变换：一切信号皆正弦叠加

任何满足狄利克雷条件的信号 $f(t)$ 都可以分解为**不同频率正弦波**的叠加：

$$f(t) = a_0 + \sum_{n=1}^{\infty}\left[a_n\cos(2\pi n f_0 t) + b_n\sin(2\pi n f_0 t)\right]$$

- 实际信道带宽有限，**高频分量被截断** → 方波变圆、边沿变缓 → 这就是**码间串扰与失真的根源**。

### 2. 带宽（Bandwidth）

- 原义（模拟）：信号**最高频率与最低频率之差**，单位 Hz。
- 引申（数字）：**单位时间内能传输的最大比特数**，单位 bit/s。

> 传输介质的**物理带宽**（Hz）决定了它能承载的**数字带宽**（bit/s）上限——这由下一节的奈氏准则与香农定理定量描述。

## 三、编码与调制

物理层的核心工作，就是把**比特**变成**能在介质上传输的信号**。

| | 数据 | 信号 | 名称 | 典型技术 |
| :--- | :--- | :--- | :--- | :--- |
| **编码（Coding）** | 数字 | 数字 | 基带编码 | 曼彻斯特、NRZ |
| **调制（Modulation）** | 数字 | 模拟 | 带通调制 | ASK、FSK、PSK、QAM |
| （调制解调） | 模拟 | 模拟 | 模拟调制 | AM、FM、PM |

### 1. 基带编码（数字数据 → 数字信号）

常用编码方式（重点记**曼彻斯特**与**差分曼彻斯特**）： 

| 编码 | 规则 | 是否自同步 | 特点 |
| :--- | :--- | :--- | :--- |
| **不归零 NRZ** | 高电平=1，低电平=0 | ✗ | 简单，但长串相同比特无法同步 |
| **归零 RZ** | 每比特中间回到零电平 | 部分 | 可同步，但占用带宽大 |
| **反向不归零 NRZI** | 遇 1 翻转、遇 0 保持 | ✗ | 差分编码，抗极性反转 |
| **曼彻斯特 Manchester** | **每比特中间必跳变**，高→低=1，低→高=0 | ✓ | **自同步**，但波特率是比特率 2 倍 |
| **差分曼彻斯特** | 每比特中间必跳变；**比特开始处是否跳变表示 0/1** | ✓ | 抗干扰更强，用于令牌环 |

- **曼彻斯特编码**的跳变**既传数据又传时钟**，因此叫**自同步（Self-synchronizing）**——这是以太网（10Base-T）采用它的原因。
- 缺点：**编码效率只有 50%**，同样的波特率只能传一半比特率。

> 现代高速以太网用 **4B/5B**、**8B/10B**、**64B/66B** 等**分组编码**：每 4/8 位比特映射为 5/10 位码元，保证足够的电平跳变以维持同步，开销比曼彻斯特小得多。

### 2. 带通调制（数字数据 → 模拟信号）

用**载波（Carrier）**的振幅、频率、相位来携带数字信息：

| 方式         | 英文  | 变化的载波参数 | 特点                 |
| :--------- | :-- | :------ | :----------------- |
| **调幅**     | ASK | 振幅      | 简单，抗噪差             |
| **调频**     | FSK | 频率      | 抗噪好，频带利用率低         |
| **调相**     | PSK | 相位      | 抗噪好，常用 BPSK / QPSK |
| **正交幅度调制** | QAM | 振幅 + 相位 | **同时利用两者**，效率最高    |

- **QAM** 把振幅与相位组合成**星座图（Constellation Diagram）**，$M$ 个点对应 $M$ 进制码元，一点 $\log_2 M$ 位比特。
- 常见 **16-QAM**（4 bit/码元）、**64-QAM**（6 bit/码元）、**256-QAM**（8 bit/码元）。
- **星座点越密，每码元比特越多，但对噪声越敏感**——这就是调制阶数与可靠性的权衡。

## 四、信道容量：奈氏准则与香农定理
?
### 1. 奈氏准则（Nyquist，理想无噪声）

在**理想低通信道**、带宽为 $W$（Hz）、无噪声时，为避免**码间串扰**，极限**码元**速率（波特率）为：
$$R_B = 2W \quad (\text{Baud})$$

进而极限**信息**速率（比特率）：
$$R_b = 2W \log_2 M \quad (\text{bit/s})$$

- 含义：**带宽越宽，码元速率上限越高**；再靠提高 $M$ 把比特率顶上去。
- 工程上 M 一般取 4-256

### 2. 香农定理（Shannon，有噪声）

在带宽 $W$（Hz）、信噪比 $S/N$ 的信道上，**极限比特率**为：
$$C = W \log_2\left(1 + \frac{S}{N}\right) \quad (\text{bit/s})$$

- C=Capacity（容量），描述**信道本身的能力上限**。
- 在良好的 wifi 环境下，信噪比大约为 20-40 dB
- **信噪比**常用分贝表示：$\text{SNR(dB)} = 10\log_{10}(S/N)$。比如 $S/N = 1000$ 即 $30\,\text{dB}$。
- 与奈氏的区别：奈氏说"**提高 $M$ 能提高比特率**"，香农说"**噪声限制了 $M$ 的上限**"——$M$ 不能无限增大。

## 五、传输介质

| 介质 | 类别 | 优点 | 缺点 | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| **双绞线** | 导向（有线） | 便宜、易布线 | 抗干扰差、距离短 | 以太网（UTP/STP，RJ45） |
| **同轴电缆** | 导向 | 抗干扰好、带宽大 | 粗重、成本高 | 有线电视、早期以太网 |
| **光纤** | 导向 | **带宽极大、抗电磁干扰、衰减小、保密好** | 贵、脆、接续难 | 骨干网、长距离 |
| **无线电波** | 非导向（无线） | 无需布线、可移动 | 易受干扰、需频谱授权 | Wi-Fi、蓝牙、蜂窝 |
| **微波 / 红外** | 非导向 | 方向性强、带宽大 | 需视距（LOS）、受天气影响 | 点对点链路、遥控 |

- **双绞线**：两根绝缘铜线**绞合**以抵消电磁干扰，绞得越密抗干扰越强。分 **UTP（无屏蔽）** 与 **STP（屏蔽）**；常见 **5e/6/6a 类**，对应不同带宽。
- **光纤**分两类：
  - **单模光纤（SMF）**：芯径小，光沿**单一模式**传播，衰减小、距离远，用**激光器**。
  - **多模光纤（MMF）**：芯径大，光**多路径**传播，有模间色散、距离短，用 **LED**。

## 六、信道复用技术

**复用（Multiplexing）**：让**多条信号共用同一条物理链路**，提高利用率。

| 技术 | 英文 | 复用维度 | 特点 |
| :--- | :--- | :--- | :--- |
| **频分复用** | FDM | 频率 | 各信号占不同频段，**同时**传输，需**保护带** |
| **时分复用** | TDM | 时间 | 各信号轮流占**时间片**，时隙固定 |
| **统计时分复用** | STDM | 时间（按需） | 时隙**动态分配**，利用率高于 TDM |
| **波分复用** | WDM / DWDM | 波长（光的频率） | 光纤中不同**波长**的光并行传输 |
| **码分复用** | CDM / **CDMA** | 编码 | 各用户用**正交码片**，同一时间同一频段共享 |

- **TDM 的缺陷**：时隙固定，某路空闲时其时段被**浪费**——STDM 正是为解决此问题而生。
- **CDMA（码分多址）**：每个用户分配一个**正交的码片序列（Chip Sequence）**，所有用户**同时同频**发送；接收方用对应码片做**内积**即可分离。这是 3G 的核心技术。
  - 码片间**规格化内积为 0**（正交）才能互不干扰；与自己内积为 1。

## 七、物理层设备

物理层设备**只处理信号，不识别帧、MAC 地址或 IP**。

| 设备 | 功能 | 说明 |
| :--- | :--- | :--- |
| **中继器（Repeater）** | **放大、整形、再生**信号 | 延长传输距离，只有两个端口 |
| **集线器（Hub）** | 多端口中继器 | 把多台主机接到一个**共享冲突域**；**广播式**转发，半双工 |

- **中继器**：信号在介质中传输会**衰减（Attenuation）**和**失真（Distortion）**，中继器把数字信号**重新再生**（不是简单放大，而是判"1/0"后重建波形），从而延长距离。
  - 以太网规定最多 **5 段**、**4 个中继器**（**5-4-3 规则**）。
- **集线器**：本质是**多端口中继器**，工作在物理层。
  - 所有端口处于**同一个冲突域（Collision Domain）**，同一时刻只能有一台主机发送。
  - 采用**广播**方式——收到的信号向所有其他端口转发，由网卡按 MAC 地址自行判断是否接收。
  - 与**交换机**的根本区别：集线器**不识别 MAC**、**共享带宽**；交换机在**数据链路层**、**独享带宽**、隔离冲突域。

> 记忆：**中继器/集线器 = 物理层**（比特、信号）；**网桥/交换机 = 链路层**（帧、MAC）；**路由器 = 网络层**（分组、IP）。

## 八、接口的四大特性

物理层**规程（协议）**规定的接口特性，是物理层的"接口标准"，记 **"机、电、功、规"**：

| 特性 | 英文 | 规定内容 |
| :--- | :--- | :--- |
| **机械特性** | Mechanical | 接口的**形状、尺寸、引脚数、排列、锁定**方式 |
| **电气特性** | Electrical | 各条线的**电压范围、阻抗、传输速率、距离**限制 |
| **功能特性** | Functional | 某条线上**某一电平表示何种含义**（数据/控制/定时） |
| **规程特性** | Procedural | 各信号线的**动作时序、工作过程**（谁先谁后） |

> 例如 **RJ45** 接口：外形与 8 根引脚是**机械特性**，电平标准是**电气特性**，每根线的用途是**功能特性**，握手时序是**规程特性**。

## 九、小结与知识地图

```text
物理层
├─ 基本概念：数据/信号/码元、波特率 vs 比特率 (Rb = RB·log₂M)
│   └─ 信息交互方式：单工 / 半双工 / 全双工
├─ 信号分析：傅里叶变换 → 频谱 → 带宽
├─ 编码与调制
│   ├─ 基带编码（数字→数字）：NRZ、曼彻斯特、差分曼彻斯特、4B/5B
│   └─ 带通调制（数字→模拟）：ASK、FSK、PSK、QAM（星座图）
├─ 信道容量
│   ├─ 奈氏准则：R = 2W·log₂M（理想、无噪声）
│   └─ 香农定理：C = W·log₂(1 + S/N)（有噪声）
├─ 传输介质：双绞线、同轴、光纤（单模/多模）、无线
├─ 信道复用：FDM、TDM、STDM、WDM、CDMA
├─ 物理层设备：中继器、集线器
└─ 接口四大特性：机械、电气、功能、规程
```

**三条主线**：

1. **"信号怎么传"** —— 编码与调制（把比特变成波形）。
2. **"能传多快"** —— 奈氏准则与香农定理（带宽、噪声决定上限）。
3. **"用什么传、怎么共享"** —— 传输介质与复用技术。
