# KL 散度与 Wasserstein 距离

两种常用的**概率分布差异度量**方法，广泛应用于机器学习、生成模型、神经架构搜索等领域。

---

## 1. KL 散度（Kullback-Leibler Divergence）

### 1.1 定义

KL 散度度量两个概率分布 $P$ 和 $Q$ 之间的差异，表示用 $Q$ 近似 $P$ 时损失的信息量。

**离散形式**：

$$D_{KL}(P \| Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)}$$

**连续形式**：

$$D_{KL}(P \| Q) = \int_{-\infty}^{+\infty} p(x) \log \frac{p(x)}{q(x)} \, dx$$

其中 $p(x)$ 和 $q(x)$ 分别是 $P$ 和 $Q$ 的概率密度函数。

### 1.2 基本性质

- **非负性**：$D_{KL}(P \| Q) \geq 0$，当且仅当 $P = Q$ 时取等号
- **非对称性**：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$
- **不满足三角不等式**：不是真正的距离度量

### 1.3 直观理解

KL 散度回答的问题是：**如果真实分布是 $P$，但我用 $Q$ 来编码，会多浪费多少比特？**

- $D_{KL}(P \| Q)$ 小：$Q$ 能较好地近似 $P$
- $D_{KL}(P \| Q)$ 大：$Q$ 与 $P$ 差异明显

### 1.4 应用

- **变分推断（VI）**：用简单分布近似复杂后验
- **变分自编码器（VAE）**：重构损失 + KL 正则项
- **信息论**：衡量信息损失

## 2. Wasserstein 距离（Wasserstein Distance）

### 2.1 定义

Wasserstein 距离又称 **推土机距离（Earth Mover's Distance, EMD）**，度量把一个分布 $P$ "搬运"成另一个分布 $Q$ 所需的最小代价。

对于两个概率分布 $P$ 和 $Q$，其 $p$ 阶 Wasserstein 距离定义为：

$$W_p(P, Q) = \left( \inf_{\gamma \in \Gamma(P, Q)} \int \|x - y\|^p \, d\gamma(x, y) \right)^{1/p}$$

其中 $\Gamma(P, Q)$ 是所有以 $P$ 和 $Q$ 为边缘分布的联合分布集合，$\gamma(x, y)$ 表示从 $x$ 处搬运多少质量到 $y$ 处。

最常用的 **Wasserstein-2 距离**：

$$W_2(P, Q) = \left( \inf_{\gamma \in \Gamma(P, Q)} \int \|x - y\|_2^2 \, d\gamma(x, y) \right)^{1/2}$$

### 2.2 高斯分布下的闭式解

当 $P \sim \mathcal{N}(\mu_1, \Sigma_1)$，$Q \sim \mathcal{N}(\mu_2, \Sigma_2)$ 时，Wasserstein-2 距离有解析解：

$$\mathcal{W}(P, Q) = \|\mu_1 - \mu_2\|_2^2 + \text{tr}\left( \Sigma_1 + \Sigma_2 - 2(\Sigma_1^{1/2} \Sigma_2 \Sigma_1^{1/2})^{1/2} \right)$$

这正是 [[paper/adaxpert.pdf_by_PaddleOCR-VL-1.6|AdaXpert]] 论文中用于度量数据分布差异的公式。

### 2.3 直观理解

想象两堆沙子：

- $P$ 是原来的沙堆形状
- $Q$ 是目标沙堆形状

Wasserstein 距离就是：**用推土机把 $P$ 改造成 $Q$ 所需的最小总搬运代价**。

$$
\text{总代价} = \sum \text{搬运量} \times \text{搬运距离}
$$

### 2.4 基本性质

- **非负性**：$W_p(P, Q) \geq 0$
- **对称性**：$W_p(P, Q) = W_p(Q, P)$
- **满足三角不等式**：是真正的距离度量
- **对分布不重叠鲁棒**：即使 $P$ 和 $Q$ 支撑集不重叠，距离仍为有限值

## 3. KL 散度与 Wasserstein 距离的对比

| 特性 | KL 散度 | Wasserstein 距离 |
|---|---|---|
| 数学本质 | 信息损失 | 最优传输代价 |
| 对称性 | 不对称 | 对称 |
| 三角不等式 | 不满足 | 满足 |
| 是否真正距离 | 否 | 是 |
| 分布不重叠时 | 可能为 $+\infty$ | 仍为有限值 |
| 梯度行为 | 不重叠区域梯度差或不稳定 | 平滑、稳定 |
| 计算难度 | 通常容易计算 | 一般需解最优传输问题 |
| 几何意义 | 概率比值的对数期望 | 质量移动的最小代价 |

### 3.1 关键差异举例

假设两个一维分布：

- $P$：集中在 $x = 0$
- $Q$：集中在 $x = 10$

**KL 散度**可能认为它们"完全不同"（甚至无穷大）。

**Wasserstein 距离**则给出直观结果：**距离约为 10**，因为把质量从 0 移动到 10 需要移动 10 个单位。

## 4. 在机器学习中的应用

### 4.1 生成模型

- **VAE**：使用 KL 散度约束隐变量分布
- **Wasserstein GAN（WGAN）**：使用 Wasserstein 距离替代 JS 散度，解决训练不稳定问题

### 4.2 神经架构搜索

- **AdaXpert**：用 Wasserstein 距离度量当前数据与之前数据的分布差异
- 差异小 → 架构微调
- 差异大 → 架构大幅调整

### 4.3 领域自适应

- 度量源域与目标域的分布差异
- Wasserstein 距离能提供更平滑、更合理的训练信号

---

## 5. 总结

- **KL 散度**：基于信息论，衡量用 $Q$ 近似 $P$ 的信息损失，计算简单但不对称、对不重叠敏感
- **Wasserstein 距离**：基于最优传输理论，衡量"搬运"分布的最小代价，是真正的距离度量，几何直观且训练稳定

选择哪种度量取决于具体问题：需要信息论解释时选 KL，需要几何意义和稳定梯度时选 Wasserstein。
