### 复数的几何表示
复数可以通过引入**复平面**（高斯平面）来进行几何表示。
- 设复数 $z = x + iy$（其中 $x, y \in \mathbb{R}$，$i$ 为虚数单位且 $i^2 = -1$）。
- 在直角坐标系中，$x$ 轴称为**实轴**，$y$ 轴称为**虚轴**。
- 复数 $z$ 与复平面上的点 $P(x, y)$ 形成一一对应关系。
- 另外，复数 $z$ 也可以表示为起点在原点 $O$、终点在 $P(x, y)$ 的**向量** $\vec{OP}$。

### 复数的模和幅角
- **模（绝对值）**：表示复数 $z$ 对应的向量 $\vec{OP}$ 的长度，记作 $|z|$ 或 $r$。
  $$|z| = r = \sqrt{x^2 + y^2}$$

>注意模不能用$\sqrt{z^2}$计算

- **幅角**：表示非零复数 $z$ 的向量 $\vec{OP}$ 与实轴正半轴之间的夹角，记作 $\text{Arg} z$。
  - 由于终边相同的角有无数个，幅角具有多值性：$\text{Arg} z = \arg z + 2k\pi \quad (k \in \mathbb{Z})$。
  - **主值（$\arg z$）**：通常规定幅角的主值范围为 $(-\pi, \pi]$ 或 $[0, 2\pi)$。由坐标 $(x, y)$ 确定主值的方法满足 $\tan(\arg z) = \frac{y}{x}$（需根据点所在的象限确定具体角度）。

> [!模和幅角的计算]
> 
> $|z_1 z_2|=|z_1||z_2|$
> $\angle z_1 z_2=\angle z_1 +\angle z_2$
> 

### 复数的三角表示和指数表示
借助模 $r$ 和幅角 $\theta = \arg z$，可以将代数形式 $z = x + iy$ 转换为其他形式：
- **三角表示法**：
  因为 $x = r\cos\theta$，$y = r\sin\theta$，所以复数可以表示为：
  $$z = r(\cos\theta + i\sin\theta)$$
- **指数表示法**：
  根据**欧拉公式**（Euler's formula）$e^{i\theta} = \cos\theta + i\sin\theta$，可以将三角形式进一步简化为指数形式：
  $$z = re^{i\theta}$$
  指数形式在计算复数的乘除法时非常方便：$z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}$，$\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)}$。

### 复数的代数运算
设有两个复数 $z_1 = x_1 + iy_1$ 和 $z_2 = x_2 + iy_2$。

- **加法与减法**：实部与实部相加减，虚部与虚部相加减。
  $$z_1 \pm z_2 = (x_1 \pm x_2) + i(y_1 \pm y_2)$$
  - **几何意义**：复数的加减法对应于复平面上向量的平行四边形法则和三角形法则。
  
- **乘法**：像普通多项式展开一样进行，并利用 $i^2 = -1$ 化简整理。
  $$z_1 z_2 = (x_1 + iy_1)(x_2 + iy_2) = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + x_2 y_1)$$

- **共轭复数（Conjugate）**：若 $z = x + iy$，则其共轭复数记为 $\bar{z} = x - iy$。在复平面上，$z$ 与 $\bar{z}$ 关于实轴对称。
  - **重要性质**：一个复数与其共轭复数的乘积等于其模的平方，即 $z \bar{z} = x^2 + y^2 = |z|^2$。这是一个实数，在复数除法中极为关键。

- **除法**：利用共轭复数的性质，将分子分母同乘“分母的共轭复数”，实现**分母实数化**（前提是 $z_2 \neq 0$）。
  $$\frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{z_2 \bar{z}_2} = \frac{(x_1 + iy_1)(x_2 - iy_2)}{x_2^2 + y_2^2} = \frac{(x_1 x_2 + y_1 y_2) + i(x_2 y_1 - x_1 y_2)}{x_2^2 + y_2^2}$$
  进一步可拆分为实部和虚部：
  $$\frac{z_1}{z_2} = \frac{x_1 x_2 + y_1 y_2}{x_2^2 + y_2^2} + i\frac{x_2 y_1 - x_1 y_2}{x_2^2 + y_2^2}$$

### 复数的乘幂与方根
利用指数表示或三角表示，可以很方便地计算复数的乘幂与方根。
- **乘幂（棣莫弗公式 De Moivre's formula）**：
  对于整数 $n$，有：
  $$z^n = (re^{i\theta})^n = r^n e^{in\theta} = r^n(\cos n\theta + i\sin n\theta)$$
- **方根**：
  求复数 $z = re^{i\theta}$ 的 $n$ 次方根（$n$ 为正整数），即求方程 $w^n = z$ 的解。其公式为：
  $$w_k = \sqrt[n]{z} = \sqrt[n]{r} e^{i \frac{\theta + 2k\pi}{n}} = \sqrt[n]{r} \left( \cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n} \right)$$
  其中 $k = 0, 1, 2, \dots, n-1$。
  - 这意味着一个非零复数的 $n$ 次方根在复平面上恰好有 $n$ 个不同的值，它们均匀分布在以原点为圆心、半径为 $\sqrt[n]{r}$ 的圆上，构成一个正 $n$ 边形的顶点。
