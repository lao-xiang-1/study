
*注意：以下公式均基于单边拉普拉斯变换，即默认时间 $t \ge 0$ 时信号存在（通常隐含乘以阶跃函数 $u(t)$）。*

## 常用基本函数变换对（查表用）

| 时域函数 $f(t)$ ($t \ge 0$)  | $s$ 域函数 $F(s)$                  | 补充说明                     |
| :----------------------- | :------------------------------ | :----------------------- |
| $\delta(t)$              | $1$                             | **单位冲激信号**（瞬间极大的敲击）      |
| $1$ 或 $u(t)$             | $\frac{1}{s}$                   | **单位阶跃信号** / 常数（突然打开的开关） |
| $t$                      | $\frac{1}{s^2}$                 | **斜坡信号**（随时间匀速增加）        |
| $\frac{t^{n-1}}{(n-1)!}$ | $\frac{1}{s^n}$                 | 高阶多项式信号 ($n$ 为正整数)       |
| $e^{-at}$                | $\frac{1}{s+a}$                 | $e^{at}$也能拉式变换（符号相反）     |
| $\sin(\omega t)$         | $\frac{\omega}{s^2 + \omega^2}$ | **正弦波**（等幅振荡，无阻尼）        |
| $\cos(\omega t)$         | $\frac{s}{s^2 + \omega^2}$      | **余弦波**（等幅振荡，无阻尼）        |

## 部分函数推导过程
### 1. $\delta'(t) \to s$

#### 推导与验证
根据拉普拉斯变换的**微分性质**：
$$\mathcal{L}\{f'(t)\} = sF(s) - f(0_+)$$
如果取输入信号为**单位冲激函数** $\delta(t)$，那么：
- $f(t) = \delta(t)$，其拉普拉斯变换 $F(s) = \mathcal{L}\{\delta(t)\} = 1$
- 代入微分性质：$\mathcal{L}\{\delta'(t)\} = s\cdot1 - 0 = s$

因此逆变换可得：$\mathcal{L}^{-1}\{s\} = \delta'(t)$。
