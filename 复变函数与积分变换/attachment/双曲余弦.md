# 双曲余弦（Hyperbolic Cosine）

## 1. 定义

对实数或复数 $z$，双曲余弦定义为

$$\cosh z = \mathrm{ch}\, z = \frac{\mathrm{e}^{z} + \mathrm{e}^{-z}}{2}.$$

与它配套的还有**双曲正弦**与**双曲正切**：

$$\sinh z = \mathrm{sh}\, z = \frac{\mathrm{e}^{z} - \mathrm{e}^{-z}}{2}, \qquad
\tanh z = \mathrm{th}\, z = \frac{\sinh z}{\cosh z} = \frac{\mathrm{e}^{z} - \mathrm{e}^{-z}}{\mathrm{e}^{z} + \mathrm{e}^{-z}}.$$

> **记号说明**：英文教材写 $\cosh,\sinh,\tanh$，中文/俄式教材常写 $\mathrm{ch},\mathrm{sh},\mathrm{th}$，两者完全同义。

## 2. 与三角函数的本质联系
?
对比复三角函数的指数定义

$$\cos z = \frac{\mathrm{e}^{iz} + \mathrm{e}^{-iz}}{2}, \qquad \cosh z = \frac{\mathrm{e}^{z} + \mathrm{e}^{-z}}{2},$$

可见二者只差一个 $z \to iz$ 的替换。于是有核心恒等式：

$$\boxed{\ \cos(iz) = \cosh z \ }, \qquad \boxed{\ \cosh(iz) = \cos z \ }.$$

同理

$$\sin(iz) = i\,\sinh z, \qquad \sinh(iz) = i\,\sin z.$$

**推导**（以 $\cos(iz)$ 为例）：

$$\cos(iz) = \frac{\mathrm{e}^{i(iz)} + \mathrm{e}^{-i(iz)}}{2} = \frac{\mathrm{e}^{-z} + \mathrm{e}^{z}}{2} = \cosh z.$$

> 一句话：双曲函数并不是"新函数"，它就是三角函数沿虚轴方向的取值——两者是同一个复函数的不同切片。

## 3. 幂级数展开

$$\cos z = \sum_{n=0}^{\infty} (-1)^{n}\frac{z^{2n}}{(2n)!}
= 1 - \frac{z^{2}}{2!} + \frac{z^{4}}{4!} - \cdots$$

$$\cosh z = \sum_{n=0}^{\infty} \frac{z^{2n}}{(2n)!}
= 1 + \frac{z^{2}}{2!} + \frac{z^{4}}{4!} + \cdots$$

即把 $\cos z$ 的级数中 $z^{2} \to -z^{2}$（等价于 $z \to iz$）就得到 $\cosh z$ 的级数，从级数层面再次印证 $\cos(iz)=\cosh z$。

## 4. 常用恒等式与对照

| 三角函数 | 双曲函数 |
| :--- | :--- |
| $\cos^{2}z + \sin^{2}z = 1$ | $\cosh^{2}z - \sinh^{2}z = 1$ |
| $\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$ | $\cosh(\alpha+\beta)=\cosh\alpha\cosh\beta+\sinh\alpha\sinh\beta$ |
| $\cos 2z = 2\cos^{2}z - 1$ | $\cosh 2z = 2\cosh^{2}z - 1$ |
| $(\cos z)' = -\sin z$ | $(\cosh z)' = \sinh z$ |

补充：

- **平方关系**：$\cosh^{2}z - \sinh^{2}z = 1$
- **和角公式**：$\cosh(\alpha+\beta) = \cosh\alpha\cosh\beta + \sinh\alpha\sinh\beta$（注意中间是 **加号**，与三角的减号相反）
- **倍角公式**：$\cosh 2z = \cosh^{2}z + \sinh^{2}z = 2\cosh^{2}z - 1$
- **导数**：$\dfrac{\mathrm{d}}{\mathrm{d}z}\cosh z = \sinh z$，$\dfrac{\mathrm{d}}{\mathrm{d}z}\sinh z = \cosh z$
- **周期性**：$\cosh(z + 2\pi i) = \cosh z$，即以 $2\pi i$ 为周期；实双曲余弦**没有实周期**。

## 5. 实双曲余弦的图像与取值

- **偶函数**：$\cosh(-x) = \cosh x$。
- **最小值**：$\cosh 0 = 1$，值域 $[1, +\infty)$。
- **增长**：$x \to +\infty$ 时 $\cosh x \sim \dfrac{\mathrm{e}^{x}}{2}$（指数增长）。
- **图像**：实 $\cosh x$ 的曲线就是**悬链线**（catenary），即两端悬挂的链条自然下垂的形状。

几个常用数值：

$$\cosh 0 = 1, \qquad \cosh 1 = \frac{\mathrm{e} + \mathrm{e}^{-1}}{2} \approx 1.5431, \qquad \cos i = \cosh 1 \approx 1.5431.$$
