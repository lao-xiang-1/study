#math 

Re (Real) 表示实部，Im（Imaginary）表示虚部

## 共轭复数的性质
  - $z\bar{z} = (x + iy)(x - iy) = x^2 + y^2 = |z|^2$（结果恒为非负实数）。
  - $|z_1 \bar{z_2}| = |z_1| |z_2|$

- **运算性质**：共轭运算与四则运算可以交换次序（设 $z_1, z_2$ 为任意复数）。
  - $\overline{z_1 \pm z_2} = \bar{z_1} \pm \bar{z_2}$
  - $\overline{z_1 z_2} = \bar{z_1}\,\bar{z_2}$
  - $\overline{\left(\dfrac{z_1}{z_2}\right)} = \dfrac{\bar{z_1}}{\bar{z_2}} \quad (z_2 \neq 0)$

- **其他性质**：
  - $\overline{e^{i\theta}} = e^{-i\theta}$，即 $\arg \bar{z} = -\arg z$

> 共轭的一个重要用途是把复数除法化归为实数分母：$\dfrac{z_1}{z_2} = \dfrac{z_1 \bar{z_2}}{z_2 \bar{z_2}} = \dfrac{z_1 \bar{z_2}}{|z_2|^2}$。


## 复数的模和幅角
1. **模（绝对值）**：表示复数 $z$ 对应的向量 $\vec{OP}$ 的长度，记作 $|z|$ 或 $r$。
$$|z| = r = \sqrt{x^2 + y^2}$$

>注意模不能用$\sqrt{z^2}$计算

2. **幅角**：表示非零复数 $z$ 的向量 $\vec{OP}$ 与实轴正半轴之间的夹角，记作 $\text{Arg} z$。
  - 由于终边相同的角有无数个，幅角具有多值性：$\text{Arg} z = \arg z + 2k\pi \quad (k \in \mathbb{Z})$。
  - **主值（$\arg z$）**：通常规定幅角的主值范围为 $(-\pi, \pi]$ 或 $[0, 2\pi)$。由坐标 $(x, y)$ 确定主值的方法满足 $\tan(\arg z) = \frac{y}{x}$（需根据点所在的象限确定具体角度）。


## 复数的几何表示
复数可以通过引入**复平面**（高斯平面）来进行几何表示。
- 设复数 $z = x + iy$（其中 $x, y \in \mathbb{R}$，$i$ 为虚数单位且 $i^2 = -1$）。
- 在直角坐标系中，$x$ 轴称为**实轴**，$y$ 轴称为**虚轴**。

### 复球面
除了用平面内的点或向量表示复数外，还可以用**球面**上的点来表示复数。

- **构造**：取一个与复平面相切于原点 $z=0$ 的球面，切点 $S$ 称为**南极**；过 $S$ 作垂直于复平面的直线，与球面交于另一点 $N$，称为**北极**。
- **球极投影（Stereographic Projection）**：对复平面内任一点 $z$，用直线段把 $z$ 与北极 $N$ 相连，该线段必与球面交于异于 $N$ 的一点 $P$；反之，球面上任一异于 $N$ 的点 $P$ 与 $N$ 连线的延长线也与复平面交于一点 $z$。故球面上除北极 $N$ 外的点与复数一一对应。
- **无穷远点**：当 $z$ 无限远离原点（即 $|z|$ 无限变大）时，$P$ 无限接近 $N$。为使复平面与球面上的点无例外地一一对应，规定复平面上有唯一的**无穷远点**与北极 $N$ 对应，复数中有唯一的**无穷大** $\infty$ 与之对应，即 $N$ 是 $\infty$ 的几何表示。这样的球面称为**复球面**。

- **扩充复平面**：包括无穷远点在内的复平面。
- **有限平面（复平面）**：不包括无穷远点在内的复平面。

> 对 $\infty$ 而言，实部、虚部与辐角均无意义，但规定其模为正无穷大，即 $|\infty|=+\infty$；而对其他每个复数 $z$，有 $|z|<+\infty$。

$\infty$ 的四则运算规定（$\alpha \neq \infty$）：
- 加法：$\alpha + \infty = \infty + \alpha = \infty$
- 减法：$\alpha - \infty = \infty - \alpha = \infty$
- 乘法：$\alpha \cdot \infty = \infty \cdot \alpha = \infty \quad (\alpha \neq 0)$
- 除法：$\dfrac{\alpha}{\infty} = 0$，$\dfrac{\infty}{\alpha} = \infty$，$\dfrac{\alpha}{0} = \infty \quad (\alpha \neq 0)$

> $\infty \pm \infty$、$0 \cdot \infty$、$\dfrac{\infty}{\infty}$ 均不规定其意义；与实变数一样，$\dfrac{0}{0}$ 仍不确定。

复球面能把扩充复平面的无穷远点明显地表示出来，这正是它比复平面优越的地方。引入扩充复平面与无穷远点，在很多讨论中能带来方便与和谐。


## 复数的三角表示和指数表示
借助模 $r$ 和幅角 $\theta = \arg z$，可以将代数形式 $z = x + iy$ 转换为其他形式：
1. **三角表示法**：
  因为 $x = r\cos\theta$，$y = r\sin\theta$，所以复数可以表示为：
$$z = r(\cos\theta + i\sin\theta)$$
2. **指数表示法**：
  根据**欧拉公式**（Euler's formula）$e^{i\theta} = \cos\theta + i\sin\theta$，可以将三角形式进一步简化为指数形式：
$$z = re^{i\theta}$$
  - 指数形式在计算复数的乘除法时非常方便：$z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}$，$\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)}$。
  - 由图像法易得：$r = \sqrt{x^2 + y^2}$，$\theta = arctan(\frac{y}{x})$。
  


## 复数的乘幂与方根
利用指数表示或三角表示，可以很方便地计算复数的乘幂与方根。
设 $z = re^{i\theta} = r(\cos n\theta + i\sin n\theta)$：
- **乘幂（棣莫弗公式 De Moivre's formula）**：
  对于整数 $n$，有：
  $$z^n = (re^{i\theta})^n = r^n e^{in\theta} = r^n(\cos n\theta + i\sin n\theta)$$
- **方根**：
  求复数 $z = re^{i\theta}$ 的 $n$ 次方根（$n$ 为正整数），即求方程 $w^n = z$ 的解。其公式为：
  $$w_k = \sqrt[n]{z} = \sqrt[n]{r} e^{i \frac{\theta + 2k\pi}{n}} = \sqrt[n]{r} \left( \cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n} \right)$$
  其中 $k = 0, 1, 2, \dots, n-1$。
  - 这意味着一个非零复数的 $n$ 次方根在复平面上恰好**有 $n$ 个不同的值**，它们均匀分布在以原点为圆心、半径为 $\sqrt[n]{r}$ 的圆上，构成一个正 $n$ 边形的顶点。
  - 除了利用 棣莫弗公式 推导，也可以认为 $z = re^{i (\theta + 2k\pi)}$ ，直接用初等函数的计算法得 $w_k = \sqrt[n]{r} e^{i \frac{\theta + 2k\pi}{n}}$，而 角度$(\theta + 2k\pi) / n$ 在 $(0, 2\pi)$ 内有 n 个不同的取值，所以 $k \;取\; 0, 1, 2, \dots, (n-1)$。

## 区域
- 如果区域D可以被包含在一个以原点为中心的圆内，那么称区域D为**有界**的，反之为**无界**
- 对于一个区域B，如果在其内部任作一条简单闭曲线，而曲线的内部总属于该区域，那么该区域为**单连通域**，反之为**多连通域**（看区域中有没有缺口）

## 映射
设$z = x + iy, \quad w = u + iv$，其中 x-y平面成为 z平面，u-v平面称为 w平面。
那么 $w = f(z)$ 所构成的映射就是把 z平面上的点 映射到 w平面上。

## 复变函数的极限的性质
如果 $\lim\limits_{z \to z_0} f(z) = A,\quad \lim\limits_{z \to z_0} g(z) = B$，那么：
1. $\lim\limits_{z \to z_0} [f(z) + g(z)] = A +B$
2. $\lim\limits_{z \to z_0} [f(z) g(z)] = AB$
3. $\lim\limits_{z \to z_0} \frac{f(z)}{g(z)} = \frac{A}{B}, \quad (B\ne 0)$
