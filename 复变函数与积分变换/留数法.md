这是一个很好的问题！这里用到的是《信号与系统》和《控制工程》中非常常用的**部分分式展开技巧**（通常称为**掩盖法**或**留数法**，Heaviside cover-up method）。

当我们把一个复杂的分式拆解时：
$$ \frac{-2}{(s + 1)^2(s + 2)} = \frac{K_1}{(s + 1)^2} + \frac{K_2}{s + 1} + \frac{K_3}{s + 2} $$
我们的目标是求出 $K_1, K_2, K_3$。下面我把这三步的原理详细拆解给你看：


## 一、题目具体示例
### 1. 为什么 $K_1$ 和 $K_3$ 可以直接“遮住”代入求值？

这利用了等式两边同乘分母的原理。

**求解 $K_1$（重根最高次项）：**
将等式两边同时乘以 $(s + 1)^2$：
$$ \frac{-2}{s + 2} = K_1 + \frac{K_2(s + 1)^2}{s + 1} + \frac{K_3(s + 1)^2}{s + 2} $$
化简一下：
$$ \frac{-2}{s + 2} = K_1 + K_2(s + 1) + \frac{K_3(s + 1)^2}{s + 2} $$
此时，如果令 **$s = -1$**，等式右边含有 $(s + 1)$ 的项就全部变成 0 了！只剩下 $K_1$：
$$ K_1 = \left. \frac{-2}{s + 2} \right|_{s = -1} = \frac{-2}{-1 + 2} = -2 $$
*(通俗地说，就是把原式左边分母里的 $(s+1)^2$ "遮住"，然后把 $s=-1$ 代入剩下的部分计算)*

**求解 $K_3$（单根项）：**
同理，将等式两边同时乘以 $(s + 2)$：
$$ \frac{-2}{(s + 1)^2} = \frac{K_1(s + 2)}{(s + 1)^2} + \frac{K_2(s + 2)}{s + 1} + K_3 $$
此时，如果令 **$s = -2$**，等式右边含有 $(s + 2)$ 的项就全为 0 了，只剩下 $K_3$：
$$ K_3 = \left. \frac{-2}{(s + 1)^2} \right|_{s = -2} = \frac{-2}{(-2 + 1)^2} = -2 $$

---

### 2. 为什么求解 $K_2$ 要“同乘 $s$ 并令 $s \to \infty$”？

对于重根的低次项（即 $K_2$），我们不能再用“遮住代入法”了，因为如果你两边同乘 $(s+1)$ 再令 $s=-1$，$K_1$ 那一项的分母会变成 0，导致等式失去意义。

这里我们用了一个非常巧妙的**极限法**。
回到最初的等式：
$$ \frac{-2}{(s + 1)^2(s + 2)} = \frac{K_1}{(s + 1)^2} + \frac{K_2}{s + 1} + \frac{K_3}{s + 2} $$

**等式两边同时乘以 $s$：**
$$ \frac{-2s}{(s + 1)^2(s + 2)} = \frac{K_1 s}{(s + 1)^2} + \frac{K_2 s}{s + 1} + \frac{K_3 s}{s + 2} $$

**现在，让 $s$ 趋向于无穷大 ($s \to \infty$)，我们来看每一项的极限：**
1. **等式左边：** 分子是 1 次方（$-2s$），分母展开后是 3 次方（$s^3 + \dots$）。根据求极限的法则，“分母阶数 > 分子阶数”，当 $s \to \infty$ 时，极限为 **$0$**。
2. **等式右边第 1 项：** $\lim_{s \to \infty} \frac{K_1 s}{(s+1)^2} = 0$ （分母是 $s^2$，分子是 $s$，极限为 0）。
3. **等式右边第 2 项：** $\lim_{s \to \infty} \frac{K_2 s}{s+1} = K_2$ （分子分母同阶，系数之比）。
4. **等式右边第 3 项：** $\lim_{s \to \infty} \frac{K_3 s}{s+2} = K_3$ （分子分母同阶，系数之比）。

把这些极限结果合并起来，等式就变成了：
$$ 0 = 0 + K_2 + K_3 $$
也就是：
$$ K_2 = -K_3 $$
因为前面已经求出 $K_3 = -2$，所以立刻就能得到 $K_2 = 2$。

---

**补充：求解 $K_2$ 的另一种常见方法（代入特殊值法）**
如果你觉得极限法不好理解，也可以随便找一个好算且没有用过的 $s$ 值（比如 $s = 0$）代入原等式：
$$ \left. \frac{-2}{(s + 1)^2(s + 2)} \right|_{s=0} = \frac{K_1}{1^2} + \frac{K_2}{1} + \frac{K_3}{2} $$
得到：
$$ \frac{-2}{2} = K_1 + K_2 + \frac{K_3}{2} $$
$$ -1 = -2 + K_2 + \frac{-2}{2} $$
$$ -1 = -2 + K_2 - 1 $$
解得：$K_2 = 2$。
这两种方法殊途同归，但“乘 $s$ 趋于无穷”的方法在多项式较复杂时计算量更小。

## 留数法通用解法

有的！你提到的“更通用的解法”正是基于复变函数中的**留数定理（Residue Theorem）**推导出来的一般公式。这种方法被称为**求导法**，专门用来对付**多重极点（重根）**，它是最严谨且完全通用的数学方法。

下面我为你详细推导并演示如何用这个通用公式来求解 $K_1$ 和 $K_2$。

### 1. 通用留数公式（求导法）

假设函数 $F(s)$ 在 $s = p$ 处有一个 $m$ 重极点（即分母含有 $(s - p)^m$），其部分分式展开式中对应于该重根的部分为：
$$ \frac{A_m}{(s - p)^m} + \frac{A_{m-1}}{(s - p)^{m-1}} + \dots + \frac{A_1}{s - p} $$

根据留数法，求解任意系数 $A_k$（$k = 1, 2, \dots, m$）的**通用计算公式**为：
$$ A_k = \frac{1}{(m - k)!} \lim_{s \to p} \frac{d^{m-k}}{ds^{m-k}} \left[ (s - p)^m F(s) \right] $$

*注：其中 $(m - k)!$ 是阶乘，$\frac{d^{m-k}}{ds^{m-k}}$ 表示求 $m-k$ 阶导数。当 $m-k = 0$ 时，0阶导数意味着不求导，0! = 1。*

---

### 2. 通用公式背后的推导逻辑

为什么要求导？我们来看一下将 $F(s)$ 同乘 $(s - p)^m$ 后的结果：
$$ (s - p)^m F(s) = A_m + A_{m-1}(s - p) + A_{m-2}(s - p)^2 + \dots + R(s)(s - p)^m $$
*(其中 $R(s)$ 是包含其他单根的部分)*

- **求最高次项 $A_m$**：直接令 $s = p$，后面含有 $(s-p)$ 的项全部消掉，直接得到 $A_m$。这其实就是前面的**“遮住代入法”**。
- **求次高次项 $A_{m-1}$**：怎么把 $A_m$ 去掉并让 $A_{m-1}$ 露出来？**对两边求一次导数！**
  常数 $A_m$ 求导后变为 0，而 $A_{m-1}(s - p)$ 求导后变成了 $A_{m-1}$。此时再令 $s = p$，就求出了 $A_{m-1}$。
- 同理，求更低次项就继续求导。每次求导会带出幂次的系数，所以公式前面要除以阶乘 $(m-k)!$。

---

### 3. 用通用公式解决前面的例题

回到你的等式：
$$ F(s) = \frac{-2}{(s + 1)^2(s + 2)} = \frac{K_1}{(s + 1)^2} + \frac{K_2}{s + 1} + \frac{K_3}{s + 2} $$

对于重根 $s = -1$，它的重数是 **$m = 2$**。

**① 求解重根最高次项 $K_1$（此时 $k = 2$）**
代入公式，需要求 $m - k = 2 - 2 = 0$ 阶导数（即不求导）：
$$ K_1 = \frac{1}{0!} \lim_{s \to -1} \left[ (s + 1)^2 F(s) \right] $$
$$ K_1 = \lim_{s \to -1} \frac{-2}{s + 2} = \frac{-2}{-1 + 2} = -2 $$
*(这与我们之前的“掩盖法”完全一致。)*

**② 求解重根次高次项 $K_2$（此时 $k = 1$）**
代入公式，需要求 $m - k = 2 - 1 = 1$ 阶导数：
$$ K_2 = \frac{1}{1!} \lim_{s \to -1} \frac{d}{ds} \left[ (s + 1)^2 F(s) \right] $$
首先把 $(s + 1)^2$ 乘进去化简：
$$ (s + 1)^2 F(s) = \frac{-2}{s + 2} $$
然后对其求一阶导数（根据分数求导法则 $(\frac{c}{v})' = -\frac{cv'}{v^2}$）：
$$ \frac{d}{ds} \left( \frac{-2}{s + 2} \right) = \frac{2}{(s + 2)^2} $$
最后，令 $s \to -1$：
$$ K_2 = \left. \frac{2}{(s + 2)^2} \right|_{s = -1} = \frac{2}{(-1 + 2)^2} = \frac{2}{1} = 2 $$

这与我们之前用“同乘 $s$ 趋于无穷”得到的结果 $K_2 = 2$ 完全相同！

### 总结

- **单根（或重根最高次项）**：直接用“遮住代入法”（留数公式的 0 阶导情况）。
- **重根的其他项**：通用解法就是**求导法**。
- **实战建议**：如果只是 2 重根，求一次导数很简单，用这个通用公式非常快且不易错；但如果是 3 重根甚至更高重根，求多次导数计算量会急剧增大，这时候结合“同乘 $s \to \infty$”或者“代入特殊值法”往往更高效。三种方法可以灵活组合使用。
