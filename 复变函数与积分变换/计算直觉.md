对于指数$e^s = e^{\sigma + j\omega}$来说，虚部$e^{j\omega}$的模长一定为1



## 部分分式分解
### 情况一：无重根的线性因式（一阶一次因式）

这是最简单、最常用的场景。假设分母可以分解为互不相同的线性因式：
$$f(x) = \frac{P(x)}{(x-a)(x-b)\cdots} = \frac{A}{x-a} + \frac{B}{x-b} + \cdots$$

**计算公式：**
求系数 $A$ 时，只需在等式两边同乘以 $(x-a)$，并取 $x \to a$ 的极限：
$$A = \lim_{x \to a} \left[ (x-a) \cdot f(x) \right]$$
在实际操作中，相当于**遮住**原式分母中的 $(x-a)$ 项，然后将 $x = a$ 代入剩下的部分。

#### 示例 1
将 $\frac{2x+3}{(x-1)(x+2)}$ 分解为 $\frac{A}{x-1} + \frac{B}{x+2}$。

*   **求 $A$**（遮住 $x-1$，令 $x \to 1$）：
    $$A = \lim_{x \to 1} \frac{2x+3}{x+2} = \frac{2(1)+3}{1+2} = \frac{5}{3}$$
*   **求 $B$**（遮住 $x+2$，令 $x \to -2$）：
    $$B = \lim_{x \to -2} \frac{2x+3}{x-1} = \frac{2(-2)+3}{-2-1} = \frac{-1}{-3} = \frac{1}{3}$$

**结果：**
$$\frac{2x+3}{(x-1)(x+2)} = \frac{5}{3(x-1)} + \frac{1}{3(x+2)}$$

### 情况二：有重根的线性因式（高阶一次因式）

当分母含有形如 $(x-a)^k$ 的重根时，分解形式为：
$$f(x) = \frac{P(x)}{(x-a)^k \cdot R(x)} = \frac{A_k}{(x-a)^k} + \frac{A_{k-1}}{(x-a)^{k-1}} + \cdots + \frac{A_1}{x-a} + \text{其他项}$$

**计算公式：**
定义辅助函数 $$g(x) = (x-a)^k \cdot f(x)=A_k+...$$
（即把原式中含重根的分母项去掉）。
各系数的极限求法为：
$$A_{k-m} = \frac{1}{m!} \lim_{x \to a} \frac{d^m}{dx^m} [g(x)] \quad (m = 0, 1, \dots, k-1)$$
也就是说，最高次幂的系数 $A_k$ 可以直接代入求得；次高次的系数需要求导 1 次后再代入；以此类推。

#### 示例 2
将 $\frac{x^2+1}{(x-1)^2(x+1)}$ 分解为 $\frac{A_2}{(x-1)^2} + \frac{A_1}{x-1} + \frac{B}{x+1}$。

先定义 $g(x) = (x-1)^2 f(x) = \frac{x^2+1}{x+1}$。

1.  **求 $A_2$**（不用求导，直接取极限）：
    $$A_2 = \lim_{x \to 1} g(x) = \lim_{x \to 1} \frac{x^2+1}{x+1} = \frac{1+1}{1+1} = 1$$
2.  **求 $A_1$**（求导 1 次）：
    先对 $g(x)$ 求导：
    $$g'(x) = \frac{2x(x+1) - (x^2+1) \cdot 1}{(x+1)^2} = \frac{x^2+2x-1}{(x+1)^2}$$
    求极限：
    $$A_1 = \frac{1}{1!} \lim_{x \to 1} g'(x) = \frac{1^2+2(1)-1}{(1+1)^2} = \frac{2}{4} = \frac{1}{2}$$
3.  **求 $B$**（单根，使用情况一的方法）：
    $$B = \lim_{x \to -1} (x+1)f(x) = \lim_{x \to -1} \frac{x^2+1}{(x-1)^2} = \frac{(-1)^2+1}{(-1-1)^2} = \frac{2}{4} = \frac{1}{2}$$

**结果：**
$$\frac{x^2+1}{(x-1)^2(x+1)} = \frac{1}{(x-1)^2} + \frac{1}{2(x-1)} + \frac{1}{2(x+1)}$$
