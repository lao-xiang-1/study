#math 

[7. 对偶的几何解释](#7.%20对偶的几何解释)

## 1. 从原问题到对偶问题

### 1.1 什么是"对偶"

考虑标准形式的约束优化问题（**原问题 / Primal Problem**）：

$$
\min_{x} f(x) \quad \text{s.t.} \quad g_i(x) \le 0, \quad h_j(x) = 0
$$

所谓**对偶**（Duality），就是从原问题出发，通过拉格朗日函数构造一个以乘子为变量的新问题。两个问题从不同角度刻画同一个最优值：

> **原问题在"最小化"，对偶问题在"最大化"；一个从上方逼近，一个从下方逼近。**

### 1.2 为什么要转对偶

| 动机 | 说明 |
|------|------|
| **约束更简单** | 对偶问题往往只剩 $\alpha_i \ge 0$，比原约束 $g_i(x) \le 0$ 更容易处理 |
| **暴露内积结构** | 消去原始变量后，$x$ 只以 $\langle x_i, x_j \rangle$ 形式出现——这是引入核方法（Kernel Trick）的前提 |
| **变量维度变换** | 原始变量维度可能很高（如特征维数），而对偶变量 $\alpha$ 的数量等于约束个数 |
| **对偶问题总是凸的** | 无论原问题是否凸，对偶问题一定是凸优化——这是它与生俱来的好性质 |

---

## 2. 拉格朗日对偶函数

### 2.1 定义

给定原问题的拉格朗日函数：

$$
L(x, \alpha, \beta) = f(x) + \sum_{i=1}^{m} \alpha_i g_i(x) + \sum_{j=1}^{p} \beta_j h_j(x), \quad \alpha_i \ge 0
$$

定义**拉格朗日对偶函数**（Lagrange Dual Function）：

$$
\theta(\alpha, \beta) = \inf_{x} L(x, \alpha, \beta)
$$

> 即：固定乘子 $(\alpha, \beta)$，对 $x$ 在整个定义域上取 $L$ 的下确界。

### 2.2 对偶函数的关键性质

**（1）对偶函数总是凹函数**

无论 $f(x), g_i(x), h_j(x)$ 是什么形式，$\theta(\alpha, \beta)$ 都是关于 $(\alpha, \beta)$ 的**凹函数**。原因是：$\theta$ 是一族关于 $(\alpha, \beta)$ 的仿射函数（对每个 $x$，$L$ 是 $\alpha, \beta$ 的仿射函数）的逐点下确界，而逐点下确界保持凹性。

**（2）对偶函数给出原问题最优值的下界**

对任意 $\alpha \ge 0$ 和任意 $\beta$，有：

$$
\theta(\alpha, \beta) \le p^*
$$

其中 $p^*$ 是原问题的最优值。

>**证明思路**：设 $x^*$ 是原问题最优解，则对任意 $\alpha \ge 0, \beta$：
$$
 \theta(\alpha, \beta) = \inf_x L(x, \alpha, \beta) \le L(x^*, \alpha, \beta) = f(x^*) + \underbrace{\sum \alpha_i g_i(x^*)}_{\le 0} + \underbrace{\sum \beta_j h_j(x^*)}_{= 0} \le f(x^*) = p^*
$$

---

## 3. 对偶问题的标准形式

既然 $\theta(\alpha, \beta)$ 给出的下界对任意 $\alpha \ge 0$ 都成立，一个自然的问题是：**什么样的下界是"最好"的？**

这就引出了**对偶问题**（Dual Problem）：

$$
\max_{\alpha \ge 0, \beta} \quad \theta(\alpha, \beta)
$$

记对偶最优值为 $d^*$，则对偶问题就是：

> **在所有可行的乘子中，找一个使得对偶函数最大的，得到原问题最优值的最紧下界。**

**原问题 vs 对偶问题对照表：**

| | 原问题 (Primal) | 对偶问题 (Dual) |
|------|------|------|
| **优化变量** | $x$（原始变量） | $\alpha, \beta$（乘子） |
| **目标** | 最小化 $f(x)$ | 最大化 $\theta(\alpha, \beta)$ |
| **约束** | $g_i(x) \le 0, \; h_j(x) = 0$ | $\alpha_i \ge 0$（只有这一个硬约束） |
| **最优值** | $p^*$ | $d^*$ |
| **凸性** | 不一定 | **一定凸** |

---

## 4. 弱对偶性

### 4.1 定义

**弱对偶性**（Weak Duality）：对任意原可行解 $x$ 和任意对偶可行解 $(\alpha, \beta)$，恒有：

$$
\theta(\alpha, \beta) \le f(x)
$$

因此最优值之间满足：

$$
d^* \le p^*
$$

> 弱对偶性**无条件恒成立**。无论原问题是否凸、是否有解，这个不等式永远正确。

### 4.2 弱对偶有什么用

即使强对偶不成立，弱对偶依然很有价值：

- 任意对偶可行解提供一个**可计算的下界**，可用于评估解的质量。
- 在分支定界（Branch and Bound）等算法中，对偶函数提供下界来剪枝。
- 若找到某个 $x$ 满足 $f(x) = \theta(\alpha, \beta)$，则可立即断定 $x$ 是最优解。

---

## 5. 强对偶性与 Slater 条件

### 5.1 强对偶

**强对偶性**（Strong Duality）：对偶最优值等于原问题最优值：

$$
d^* = p^*
$$

此时，原问题和对偶问题之间没有"间隙"，对偶问题提供了原问题的精确等价形式。

### 5.2 Slater 条件

强对偶不是无条件成立的。对于**凸优化问题**（$f$ 和 $g_i$ 是凸函数，$h_j$ 是仿射函数），一个常用的充分条件是 **Slater 条件**：

存在一个严格可行点 $x$，使得所有不等式约束严格成立：
$$
 g_i(x) < 0, \quad \forall i
 $$
（等式约束 $h_j(x) = 0$ 按仿射约束自然满足。）

**直觉**：只要可行域"内部不是空的"，强对偶就成立。

> 当某些 $g_i$ 是仿射函数时，对应的严格不等式可以放宽为 $\le 0$，只要求非仿射的不等式约束有严格可行点即可。

### 5.3 强对偶成立的条件总结

| 条件 | 强对偶 |
|------|--------|
| 原问题为凸优化 + Slater 条件成立 | ✅ 成立 |
| 原问题为凸优化 + Slater 不成立 | 可能成立也可能不成立 |
| 原问题非凸 | 一般**不成立**（存在对偶间隙） |

---

## 6. 对偶间隙

**对偶间隙**（Duality Gap）定义为：

$$
\text{gap} = p^* - d^* \ge 0
$$

- 强对偶成立时，$\text{gap} = 0$。
- 强对偶不成立时，$\text{gap} > 0$，表示对偶问题只能给出原问题的一个下界近似。

> 在非凸问题中，对偶间隙的存在意味着"转对偶求解"会丢失部分最优性。但即便如此，对偶问题依然有用——因为它给出的是一个可计算的下界。

## 7. 对偶的几何解释

### 7.1 集合构造

考虑只有一个不等式约束的最简单情形：

$$
\min f(x) \quad \text{s.t.} \quad g(x) \le 0
$$

定义集合 $\mathcal{G}$——所有可达的 $(g(x), f(x))$ 对：

$$
\mathcal{G} = \{ (u, t) \mid \exists x: g(x) = u, \; f(x) = t \}
$$

那么：
- 原问题的最优值 $p^*$ = 在 $u \le 0$ 的区域里，$t$ 的最小值。
- 对偶问题的最优值 $d^*$ = 用一条斜率为 $-\alpha$（$\alpha \ge 0$）的直线去"托住"集合 $\mathcal{G}$，直线在 $u = 0$ 处的截距的最大值。

- $p^*$ 是集合 $\mathcal{G}$ 在 $u \le 0$ 半平面内的最低点。
- $d^*$ 是用一条不穿过 $\mathcal{G}$ 的支撑超平面（斜率为 $-\alpha$）在 $u=0$ 处的截距的最大值。
- **$p^* = d^*$ 当且仅当 $\mathcal{G}$ 在 $u \le 0$ 区域的"下边界"是凸的**——这正是强对偶的几何本质。

## 8. 对偶问题与 KKT 条件的关系

### 8.1 KKT 条件回顾

KKT 条件（详见 [[拉格朗日乘数法与KKT条件]]）是强对偶成立时，原-对偶最优解对 $(x^*, \alpha^*, \beta^*)$ 必须满足的一组必要条件（凸情形下也是充分的）：

| 条件 | 含义 |
|------|------|
| $\nabla_x L = 0$ | 平稳性——$x^*$ 是 $L$ 关于 $x$ 的驻点 |
| $g_i(x^*) \le 0, \; h_j(x^*) = 0$ | 原始可行性 |
| $\alpha_i^* \ge 0$ | 对偶可行性 |
| $\alpha_i^* \cdot g_i(x^*) = 0$ | 互补松弛 |

### 8.2 原-对偶关系链

KKT 条件恰好描述了 $x^*$（原问题最优解）和 $(\alpha^*, \beta^*)$（对偶问题最优解）之间的配合关系：

- **对偶可行性**（$\alpha_i \ge 0$）确保 $(\alpha, \beta)$ 是对偶问题的可行解。
- **互补松弛**（$\alpha_i g_i = 0$）确保原、对偶之间的紧致耦合。
- **平稳性**（$\nabla_x L = 0$）确保 $x$ 在 $L$ 中取到 $\inf$。

> 一言以蔽之：**强对偶成立 ⇔ KKT 条件有解（凸优化 + Slater 条件下）**。

```
原问题: min f(x) s.t. g(x)≤0, h(x)=0
              │
              ▼
    ┌─────────────────────────┐
    │ 1. 构造 L(x,α,β)       │
    │   = f(x) + Σαᵢgᵢ + Σβⱼhⱼ │
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 2. 定义对偶函数         │
    │   θ(α,β) = inf_x L     │
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 3. 写出对偶问题         │
    │   max θ(α,β) s.t. α≥0  │
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 4. 求 θ 的解析式       │
    │   令 ∇_x L = 0, 代回消去x│
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 5. 求解对偶问题         │
    │   得到 α*, β*, d*      │
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 6. 验证强对偶           │
    │   凸 + Slater → d* = p* │
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │ 7. 还原原始解 x*        │
    │   通过 KKT 条件反推     │
    └─────────────────────────┘
```

## 10. 应用场景

- **支持向量机（SVM）**：原问题在 $w$ 空间，对偶问题在 $\alpha$ 空间，暴露 $\langle x_i, x_j \rangle$ 内积结构，使核方法成为可能。详见 [[4. 支持向量机]]。
- **拉格朗日松弛**（Lagrangian Relaxation）：在组合优化中，把困难约束"松弛"进目标函数，用对偶提供下界。
- **分布式优化**：对偶分解（Dual Decomposition）将大规模问题拆分为子问题并行求解。
- **经济学**：影子价格（Shadow Price）就是对偶变量的经济学解释——它度量了放松单位约束带来的边际收益。
