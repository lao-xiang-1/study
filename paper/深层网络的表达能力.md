考虑两种全连接网络：

5 -> 4096 -> 10

5 -> 64 -> 64 -> 64 -> 64 -> 10

- 参数量
第一种：$5 \times 4096 + 4096 \times 10 = 61440$
第二种：$5 \times 64 + 64 \times 64 + 64 \times 64 + 64 \times 64 + 64 \times 10 = 13248$

## 深度真正带来的是什么: 线性区域（piecewise-linear regions）

对一个 ReLU 网络,表达能力可以精确地用**它能把输入空间划分成多少个线性区域**来衡量。Montufar 等人的结论（*On the number of linear regions of deep neural networks*, 2014）:

- 宽度 $n$、深度 $L$ 的网络,线性区域数 $\le \prod_{i=1}^{L}\sum_{j=0}^{d}\binom{n_i}{j}$（$d$ = 输入维度）
- **单隐层**（浅而宽）时这个量只随宽度**多项式增长**（这里是 $d=5$,约 $N^5$）
- **多层**（深而窄）时会**逐层相乘,随深度指数增长**

拿你的两个网络实算（$d=5$）:

|                                 | 宽度   | 隐藏单元 | 参数    | 线性区域数上界                                                              |
| ------------------------------- | ---- | ---- | ----- | -------------------------------------------------------------------- |
| 浅宽 $5\to4096\to10$              | 4096 | 4096 | 61440 | $\sum_{j=0}^{5}\binom{4096}{j}\approx 9.6\times10^{15}$              |
| 深窄 $5\to64\to64\to64\to64\to10$ | 64   | 256  | 13248 | $\left(\sum_{j=0}^{5}\binom{64}{j}\right)^4\approx 4.8\times10^{27}$ |

**注意这个对比的震撼之处**: 深网络参数更少（13248 < 61440）、隐藏单元更少（256 < 4096),可它能刻画的线性区域数量却是浅网络的 **约 $10^{11}$ 倍以上**。
