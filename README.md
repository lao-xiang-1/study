# 个人学习笔记整理

个人向的学习笔记整理。目前在尝试整理我所有学过的东西。并且不断扩展新内容。

**全部为markdown格式**，该格式对ai友好，可配合ai学习。

许多内容为**ai生成**，虽然都经过我审核，但是还可能出现错误，请自行判断。

所有笔记力求简短，只记录最重要的信息，减少阅读量

目前还很乱，许多笔记需要后续整理

---

## 为什么要做这个笔记库？

很多人会觉得，做这样的东西根本没有用。因为大多数笔记根本不会被复习，更何况是ai生成的，写完了就不会在看了。但实际上只要配合一些复习系统，就可以解决这个问题。我自己使用的是obsidian的插件 Spaced-Repetition（不是广告，这是开源的）, 它可以追踪你的标记过的笔记，根据对抗遗忘曲线的算法来进行推荐。
当然不只是这样，笔记的优点是你可以自己修改——书本是面向所有人的，而笔记是针对你自己的。你可以自己删除一些冗余的内容，加上你自己的想法。当你这样做了之后，你会发现你阅读笔记的速度会非常快。它完全是你自己的内容，你熟悉它的一切。
笔记库还有一个好处：它是不会丢失的。你以前上学时记的笔记可能已经找不到了。但是如果你把笔记记在电脑里，甚至上传到github。那它永远都在那里，就算换了一个设备，直接git pull 就好了。
我认为学习的关键在于——不要忘记以前学过的知识。要持续使用笔记复习，只有这样才能不断积累，否则一旦长时间没有学习，用不了几个月就忘干净了。

当然，这个笔记库之所以能存在，少不了ai的帮助。没有ai帮忙整理信息，我大概很快就半途而废了。使用ai生成大致框架，并且解释难度较高的内容，这一点非常重要

---

## 如何维护自己的笔记库？

1. 将任何你认为有用的知识 记到笔记中，注意必须要是长期会用到的知识。长期记忆的关键还有持续练习。如果是平时用不到的知识，复习的效果也微乎其微。
2. 设置自己的复习系统，obsidian上有很多复习插件，挑一款适合的。或者用其他的软件比如Notion，甚至是自己vibe一个插件也没有问题。
3. 配合ai学习。这一点相当重要。如前所述，没有ai帮忙整理的话，很难坚持下来。可以用任意一个agent，最好是能集成进obsidian中，这样就不用来回切换窗口。(我用的是[Claudian](https://github.com/yishentu/claudian))

**提示**：
我把我自己的obsidian设置放进[release](https://github.com/lao-xiang-1/study/releases)中了，需要的自取

## 使用建议：

虽然主要目的是 为了帮助记忆+督促自己学习，但是既然已经开源，姑且附上建议的使用方法

1. 搭配[obsidian](https://obsidian.md/)：一个本地markdown阅读器。github上的渲染规则和obsidian不同，直接在网页打开 格式会乱掉，使用obsidian则没有问题。
2. 自己创建一个git仓库：上课的时候大多不方便带电脑，那就得在手机上记笔记。创建git仓库可实现双端同步。
3. 自行修改内容：笔记是为了帮助记忆，那肯定是自己写的 最适合自己，最好能自行增添内容。
